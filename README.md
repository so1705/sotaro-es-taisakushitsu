# ES対策室 by sotaro

自分の経験を深く掘り下げた「経験DB」と、企業ごとのリサーチ、多面的な審査を使って、ESを作成・添削するためのClaude用の仕組みです。

- **自分史インタビュー**（ChatGPT）：トップクラスのキャリアアドバイザー役のAIが、点ではなく「線」で経験を掘り下げ、`経験DB.md` を作ります（レベル1〜3）。
- **ES作成・審査**（Claude）：企業の公開情報を調べて評価基準を作り、複数の審査役で採点・改善し、あなたの修正版とAIの版を比べながら仕上げます。
- **深掘りチャット**（Claude）：ESを書く中で見つかった浅いところを、あとから掘り直して経験DBを育てます。

有料版（Claude Pro：Claude Code／Cowork）と無料版（Claude.aiのプロジェクト）の両方に対応する予定です。

## 中身
| フォルダ | 内容 |
|---|---|
| `interview/` | 自分史インタビュアーの指示（ChatGPTに貼って使う） |
| `knowledge/es-pro/` | ESの本質原則・設問の裏読み・業界別・落ちるES・一次情報・線の設計図・通過ES分析 |
| `.claude/skills/` | Claude用のSkill（深掘りチャットなど。順次追加） |
| `.claude/agents/` | 有料版のエージェント（監修・リサーチ・執筆・審査役5体） |
| `.claude/commands/` | 有料版のコマンド（/es・/es-review・/rally・/deep-dive） |
| `docs/` | 設計書・更新のしかた |

## 使い方
### 有料版（Claude Pro：Claude Code／Cowork）
1. このリポジトリをクローンして、そのフォルダを Claude Code（またはデスクトップアプリのCodeタブ・Cowork）で開く
2. ChatGPTで自分史インタビューをして（`interview/自分史インタビュアー_指示.md`）、できた `経験DB.md` を `経験DB/` フォルダに入れる
3. コマンドで使う
| コマンド | すること |
|---|---|
| `/es` ＋【ES依頼】 | 0から作る。リサーチ → 骨子（ここで方向を決める）→ 執筆 → 審査役5体×2周 → AIっぽさの除去 |
| `/es-review` ＋ 自分のES | 持ち込んだESを、審査役5体×2周とAIっぽさの除去で引き上げる |
| `/rally` | 1設問ずつ、やりとりしながら仕上げる |
| `/deep-dive` | 経験DBの浅いところを掘り直す |

【ES依頼】のフォーマット：
```
【ES依頼】
■企業名：
■コース・職種：
■種類：インターン／本選考
■募集ページURL：
■設問（1問ずつ）
Q1：
字数：
Q1の書き方メモ（任意）：
■使いたいエピソード（任意）：
■全体の書き方メモ（任意）：
■備考（説明会・OB訪問で聞いた話など）：
```
