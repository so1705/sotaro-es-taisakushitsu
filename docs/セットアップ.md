# ES対策室 セットアップ手順書

ES対策室は、あなたの経験を深く掘り下げた「経験DB」と、企業ごとのリサーチ・複数の審査役を使って、ESを作り、仕上げるための仕組みです。
この手順書どおりに進めれば、最初のESを作るところまで行けます。

## 0. 有料版と無料版、どっちを使う？

| | 有料版 | 無料版 |
|---|---|---|
| 必要なもの | Claude の Pro プラン以上（Claude Code を使う） | Claude.ai の無料アカウント |
| 使う場所 | パソコンの Claude Code（ターミナル、またはデスクトップアプリ） | ブラウザかアプリの Claude.ai |
| 企業リサーチ | 調べる役が3人で手分けして、並行して調べる | 1つのチャットで、順番に調べる |
| 審査 | 審査役5人が、それぞれ別々に読んで採点する | 1つのチャットの中で、役を切り替えて審査する |
| 深い調査（imozuru） | 頼んだ時だけ使える | 使えない |
| 更新 | 起動した時に自動で取り込む | 自分でファイルを差し替える |
| 1社にかかる量 | 約140万トークン（Pro の5時間の枠の大きな部分） | 4〜5往復。無料版はメッセージの上限がきついので、1日1〜2社が目安 |

迷ったら、まず無料版で1社試して、もっと深くやりたくなったら有料版に移るのがおすすめです。経験DBはどちらでも同じものを使います。

## 0-2. 答えは「話して」入力するのがおすすめ
自分史インタビューもESのやりとりも、長い文章を打つより、話した方がずっと楽で、内容も深くなります。
| ツール | 使える所 | 料金 | ひとこと |
|---|---|---|---|
| Aqua Voice | Windows・Mac・iPhone | 最初の1,000語まで無料、その後は有料（月8ドル前後） | 日本語の精度が高い。話した内容を、そのまま文章として入力欄に入れてくれる |
| Speakly（Genspark） | Windows・Mac・iPhone・Android | Genspark のアカウントで使う（料金は公式ページで確認） | 言いよどみの削除や誤変換の修正もしてくれる |
| パソコンに最初から入っている音声入力 | Windows：Windows キー＋H ／ Mac：設定の「音声入力」をオンにして、ショートカットで起動 | 無料 | まずはこれで十分 |
| スマホのボイスメモの文字起こし | iPhone・Android | 無料 | 歩きながら話して、文字起こしを貼るだけ |
※ 料金や対応端末は変わることがあります。使う前に、各公式ページで確かめてください。

## 1. 無料版：自分史インタビューで「経験DB」を作る（ChatGPT）
ESの材料になる、あなたの経験のデータベースを作ります。無料版では、インタビューを ChatGPT で行います（Claude の使用量を、ES作成のために残しておくため）。**有料版の人は、この章は飛ばして、2-6 の `/jibunshi` で作ってください**（答えが自動でファイルに書き込まれるので、コピーも保存も要りません）。

0. 先に、3-1 の方法でファイル（ZIP）をダウンロードして開いておく。使うのは `free/ChatGPT用/` の4つ
1. ChatGPT で、新しいプロジェクトを1つ作る（プロジェクトが使えない時は、新しいチャット）
2. `free/ChatGPT用/指示.txt` の中身を全部コピーして、プロジェクトの「指示」に貼る。プロジェクトの「ファイル」に `資料1_インタビューの設計.md`・`資料2_ESの型.md`・`資料3_文章の仕上げ.md` を入れる（資料は、ESに必要な所を狙って深く聞くための設計図です。プロジェクトがない時は、チャットの最初に、指示と資料3つを貼る）
3. 新しいチャットで「始めて」と送る。最初に、その回の目標を一緒に決める（1回目は「ESを1本書ける状態にする」）。2回目からは、足りない所から次の目標を提案してくれる
4. 質問が3〜4問まとめて出てくるので、**音声入力（0-2）で話して、そのまま貼る**。荒くて大丈夫です。覚えていないことは「覚えてない」でOK
5. 区切りのいいところで「保存」と送ると、経験DBがまとめて出てくる。それを `経験DB.md` という名前のテキストファイルに保存する

注意
- 友だちやバイト先の実名は、AIが「ゼミの同期A」のように置き換えます。自分でも、気になる名前は伏せてください
- 経験DBはあなたの個人情報です。人に渡したり、公開したりしないでください

## 2. 有料版のセットアップ（Claude Code）

### 2-1. Claude の Pro プランに入る
Claude Code は、Pro・Max などの有料プランで使えます（無料プランでは使えません）。claude.ai で契約してください。

### 2-2. Claude Code を入れる
**Mac**：「ターミナル」アプリを開いて、次の1行を貼り付けて Enter。
```
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows**：先に [Git for Windows](https://git-scm.com/downloads/win) を入れてください（ES対策室の自動更新とダウンロードに使います）。そのあと「PowerShell」を開いて、次の1行を貼り付けて Enter。
```
irm https://claude.ai/install.ps1 | iex
```

入れ終わったら、ターミナルを開き直して `claude --version` と打ち、番号が出れば成功です。
ターミナルを使いたくない人は、Claude のデスクトップアプリ（[Mac](https://claude.ai/download)・Windows）からも Claude Code を使えます。

### 2-3. ES対策室をダウンロードする
ターミナルで、次の3行を1行ずつ貼って Enter。
```
cd ~
git clone https://github.com/so1705/sotaro-es-taisakushitsu.git
cd sotaro-es-taisakushitsu
```
Mac で「コマンドライン・デベロッパ・ツールをインストールしますか？」と出たら、「インストール」を押して、終わってからもう一度 2行目を貼ってください。

### 2-4. 経験DBについて
有料版では、起動したあと `/jibunshi` と打つと、Claude が質問して、答えを `経験DB` フォルダの中のファイル（エピソードごと・数字一覧など）に自動で書き込みます（2-6）。ChatGPT で作った `経験DB.md` がすでにある人は、`経験DB` フォルダに入れておけば、そこから続きを聞いてくれます。
（`経験DB` と `企業` のフォルダは、更新しても上書きされません。あなたのデータはそのまま残ります）

### 2-5. 起動して、ログインする
ターミナルで `sotaro-es-taisakushitsu` フォルダにいる状態で、
```
claude
```
と打ちます。初めての時はブラウザが開くので、Claude のアカウントでログインしてください。
次からは、ターミナルで `cd ~/sotaro-es-taisakushitsu` → `claude` で起動します。

### 2-5-2. ES対策室は、このフォルダの外を触りません
安心して使えるように、ES対策室は `sotaro-es-taisakushitsu` フォルダの中だけで動くように設定してあります（何もしなくてOK）。
- フォルダの外（デスクトップ・ダウンロード・ドキュメントなど）のファイルを読もうとすると、自動で止まります。読ませたいファイル（過去のES・経験DBなど）は、先にこのフォルダの中に入れてから頼んでください
- 「フォルダの外」のファイルやコマンドについて確認が出たら、よく分からない時は「いいえ」でOKです
- 深い調査の結果も、このフォルダの中の `research/` に保存されます

### 2-6. 経験DBを作る（/jibunshi）
Claude Code に `/jibunshi` と打ちます。棚卸し → 核のエピソードの深掘り → 価値観・原体験 → 志望の芯 → 企業との接点 …の順に、3〜4問ずつ質問が来ます。音声入力（0-2）で話して、そのまま送るだけでOK。途中でやめても、次に `/jibunshi` と打てば続きから再開します。

### 2-6-2. 最初のESを作る
Claude Code に、`/es` と打って、続けて【ES依頼】を貼って送ります（書き方は4章）。

```
/es
【ES依頼】
■企業名：〇〇
■コース・職種：
...
```

すると、次の順で進みます。チャットには、今どの工程かが1行ずつ出ます。
1. 企業リサーチ（公式ページ・決算・有価証券報告書の人材戦略・社員の声・業界の動き）
2. 構造分析：この会社が、このコースで、この設問を通して欲しがっている人物を、「求める要素」にまとめる
3. 素材の診断：あなたの経験DBで、何点くらいまで届きそうか
4. **骨子が出て、ここで1回だけ止まります**
   - 「この方向で」「ここはこうしたい」と返すか、「おまかせ」と返す
   - 80点未満の見込みの時は、経験を思い出すための質問が2〜3個つきます。答えられるものだけ答えればOK。「なし」でもそのまま進みます
5. 執筆 → 審査役5人×2周 → AIっぽさの除去 → 完成版

完成版と、なぜこう書いたか・面接で聞かれそうなことは、`企業/<企業名>/` フォルダに残ります。

### 2-7. ほかのコマンド
| コマンド | すること |
|---|---|
| `/es` ＋【ES依頼】 | 0から作る |
| `/es-review` ＋ 企業名・設問・字数・自分のES | 自分で書いたESを持ち込んで、今の点数を出し、審査役5人×2周で引き上げる |
| `/rally` | 1設問ずつ、やりとりしながら仕上げる（「ここをもっとこうしたい」など） |
| `/deep-dive` | 経験DBの浅いところを掘り直す（時間がある時に） |

### 2-8. 使用量について（大事）
- 1社を `/es` で作ると、約140万トークン使います。Pro プランだと、5時間の利用枠の大きな部分です
- **1回に1社ずつ**進めてください。何社も同時に始めると、途中で枠の上限に当たって止まります（止まっても、枠が戻れば続きから進められます）
- 会社を変える時は、`/clear` と打ってから次の会社を始めると、余計な使用量を減らせます
- 急ぐ時は、【ES依頼】の書き方メモに「軽く」と書くと、リサーチと審査を減らして、約半分の量で作ります
- 「この業界をもっと深く調べて」のように頼むと、深い調査の道具（imozuru）を使ってよいか聞かれます。1つの問いで約15〜20万トークン使うので、本命の会社や、大きく方向を変える時だけにしてください。PDFの資料も読ませたい時は、Mac なら `brew install poppler` で、PDFの文字を取り出す道具を入れておくと、より深く調べられます

### 2-9. 更新
中身を良くした版を、ときどき出します。Claude Code を起動した時に、前の確認から3日以上たっていれば、自動で取り込んで、何が変わったかを教えてくれます。
自動で取り込めなかったと言われた時は、`sotaro-es-taisakushitsu` フォルダで次を打ってください。
```
git pull
```

## 3. 無料版のセットアップ（Claude.ai）

### 3-1. ファイルを手に入れる
[GitHub のページ](https://github.com/so1705/sotaro-es-taisakushitsu) の緑の「Code」ボタン →「Download ZIP」でダウンロードして、開きます。使うのは `free/アップロード用/` の5つのファイルです。

### 3-2. プロジェクトを作る
1. claude.ai で「プロジェクト」→「新しいプロジェクト」。名前は「ES対策室」
2. プロジェクトの「指示」に、`プロジェクトの指示.txt` の中身を全部コピーして貼る
3. プロジェクトの「ファイル（ナレッジ）」に、次の5つを追加する
   - `手順_作成と審査.md`
   - `知識1_ESの考え方.md`
   - `知識2_型と業界.md`
   - `知識3_文章の仕上げ.md`
   - 1章で作った自分の `経験DB.md`

### 3-3. 最初のESを作る（チャットを分けて進める）
無料版では、**作る係と審査する係を、別のチャットに分けます**。同じチャットで、自分が書いたESを自分で審査すると、甘くなるからです。

**チャットA（作る係）**：プロジェクトの中で新しいチャットを開き、【ES依頼】を貼って送る
1. 1回目の返事：リサーチ → この会社が欲しい人 → 見込みの点数 → **骨子が出て止まる**
2. 「おまかせ」か、直したい方向を返す（質問がついていたら、答えられるものだけ答える）
3. 2回目の返事：ESの v1 と、ファイル「〇〇社.md」が出てくる
4. 「〇〇社.md」をダウンロードして、プロジェクトのファイルに追加する

**チャットB（審査する係）**：新しいチャットを開いて「〇〇社 審査」と送る
1. 1回目の返事：審査役5人分の審査 → 直した v2
2. 「続けて」と送ると、2回目の比べ直し → 完成版 → AIっぽさの除去
3. 最後に出てくる「経験DBへの追記」は、自分の `経験DB.md` に書き足して、プロジェクトのファイルを入れ替える

**その他のチャット**
| 送る言葉 | すること |
|---|---|
| 「〇〇社 ラリー」 | 1設問ずつ、やりとりしながら仕上げる |
| 「深掘り」 | 経験DBの浅いところを掘り直す |
| 「〇〇社 審査」＋自分のES・設問・字数 | 自分で書いたESを持ち込んで審査する |

### 3-4. 無料版のコツ
- 無料版はメッセージの上限がきついので、1回の返事でまとめて進むように作ってあります。途中で「続けて」以外の雑談をすると、上限に早く当たります
- 上限に当たったら、時間をおいてから同じチャットで「続けて」と送ってください
- 「もっと深く調べて」と頼んでも、有料版の深い調査（imozuru）は無料版では使えません。ふつうのリサーチの範囲で、足りないところを追加で調べます

### 3-5. 更新
新しい版が出ている時は、作る係のチャットの1回目の返事の最後で教えてくれます（気になる時は [GitHub のページ](https://github.com/so1705/sotaro-es-taisakushitsu) の `CHANGELOG.md` でも確かめられます）。新しい版が出ていたら、3-1 と同じようにダウンロードし直して、プロジェクトの指示と4つのファイルを入れ替えます（`経験DB.md` と「〇〇社.md」はそのままでOK）。ChatGPT のプロジェクトの指示と資料1〜3も、同じように入れ替えます。

## 4. 【ES依頼】の書き方
```
【ES依頼】
■企業名：
■コース・職種：
■種類：インターン／本選考
■募集ページURL：

■設問（1問ずつ）
Q1：
字数：
Q1の書き方メモ（任意）：
Q2：
字数：
Q2の書き方メモ（任意）：

■使いたいエピソード（任意）：
■全体の書き方メモ（任意）：
■備考（説明会・OB訪問で聞いた話、知ってることなど）：
```
- 設問は、文章のまま正確に貼ってください。設問の言葉づかいに、会社が見たいものが出ています
- 募集ページのURLがあれば必ず入れてください。インターンやコースの中身を調べる手がかりになります
- **備考は、ESの質を一番上げる欄です。** 説明会・OB訪問・インターンで聞いた話、社員の言葉、自分がその会社の商品やお店と関わった経験を、メモのままでいいので書いてください。設問の意図や、どんな人が通っているかは、ネットの公開情報ではほとんど分からないので、あなたが直接聞いた話が一番の材料になります
- 名前・大学名・連絡先は書かないでください

## 5. 困った時
| 困ったこと | どうするか |
|---|---|
| 骨子のところで止まった | 正常です。「おまかせ」か、直したい方向を返すと先に進みます |
| 質問に答えられない | 「なし」と返せばOK。今の経験DBの範囲で一番良い形で進めます |
| 【盛り提案】が出てきた | 経験の言い方や見せ方を強くする提案です。採用するかはあなたが決めます。採用したら、面接で聞かれた時の答え方も一緒に準備してください（面接ではESの中身を深掘りされます） |
| 字数が合っていない | 「字数を数え直して」と送ってください |
| 利用の上限に当たった | 時間をおいて、枠が戻ってから「続けて」と送ってください（有料版は5時間ごとに戻ります） |
| 有料版で `/es` が出てこない | `sotaro-es-taisakushitsu` フォルダの中で `claude` を起動しているか確かめてください |
| 経験DBを更新したい | 有料版は `/deep-dive`、無料版は「深掘り」チャット。ChatGPT のインタビューの続きをしてもOK |

## 6. 守ってほしいこと
- 経験DBと、作ったESは、あなたの個人情報です。人に渡したり、公開したりしないでください（有料版では、`経験DB/` と `企業/` のフォルダは GitHub に上がらない設定になっています）
- 完成版をそのまま出すのではなく、自分の言葉で話せるかを確かめてから提出してください。面接では、ESに書いたことを深く聞かれます
- この仕組みの中身（知識・手順）の再配布や販売はご遠慮ください
