## 2. エピソード

### E01 常連の店に、若い客を呼び戻した ［種類：力を入れたこと／強み］
- 概要：コロナ後に平日の客が戻らず、店の存続が危ぶまれていた。3か月分の手書き伝票をデータにして原因を探り、大将の反対を受けて提案を作り直し、常連が若い客を連れてくる仕組みをつくった。若い客が定着しない2つ目の課題も解決し、平日の客数を約1.5倍にした。
- 背景・始めた理由（線：価値観 → 動機）：大将に「この店も、あと2年もつかどうかだ」とこぼされた。祖父の酒屋が閉まった時と同じことが起きると思い、「料理も酒もいいのに、知られずに消えるのは絶対に嫌だ」と感じた
- 自分の役割・立場：アルバイト（ホール）。提案する権限はない立場
- 目標：平日の客数をコロナ前の水準に戻す
- 時期ごとの流れ：
  - 第1段階（大学2年4〜6月）：手書きの伝票3か月分（約1,800枚）をスマホで撮り、時間帯・人数・年代（伝票の注文内容から推定）・注文品をスプレッドシートにまとめた → 平日の客の8割が50代以上の常連。20代の客は全体の約5%で、ほぼ1杯目で帰っていた
  - 最初の提案：20代向けのSNS割引を大将に提案 → 「うちは常連さんの店だ。安売りで知らない客を呼んで、常連さんの居場所を壊したくない」と却下される
  - 考え直し：大将の言葉を何度も思い出し、常連の居心地の良さこそが店の価値で、同時に若い客が入りにくい理由にもなっていると気づく（逆説）。常連さんに、店に来ない理由ではなく「この店を誰に紹介したいか」を聞いて回った → 「孫や会社の若いのを連れてきたいが、自分の好きな店を気に入ってくれるか不安」という声が多かった
  - 第2の提案：常連さんが若い知り合いに1杯ごちそうできる「一杯おすそわけ券」（常連さんが買って渡す、1杯500円）。大将は「常連さんが主役なら」と了承
  - 第2段階（大学2年7〜12月）：若い客は来るようになったが、2回目に来ない。本人たちに聞くと「常連さんの輪に入れず、気まずかった」 → 大将と相談して、カウンターの端の1席を「はじめて席」にし、自分がそこを担当して、常連さんとの会話をつなぐ役になった
- 一番難しかったこと（型：逆説）：店の一番の価値である常連の居心地が、若い客を遠ざける原因でもあった。常連を守ることと、新しい客を呼ぶことが、正面からぶつかっていた
- 原因をどう突き止めたか：伝票のデータで「誰が来ていないか・いつ帰るか」まで分かったが、「なぜか」は分からなかった。常連さんと若い客の両方に直接話を聞いて、初めて分かった。最初は、データだけで原因が分かったと思い込んでいた
- 判断の分岐：①SNS割引で一気に若い客を集める ↔ 常連さん経由で少しずつ → 大将と常連の想いを守れる後者を選んだ（速さを捨てた）／②自分が若い客を集める ↔ 常連さんに主役になってもらう → 常連さんが連れてくる方が、若い客も常連さんの輪に入りやすいと考えた
- 人との関わり（セリフつき）：大将「うちは常連さんの店だ」→ のちに「お前の券、俺より常連さんに人気だな」。常連のAさん（70代）「孫に、じいちゃんの行きつけを見せたかったんだよ」。初めて来た20代の客「1人で来ても話しかけてもらえるなら、また来ます」
- 感情の変化：始めた時＝祖父の店を思い出して焦り／一番しんどい時＝最初の提案を却下され、「データは正しいのに」と悔しかった。何日か大将とぎこちなかった／終わった時＝Aさんが孫と来た日に、大将が初めて自分に礼を言った
- 結果：平日の1日平均客数 約18人 → 約27人（約1.5倍、半年）。20代の客の割合 約5% → 約22%。おすそわけ券は半年で約300枚。「はじめて席」から来た客の再来店率は約4割
- 失敗・やり直し：最初の提案の却下。データだけで答えが分かると思っていた
- 周りの反応：大将が、券の仕組みを近所の店主たちに話すようになった（→ E02 につながる）
- 学び → 今の行動原理：データで分かるのは「何が起きているか」まで。「なぜか」は、相手の立場に立って話を聞かないと分からない。それ以来、数字を見たら、必ず当事者に1人は話を聞くようにしている（ゼミの分析でも、アンケートの前に必ず数人に話を聞く）
- 似た動きをした他の経験（線：行動のパターン）：中2の文化祭（人の流れを数えて呼び込みを変えた）、高校の配球ノート（データで勝ち筋を探した）。どれも「数えて、仕組みで、埋もれたものを届ける」
- その後にやりたくなったこと：この仕組みを他の店でも使えないか → E02
- 使える数字：伝票約1,800枚（3か月分）・平日客数 約18→27人（約1.5倍）・20代の割合 約5→22%・券 約300枚・はじめて席からの再来店率 約4割（すべて概算、本人の記録ベース）
- 盛ってはいけない情報：売上の金額は正確に把握していない（大将の管理）。「店を救った」とは言わない（店の存続はまだ分からない）
- 面接で聞かれそうな質問と答え：年代をどうやって推定した？→ 注文内容（ボトルキープ・日本酒は常連、サワーは若年層）と、自分の接客の記憶で照らし合わせた。精度は高くないと正直に言う／大将の反対の時どう思った？→ 悔しかったが、大将が40年守ってきたものを自分は数字でしか見ていなかったと気づいた
- 本人の言葉（そのまま）：「データは正しかったけど、答えではなかった」「常連さんの店のまま、若い人が入れる店にしたかった」
- まだ浅いところ：なし

### E02 同じ仕組みを、別の店で試して失敗した ［種類：挫折・失敗］
- 概要：大将の紹介で、友人が営む近所の焼き鳥屋に「おすそわけ券」を導入した。3か月でほぼ使われず、やめることになった
- 原因：その店は常連同士のつながりが薄く、一人客が多かった。券は「常連さんが誰かを連れてきたい店」だから機能していた。仕組みだけを移しても、店ごとの関係性が違うと再現できなかった
- 感情：自分の仕組みが通用すると思っていたので、恥ずかしかった。焼き鳥屋の店主に謝りに行った
- 学び：うまくいった理由を、自分の店の条件と切り分けて説明できていなかった。1店舗で成功させることと、それを他の店に広げることは別の力が要る
- 今：ゼミで、うまくいった施策の「どの条件が効いたか」を分解する練習をしている
- 使える数字：導入期間3か月、使われた券は10枚未満（概算）
- まだ浅いところ：店主に謝りに行った時の会話

### E03 高校野球部の配球ノート ［種類：挫折／チーム］
- 正捕手争いに負けてベンチへ。1か月ほど練習に身が入らなかったが、「試合に出なくても勝ちに関われることはある」と、相手投手の配球を記録する係を自分から始めた。1年分で約60試合を記録。3年夏の地区予選で、監督に「お前のノートで配球が読めた」と言われ、チームはベスト8
- 学び：自分の役割が変わっても、勝ちに関わる方法は自分で作れる

### E04 中学の文化祭の駄菓子屋 ［種類：原体験・小さな成功］
- 初日、教室の奥の店にほぼ客が来なかった。廊下で10分ごとに人の流れを数え、人が一番多い階段の前に呼び込み役を置き、時間帯を絞った。2日目は完売

## 4. 小さなエピソード集
1. 店の常連さん30人以上の「いつもの一杯」を覚えている
2. 大将の手書きのおすすめ黒板を、写真に撮ってSNSに載せることだけは許してもらえた
3. 苦手：大人数の前で話すのは緊張する。だから、話す前に必ず紙に3行で書く
4. 失敗：最初の提案を、大将の気持ちを考えずに数字だけで押し通そうとした
5. 実家の近くの、閉店した商店のシャッターの数を、毎年帰省のたびに数えている
6. 野球部の配球ノートは、引退後に後輩に引き継いだ
7. 友人からは「話をちゃんと最後まで聞くやつ」と言われる
8. 苦手：最初の一歩が遅い。調べすぎてしまう
9. 祖父の酒屋の前掛けを、今もバイトで使っている
10. 文化祭の駄菓子屋で、売上より「客がどこから来たか」をメモしていた
