# 型ライブラリ（v1 / 2026-10-20）

**ここにある型は評価基準ではない。** 本人の書きたい内容と特性に合わせて、設問ごとに1つ選ぶための引き出し。評価基準（A〜F＋企業固有）は増やさず、型の選び方で質を上げる。

## 0. 塾講師として、本当に外せない核（7つ）
型は何を選んでもいい。ただし、次の7つはどの型にも入れる。これ以外は選択肢。
1. **1本の線**：原体験 → 価値観 → 行動のパターン → やりたいこと（05）
2. **判断の分岐**：捨てた選択肢と、捨てた理由
3. **利害の違う人を、相手の要望を組み込んで動かした場面**（10の3）
4. **原因をどう突き止めたか**（最初に思った原因と、本当の原因の違い）
5. **本人の言葉**：セリフ・口癖・比喩のどれか1つ
6. **会社にしかない事実を1つ**（志望系の設問）
7. **面接で深掘りされる核**：わざと残すフックと、経験DBで答えられる裏づけ

「結論から書く」「数字を使う」は前提であって、差がつく要素ではない（00）。

### 設問が複数ある時（丸紅の検証で分かったこと）
- **設問ごとに役割を分ける**：同じ話・同じ言葉（「仲間の夢を重ねる」など）を3問で繰り返すと、薄く見える。例：原動力＝原体験と1つの場面／ガクチカ＝事業の話／志望＝足りないもの → その会社
- **会社の事実は、本人の線と同じ文脈で入れる**：事業の事実（投資額・戦略）を足すと「なぜ当社か」は具体的になるが、原動力とのつながりが切れやすい。その会社にしかない核の言葉（例：強みだけでなく人の志まで掛け合わせる）を、本人の原動力と同じ言葉で受け止めてから、事実を添える

## 2. ガクチカ・困難を乗り越えた経験
**G-a 6段の基本形**（外部：unistyle）
結論（何に取り組んだか）→ 動機（なぜ取り組んだか。価値観とつなげる）→ 目標と困難 → 取り組みと結果（工夫と数字）→ 人柄（行動の裏の姿勢）→ 学びと、社会での活かし方
- 弱い例：結果だけで工夫がない／「多くを学んだ」だけ／1つのエピソードに要素を詰め込みすぎ

**G-b 逆説型**（通過ES）
良い状態（雰囲気が良い・常連の居心地が良い）が、逆に課題を難しくしていた → 両方を立てる解決策
- 強いところ：難しさの構造が、読み手にすぐ伝わる

**G-c 却下 → 作り直し型**（通過ES・居酒屋デモ）
最初の案 → 却下（相手のセリフ）→ 自分の見落としに気づく（本人の言葉）→ 相手の要望を組み込んで作り直す → 了承 → 結果
- 強いところ：素直さと変化への対応（多くの会社が公式に求める資質）が、そのまま見える

**G-d 2段階の変化型**（通過ES）
施策1で伸びた → 新しい課題（定着しない・続かない）→ 原因を突き止め直す → 理念は守りつつ調整 → 結果

**G-e キーマンを口説く型**（通過ES・伊藤忠）
全体への呼びかけという従来の手法を捨てる → キーマンを1人ずつ、相手の動機に直結する言葉で口説く → 断られても続ける → 自走する体制

**G-f 5分割型**（設問の形式。10の4）
30字の見出し（動詞＋成果）／背景・目的／目標（チーム＋個人。個人に経営の視点）／課題とアクション／結果（数字＋持続性）

**G-g 研究型**（通過ES・トヨタ）
研究の目的（社会で何に役立つか）→ なぜ今まで分からなかったか → 自分の手法 → 分かったこと → 苦労と工夫（構造的に考えて、条件を絞った）→ 次の課題。専門外の人に平易に

## 3. 自己PR・強み
**P-a 基本形**（外部：unistyle）
強み → 原点（その強みができた経験）→ 具体的なエピソード → 方法論（どうやって発揮するか）→ 入社後の活かし方

**P-b 複数エピソードで再現性**（外部：unistyle・通過ES）
強みを、別の時期の2〜3の場面で示す（06 発見2）。数字や第三者の評価など、客観的な成果を入れる

**P-c 自分らしい言い方**（通過ES）
「全力でおせっかいを焼いてしまう人間」のように、能力名ではなく、人柄が見える言い方で強みを言う → エピソード → 相手の反応・感謝の言葉 → 仕事で

**P-d 長所と短所の裏表**（通過ES）
長所と短所を、同じ性質の裏表で（06 発見11）。短所には、今やっている対策を具体的に

## 4. 志望動機・なぜ当社か
**M-a 夢 → 原体験 → 手段**（通過ES）
将来の夢（一言）→ それを持つようになった経験 → これまでの取り組み → まだ足りないもの → その会社でなければならない理由 → 入社後

**M-b 6要素で絞り込む**（外部：unistyle）
成し遂げたいこと → きっかけの経験 → 企業選びの軸 → 他の業界を選ばない理由 → 具体的に取り組みたい仕事 → 同業他社の中でその会社を選ぶ理由
- 同業比較から考え始めると論理が崩れやすい。大枠から順に絞る（09の2の競合比較表は、最後の要素に使う）

**M-c 現場で会った人・場面**（外部：外資就活／通過ES）
OB訪問・インターン・説明会で、実際に心を動かされた人や場面を具体的に → 自分の価値観との重なり。実体験がないと薄くなるので、経験DBの「企業・業界との接点」がある時だけ使う

**M-d 課題指摘型**（通過ES：総合商社・小売）
業界やその会社の課題を、自分の切り口で1つ指摘する → 自分の経験・専門で、どう解きたいか（例：総合商社が市場から評価されにくい課題を、財務と投資家への発信から）

**M-e 部署・部門の市場構造型**（通過ES：丸紅）
その商材や部門の市場の構造（地政学・需給・価格の変動・規制）→ その環境で求められる力 → 自分の強みとの一致

### 総合商社の志望で使えるパターン（外部：unistyle。塾講師の注意つき）
新しいビジネスを生み出したい／価値観の違うメンバーと1つの目標を達成したい／日本のプレゼンスを高めたい／途上国の発展に貢献したい／特定分野の川上から川下まで関わりたい
- 「日本のプレゼンス」「途上国の発展」は、短い旅行などの浅い経験だと差がつかない（外部の指摘どおり）
- 五大商社の自己PRの約6割が「立場の違う人と協力して成果」「リーダーシップ」系統という集計がある（外部）。同じ系統で書くなら、10の3の具体性（相手の要望を組み込む・キーマンを口説く）がないと埋もれる
- 「グローバル」「幅広い事業」は、定番すぎて響かない（外部：外資就活の指摘）

## 5. 原動力・価値観
**V-a 対の気づき**（通過ES：丸紅）
原動力を一言 → 原体験 → 対になる気づき（勝ちは向上心に、負けは執着心に）→ だからどんな場面で力が出るか

**V-b 他人の言葉から**（通過ES）
身近な人の口癖・言葉 → それが自分にしみ込んだ過程 → 今の行動の変化

**V-c 弱さを認めた**（通過ES）
一人で抱え込んだ・助けを求められなかった → 気づき（人を頼ることは成長のための選択）→ 今のやり方

## 6. 自己分析の型（経験DBを作る側で使う）
- **ファクト → 抽象化 → 転用**（外部：『メモの魔力』の紹介記事）：具体的なエピソード → 共通する原理 → 他の場面でどう生きるか。05の「行動のパターン」を見つける時に使う
- **得意・需要・好き**（外部：『絶対内定』の紹介記事）：強みを、得意なこと・人から求められること・好きなことの重なりで見つける。自分史インタビュアーのレベル2の横断のまとめで使う

08の6を参照（行動指針から選ぶ・ハッシュタグ・取扱説明書・割合・単語の作文・企画・自分史・キャッチフレーズ）。

# 【08_設問タイプ別の型】

# 設問タイプ別の型（v1 / 2026-10-20）

通過ES・内定者ES 約30本（コンサル・金融・総合商社・デベロッパー・メーカー・IT・航空・エンタメ・小売・化粧品）を、設問の種類ごとに分けて、強い型と弱い型を抽出した。本文は載せず、型と判定だけを記録する。通過していても弱いESは多い（06 発見7）ので、「通過した」ではなく「要素が強い」ものを型にした。

## 1. 志望動機・志望理由
**強い型**：人生の目標・夢（一言）→ それを持つようになった原体験 → なぜこの業界か → **なぜこの会社か（その会社にしかない具体名）** → 入社後に何をするか（部署・商材・地域・年次まで）
- 会社固有の具体名が入っている：開発思想の名前と具体的な地名（デベロッパー）、主力の技術基盤の名前とその特性（IT）、事業の種類と担当したい地域（海運）、自社商品の具体名と販売先の地域と健康課題（食品メーカー）
- 入社後の具体性：10年後・20年後のキャリアの段階、2年以内に店長、その後に売場づくり、のように時間軸がある
- 「自分の夢 → この会社の手段」の順で書き、「会社の説明 → 共感」の順にしない
- 本人の注意点にも「業界 → 企業 → 職種の順」「なぜ資産運用か → なぜこの会社か → どう貢献するか」「なぜこの会社か → その中でなぜこの部門か → そこで何をしたいか」と、**絞り込みの順番**を意識した記述が繰り返し出てくる

**弱い型**（通過していても、要素は弱い）
- 理念・パーパスへの共感だけ／「多様な事業」「グローバル」「社会への影響力」など、どの会社にも言える言葉
- 「持続可能な社会」「技術革新」を並べた、抽象度の高い文章（AIっぽさも強い）

## 2. インターン・コース・部門・職種の志望理由（Q2型）
**強い型**：なぜその領域か → **その会社のそのインターン（部門）で、具体的に何をするのか** → 自分の経験の何がつながるか → 何が足りず、何を確かめたい／得たいか → どう貢献するか
- インターンや説明会に参加した後なら、**現場で見たもの・聞いたことを1つ具体的に**書き、挑戦したい業務を具体名で挙げる（航空：インターンで見た困難な場面への社員の対応 → 挑戦したい業務を2つ具体的に）
- 部門を選ぶ理由は、その部門の事業の構造（市場の課題・その会社の立ち位置・使える資源）まで踏み込む（EC：国内のEC化の遅れ → 中小企業の課題 → その会社の市場シェアとポイント経済圏）
- 希望分野ごとに理由を書き分ける。「まだ決めきれないので、社員の方に業務を伺って見極めたい」という正直な書き方も、理由があれば通る（IT）
- 必要なリサーチ：インターン・部門の中身（テーマ・期間・成果物・社員の関わり）、その事業の今（伸びている所・課題）、過去の参加者の声

**弱い型**：会社の一般的な魅力（若手の裁量・成長環境）だけで、インターンの中身に触れていない

## 3. ガクチカ・最も力を入れたこと・困難を乗り越えた経験
**強い型**：想い・目標 → 課題（数字で）→ **原因をどう突き止めたか**（面談・アンケート・データ・フィードバック）→ 施策2〜3（頻度・期間・量まで具体的）→ 結果（数字）→ 学び
- 2段階の変化：施策で伸びた → 新しい課題（定着率など）→ 原因を突き止め直す → 理念は守りつつ活動を調整、の流れは特に強い
- 施策の具体性：週2日×2時間×1か月、毎週最初の30分を勉強の時間にする、役割を新設する、など
- 想いを最初に置く：「全員が本気で喜べる勝利を」「このステージに立つのが憧れだったという言葉に、成功させたいと思った」
- 他の人のセリフが1つ入ると、場面が立つ

**弱い型**：「リーダーシップとプロジェクトマネジメントのスキルを培った」のような、能力名だけで終わる学び

## 4. 自己PR・強み
**強い型**：自分らしい言い方の強み（例：「全力でおせっかいを焼いてしまう人間」）→ それが出たエピソード（想い → 施策2つ → 相手の反応・感謝の言葉）→ 仕事でどう使うか
- 強みを3つ求められた時は、それぞれ別の場面で示す
- 長所は「具体的な行動と数字」、短所は「強みの裏返し＋今やっている対策」（例：責任を抱え込みやすい → 事実と仮説を分けて整理し、一定時間で解決しなければ早めに共有する）

## 5. 価値観・人生に影響を与えた出来事
**強い型**：出来事（家族の病気、役職で一人で抱え込んだ経験、友人の口癖）→ その時の気づき → 今の行動の変化
- 他人の言葉から価値観が生まれた話（友人の「お互い様だから」）は、本人らしさが出やすい
- 弱さを認めた話（助けを求めるのが恥ずかしかった → 人を頼ることは成長のための選択）は、素直さとして評価されやすい

## 6. 変わった形式の設問
| 形式 | 強い答え方 |
|---|---|
| 行動指針から1つ選ぶ | 選んだ言葉の意味を、自分の失敗経験（相手を一方的に判断していた → 対話で背景を知った）で裏づける |
| ハッシュタグ×3 | 30字の中に動詞を入れ（想像し尽くす・揺さぶる・つなぐ）、理由でそれぞれ別の場面を示す |
| 取扱説明書 | 特徴（エピソード）＋注意事項（弱み）＋「こう声をかけてくれると力を発揮する」まで書く。少しのユーモアは可 |
| 自分を表す要素と割合 | 比重をつけて、大事な順に並べる。割合の小さい要素で、日常の小さなこだわりを見せる |
| 単語を使った自由作文 | 物語にしながら、最後に自分の価値観（変わらない価値を守る、など）に着地させる |
| 商品の企画・売り方のアイデア | テーマ／商品／時期／ターゲット／販売場所／背景（市場の数字）／内容、と項目立てで構造化する |
| 時期ごとの自分史・影響の大きい順のエピソード | 時期ごとに1行で、役割と気持ちの変化を入れる（06 発見8） |
| キャッチフレーズ | 比喩＋補足で、どんな時に発揮されるかを書く（「チームの心の火付け役」→ 劣勢の時こそ） |

## 7. 本人たちの「注意した点」から分かる書き方
- 書類選考を通ることではなく、**面接でどう聞かれても答えられるエピソード**にする。深掘りしてほしい部分に興味を持たせる（00 原則1）
- そのエピソードを知らない人に読んでもらい、分かりにくい部分を指摘してもらう
- やったことの羅列ではなく、**なぜそれをやったか**と、**その時の感情**を書く
- 他の就活生と被らないエピソードを選ぶ（06 発見9）
- 字数が少ない時は、**絶対に入れたい言葉を先に決めてから**書く
- 業界 → 企業 → 職種の順に絞り込み、他社との比較で「なぜこの会社か」を言えるようにする
- 制限字数ぎりぎりまで書く。誤字・ブランド名の表記（大文字小文字・空白・英語かカタカナか）まで確認する

# 【05_線の設計図】

# 線の設計図：ESに必要な要素から、深掘りを逆算する

自分史インタビュー（ChatGPT）と、深掘りチャット（Claude）の両方がこのファイルを使う。
v1（2026-10-19）。根拠は 04_一次情報 と、公開されている通過ESの断片。通過ES30本での検証はまだ（下の「検証待ち」を参照）。

## 1. 一番大事な考え方：ESは1本の線の切り取り
良いESは、設問ごとに別々の話をしていない。1人の人間を貫く1本の線があって、設問ごとにその線の別の区間を見せている。

```
原体験 → 価値観 → 動機 → 行動のパターン → 強み・弱み → やりたいこと → 志望の軸
(小〜高)  (何を大事に) (なぜ始めた) (何度も出る動き)  (その裏表)  (これから)  (なぜこの会社)
```

| 設問 | 線のどの区間を見せるか |
|---|---|
| ガクチカ | 動機 → 行動のパターン → 強み（＋学び → 今の行動原理） |
| 自己PR | 強み → それが形づくられた原体験 → 別の場面での再現 → 入社後 |
| 志望動機 | 原体験 → 価値観 → やりたいこと → なぜ業界 → なぜこの会社 → 入社後 |
| 挫折・失敗 | 弱み → その場面 → 立て直し → 今の行動原理（強みとの裏表） |
| 大切にしている価値観 | 原体験 → 価値観 → それで判断した場面（迷った選択肢つき） |
| チームでの役割 | 行動のパターン → 他の人との関係の中での発揮 → 他の人の変化 |
| 将来像・挑戦したいこと | やりたいこと → その根拠の経験 → この会社の手段 |
| 自己紹介・あなたを一言で | 線の全体を、1〜2文に圧縮したもの |

→ だから、深掘りで「点」（1つのエピソードの事実）だけを集めても、ESは書けない。**点と点のつながり（なぜそれを始めたのか、前にも同じことをしたか、それが次に何につながったか）**を聞かないと、線にならない。

## 2. 線をつなぐための質問（どのエピソードでも必ず聞く）
| つなぐ区間 | 質問 |
|---|---|
| 価値観 → 動機 | それを始めると決めた日、何があった？他にも選択肢があった中でそれを選んだ時、何を考えてた？ |
| 原体験 → 価値観 | それを大事にするようになったきっかけの場面を1つ教えて。いつ、誰と、何があった？ |
| エピソード → パターン | 前にも同じような動き方をしたことある？逆に、しなかった時は？ |
| 強み ↔ 弱み | その強みが裏目に出た時のことを1回だけ教えて。その時どうなった？ |
| 経験 → やりたいこと | その経験の後、次に何をしたくなった？実際に何かした？ |
| やりたいこと → 志望の軸 | それを一生の仕事にするなら、どんな環境が必要？ |

聞き方は、知識13の4章「聞き方の決まり」に従う（一度きりの場面を選ばせる・「なぜ」ではなく「どうやって／何を」で聞く・誘導しない・ほめない・「ない」は1回で受け入れる）。研究の根拠は04。

## 3. 線の点検表（レベル2・3と深掘りモードの最後に必ず作る）
```
| 区間 | 中身（本人の言葉） | 根拠のエピソード | 状態 |
| 原体験 | | | ある／弱い／ない |
| 価値観 | | | |
| 動機 | | | |
| 行動のパターン | | E番号が2つ以上 | |
| 強み | | | |
| 弱み | | | |
| やりたいこと | | | |
| 志望の軸 | | | |
```
- 「行動のパターン」は、エピソードが2つ以上ないと「ある」にしない（1回だけなら偶然かもしれない）。
- 「弱い」「ない」の区間が、次の深掘りの対象になる。

## 4. エピソード1つの深さ（点の深さ）
自分史インタビュアーの「完了の基準」と同じ。判断の分岐2つ以上／セリフ3つ以上／感情3時点／数字の確度／なぜを3段／失敗・やり直し／行動原理を場面つきで。

## 5. レベルごとに、何を完成させるか
| レベル | 点 | 線 |
|---|---|---|
| 1 | 3エピソードを、完了の基準まで | 各エピソードで「なんで始めた？」と「今につながっていること」だけ聞く |
| 2 | ＋チーム・価値観・サブ2〜3個 | 線の点検表を作る。「行動のパターン」と「強み↔弱み」を「ある」にする |
| 3 | ＋メインの経験を時期ごとに。面接での深掘りへの回答 | 線の全区間を「ある」にする。原体験（小〜高）と志望の軸まで閉じる |
| 深掘りモード | ES作成中に浅いと分かった点 | ES作成中に途切れた区間 |

## 6. 検証
- 通過ES13本で確かめた（`06_通過ES分析.md`）。企業自身が線を設問にしていること、強いESは行動のパターンを複数の時期で示していることを確認した。
- 次の検証：利用者の通過ES・落選ES（本人の同意を取ったもの）を集めて、落ちたESにないものを特定する。就活サイトのコンテンツは、規約上、配布するプロダクトのための一括取得はしない。
