# 【00_本質原則】

# ESの本質原則

「結論ファースト」「数字を使う」「構造的に」は前提であって差別化にはならない。27卒では8割以上がAIでESを書いており、文章の巧拙では差がつかなくなった。差がつくのは以下。

## 1. ESは面接の予告編
- 面接官はESを見て質問を作る。ESの役割は「通過」と「面接で戦いたい土俵に誘導すること」の2つ。
- 全部を書き切らない。「なぜそう判断したのか」を聞きたくなる一文を、わざと1か所残す（例：「あえて〇〇はやめた」）。
- 逆に、聞かれたら困ることは書かない。面接で3段深掘りされても答えられない文は、ESの中で一番危ない文。

## 2. 評価されるのは「能力」ではなく「判断」
- 「主体性を発揮した」は誰でも書ける。書けないのは「AとBで迷い、〇〇だからBを選び、Aを捨てた」という分岐。
- 判断の分岐（捨てた選択肢と捨てた理由）が1つ入るだけで、ESは「その人にしか書けない文章」になる。
- 採用側は「入社後、同じ判断を自社の現場でしてくれるか」を想像している。

## 3. 成果の大きさより「難しさの説明」
- 小さい成果でも、なぜ難しかったかを構造で説明できれば評価される。難しさの型は3つ：
  - 利害の対立（立場の違う人が同じ方向を向いていない）
  - 資源の制約（時間・人・お金・権限がない）
  - 不確実性（正解がない、前例がない）
- 「大変だった」は感想。どの型の難しさかを書いて初めて、読み手が難易度を測れる。

## 4. 最初の2文で「誰か」が決まる
- 1枚にかけられる時間は短い。冒頭で何の話かが分かることが大事。（2026-10-20 改訂：以前の「冒頭2文に固有名詞・数字・意外性を入れる」は根拠が弱いので任意にする。通過ESの多くは「私の強みは〜です」のように普通に始まる）
- 冒頭には「固有名詞・数字・意外性」のどれか1つを入れる。「私の強みは〇〇力です」で始まる文章は、その時点で100枚の中に埋もれる。

## 5. 強みは企業の言葉に「翻訳」する
- 自分の言葉の強み（例：粘り強さ）を、その会社の行動指針・バリュー・社員インタビューに出てくる動詞に対応づける。
- ただし、企業の言葉をそのまま書き写すのは逆効果（媚びに見える）。エピソードの行動で見せて、言葉は1回だけ寄せる。

## 6. ES全体で人物像を1つにする
- 設問ごとに別の強みを書くと、人物像がぼやける。全設問を通して「この人は〇〇な人」と一文で言える状態にする。
- 設問ごとの役割分担：
  - ガクチカ＝行動の特性（どう動く人か）
  - 自己PR＝再現性（別の場面でも同じように動けるか）
  - 志望動機＝未来（その特性をこの会社で何に使うか）
  - 挫折＝自己認識（自分の弱さをどう扱う人か）

## 7. 志望動機は「原体験 × その会社にしかない手段」
- 理念への共感や、商品が好きという理由では差がつかない（全員が書く）。
- 「なぜこの会社か」は、会社の説明ではなく手段の違いで語る。事業の構造・業界内の立ち位置・持っている資産（顧客基盤・技術・拠点・データ）のうち、同業他社にないものを、自分のやりたいことの手段として選んだ、と書く。
- 「他社ではだめな理由」を、他社を下げずに書けるかが分かれ目。

## 8. 学びは、素直に書けばいい（2026-10-20 改訂）
- 通過ES・内定者ES 約55本の締めは、ほとんどが「この経験から〜を学んだ」「〜の大切さを学んだ」「〜力を培った」という素直な書き方だった。
- 以前このファイルにあった「学びは『以来〜している』という行動原理に変える」は、通過ESの分析より前に書いた根拠のないルールだったので撤回する。「〜するようになったのは、この時からです」のような締めは、上から目線で回りくどく読まれやすい。
- 学びの中身が、その会社の仕事で生きることが分かれば十分。

## 9. チーム成果は「自分の分」を切り出す
- 「チームで〇〇を達成した」だけだと、本人の貢献が見えない。
- 自分がいなかったら何が起きなかったか、を一文で書く。主語が「私たち」のままの文が続いたら危ない。

## 10. 数字には「比較の基準」をつける
- 「売上120%」より「前年比120%（過去5年で最高）」。母数・比較対象・期間がない数字は、読み手が評価できない。
- 表現や数字の見せ方を強くする「盛り」は、ESに必要な工夫。ただし、本人が面接で同じように話せないと崩れる。だから、盛りは必ず本人に提案して、本人が決める（07_文体と盛り）。

## 11. インターンESと本選考ESは別物
- インターンでは、完成度よりも伸びしろ・学習意欲・その仕事への仮説を見ている。
- 「インターンで何を得たいか」は「成長したい」ではなく、「〇〇という仮説を、△△の場面で確かめたい」の形にすると強い。
- 本選考では入社後の具体像（配属・職種・最初の3年）まで求められる。

## 12. 字数ごとの設計
- 200字：1エピソード・1論点。判断の分岐は1つだけ。
- 400字：判断を1つ深く掘る（なぜその判断か、どう周りを動かしたか）。
- 600〜800字：変化を2段階で書く（最初のやり方が失敗し、やり方を変えた）。
- 指定字数の9割未満は「意欲が低い」と読まれやすい。

## 13. AIで書いたことを隠すより、AIっぽさを消す
- AI文章の特徴：抽象語の連続、どこかで見た言い回し、感情と固有名詞の欠落、きれいすぎる三段構成。
- 消し方：その場のセリフ、その時の感情、固有の場所・人の役割、迷った瞬間を入れる。これらはAIには書けず、経験DBにしかない。

# 【01_設問の裏読み】

# 設問の裏読み

設問の文面と、採用側が本当に知りたいことは違う。書く前に「裏の問い」と「この設問で落とされる人」を確認する。

| 設問 | 裏の問い | 落とされる人 |
|---|---|---|
| 学生時代に力を入れたこと | 困難にぶつかったとき、どう考えてどう動く人か | 成果の自慢だけで、判断の過程がない |
| 自己PR | その強みは別の場面でも再現されるか | 強みの宣言とエピソードが1つだけで、再現性がない |
| 志望動機 | うちでなければならない理由があるか。入社後に続くか | 業界の説明か理念への共感で終わり、他社名に差し替えても通じる |
| 挫折・失敗経験 | 自分の弱さを直視して、行動を変えられる人か | 実は成功談。または他人や環境のせい |
| チームでの役割 | 自分を客観視できているか | 「リーダーとして」と肩書きを言うだけで、他の人との関係が書かれていない |
| あなたを一言で／キャッチコピー | 自分を短く要約する力、相手の記憶に残す工夫 | 抽象的な形容詞だけ（例：努力家） |
| 当社で挑戦したいこと | 事業をどこまで理解しているか、入社後の像があるか | 会社がもう発表していることをなぞるだけ |
| 10年後どうなっていたいか | キャリアの軸があるか。会社の育成方針と合うか | 役職名だけ（例：管理職になりたい） |
| 大切にしている価値観 | 判断の基準。社風と合うか | 価値観の説明だけで、それに従って判断した場面がない |
| 周りからどんな人と言われるか | 自己評価と他者評価のズレを把握しているか | 自己PRの言い換えで、他者の具体的な言葉がない |
| 最近気になったニュース | 情報感度と、自分の頭での解釈 | ニュースの要約で終わる |
| インターンに応募した理由 | その仕事への仮説と学習意欲 | 「成長したい」「業界理解を深めたい」だけ |
| インターンで得たいこと | 何を確かめに来るのか | 受け身（教えてもらう前提） |
| 自由記述・写真で自己紹介 | 指示がない中での発想力と編集力 | 他の設問の焼き直し |
| 研究内容（理系） | 専門外の人に伝える力、研究の意義を自分で語れるか | 専門用語のまま。研究の目的と自分の工夫が分かれていない |

## 複数の設問があるとき
- 設問の並び順を見る。前の設問で書いたことを、後の設問で前提として使える。
- 同じエピソードを2つの設問で使ってもよいが、切り口（行動の特性／再現性）を変える。
- 字数の少ない設問は、ES全体の人物像を一文で伝える場所として使う。

# 【03_落ちるES】

# 落ちるES：判定チェックリスト

1つでも当てはまれば指摘する。上ほど致命的。

## 致命的（これだけで落ちる）
- [ ] 他社名・他社の事業が混じっている
- [ ] 本人が承認していない新しい経験・数字がある（盛りは【盛り提案】として本人に出し、承認されたものだけ使う）
- [ ] 設問に答えていない（聞かれたことと別の話をしている）
- [ ] 指定字数の9割未満、または超過

## 埋もれる（通過ラインの下で横並びになる）
- [ ] 社名を他社に差し替えても通じる志望動機
- [ ] 冒頭を読んでも、何の話か分からない
- [ ] 判断の分岐（迷った選択肢と捨てた理由）がない
- [ ] 難しさが「大変だった」で終わっていて、どういう難しさか分からない
- [ ] 主語が「私たち」のままで、自分の貢献が切り出されていない
- [ ] 数字に比較の基準（前年比・母数・期間）がない
- [ ] 設問ごとに別の強みを書いていて、人物像が1つにまとまらない

## 面接で崩れる
- [ ] 「なぜ？」と3回聞かれたら答えられない文がある
- [ ] 本人が普段使わない言葉（難しい言い回し・ビジネス用語）が多い
- [ ] エピソードに登場する他の人の名前・役割・セリフが一つもない

## 不自然な日本語（07_文体と盛り の3）
- [ ] 口語（潰す・張りつく・〜してくれません）が混じっている
- [ ] 「〜ではなく〜」が1設問に2回以上ある
- [ ] 「・」でつないだ名詞が3つ以上、または1文に数字が3つ以上ある
- [ ] です・ます調とだ・である調が混ざっている

## AIっぽさ
- [ ] 抽象語が2つ以上続く（例：主体性と協調性を発揮し）
- [ ] よく見る言い回し：「〜という経験を通じて」「〜の重要性を痛感しました」「〜に貢献したいと考えております」
- [ ] 感情の描写が一つもない
- [ ] 三段構成がきれいすぎて、迷った跡や失敗が見えない

## 判定の出し方
- 致命的が1つでもあれば「落とす」
- 埋もれるが3つ以上なら「保留」
- それ以外は「呼ぶ」。ただし「面接で崩れる」がある場合は、面接でここを突かれると注記する

# 【05_線の設計図】

# 線の設計図：ESに必要な要素から、深掘りを逆算する

自分史インタビュー（ChatGPT）と、深掘りチャット（Claude）の両方がこのファイルを使う。
v1（2026-10-19）。根拠は 04_一次情報 と、公開されている通過ESの断片。通過ES30本での検証はまだ（下の「検証待ち」を参照）。

## 1. 一番大事な考え方：ESは1本の線の切り取り
良いESは、設問ごとに別々の話をしていない。1人の人間を貫く1本の線があって、設問ごとにその線の別の区間を見せている。

```
原体験 → 価値観 → 動機 → 行動のパターン → 強み・弱み → やりたいこと → 志望の軸
(小〜高)  (何を大事に) (なぜ始めた) (何度も出る動き)  (その裏表)  (これから)  (なぜこの会社)
```

| 設問 | 線のどの区間を見せるか |
|---|---|
| ガクチカ | 動機 → 行動のパターン → 強み（＋学び → 今の行動原理） |
| 自己PR | 強み → それが形づくられた原体験 → 別の場面での再現 → 入社後 |
| 志望動機 | 原体験 → 価値観 → やりたいこと → なぜ業界 → なぜこの会社 → 入社後 |
| 挫折・失敗 | 弱み → その場面 → 立て直し → 今の行動原理（強みとの裏表） |
| 大切にしている価値観 | 原体験 → 価値観 → それで判断した場面（迷った選択肢つき） |
| チームでの役割 | 行動のパターン → 他の人との関係の中での発揮 → 他の人の変化 |
| 将来像・挑戦したいこと | やりたいこと → その根拠の経験 → この会社の手段 |
| 自己紹介・あなたを一言で | 線の全体を、1〜2文に圧縮したもの |

→ だから、深掘りで「点」（1つのエピソードの事実）だけを集めても、ESは書けない。**点と点のつながり（なぜそれを始めたのか、前にも同じことをしたか、それが次に何につながったか）**を聞かないと、線にならない。

## 2. 線をつなぐための質問（どのエピソードでも必ず聞く）
| つなぐ区間 | 質問 |
|---|---|
| 価値観 → 動機 | それを始めると決めた日、何があった？他にも選択肢があった中でそれを選んだ時、何を考えてた？ |
| 原体験 → 価値観 | それを大事にするようになったきっかけの場面を1つ教えて。いつ、誰と、何があった？ |
| エピソード → パターン | 前にも同じような動き方をしたことある？逆に、しなかった時は？ |
| 強み ↔ 弱み | その強みが裏目に出た時のことを1回だけ教えて。その時どうなった？ |
| 経験 → やりたいこと | その経験の後、次に何をしたくなった？実際に何かした？ |
| やりたいこと → 志望の軸 | それを一生の仕事にするなら、どんな環境が必要？ |

聞き方は、知識13の4章「聞き方の決まり」に従う（一度きりの場面を選ばせる・「なぜ」ではなく「どうやって／何を」で聞く・誘導しない・ほめない・「ない」は1回で受け入れる）。研究の根拠は04。

## 3. 線の点検表（レベル2・3と深掘りモードの最後に必ず作る）
```
| 区間 | 中身（本人の言葉） | 根拠のエピソード | 状態 |
| 原体験 | | | ある／弱い／ない |
| 価値観 | | | |
| 動機 | | | |
| 行動のパターン | | E番号が2つ以上 | |
| 強み | | | |
| 弱み | | | |
| やりたいこと | | | |
| 志望の軸 | | | |
```
- 「行動のパターン」は、エピソードが2つ以上ないと「ある」にしない（1回だけなら偶然かもしれない）。
- 「弱い」「ない」の区間が、次の深掘りの対象になる。

## 4. エピソード1つの深さ（点の深さ）
自分史インタビュアーの「完了の基準」と同じ。判断の分岐2つ以上／セリフ3つ以上／感情3時点／数字の確度／なぜを3段／失敗・やり直し／行動原理を場面つきで。

## 5. レベルごとに、何を完成させるか
| レベル | 点 | 線 |
|---|---|---|
| 1 | 3エピソードを、完了の基準まで | 各エピソードで「なんで始めた？」と「今につながっていること」だけ聞く |
| 2 | ＋チーム・価値観・サブ2〜3個 | 線の点検表を作る。「行動のパターン」と「強み↔弱み」を「ある」にする |
| 3 | ＋メインの経験を時期ごとに。面接での深掘りへの回答 | 線の全区間を「ある」にする。原体験（小〜高）と志望の軸まで閉じる |
| 深掘りモード | ES作成中に浅いと分かった点 | ES作成中に途切れた区間 |

## 6. 検証
- 通過ES13本で確かめた（`06_通過ES分析.md`）。企業自身が線を設問にしていること、強いESは行動のパターンを複数の時期で示していることを確認した。
- 次の検証：利用者の通過ES・落選ES（本人の同意を取ったもの）を集めて、落ちたESにないものを特定する。就活サイトのコンテンツは、規約上、配布するプロダクトのための一括取得はしない。

# 【13_構造分析と素材の診断】

# 構造分析と素材の診断（v2 / 2026-10-20）

ESは、「この会社が、このコースで、この設問を通して欲しがっている人物」の型に、本人の経験を当てはめる作業。型を先に決めずに書くと、文章が良くても的を外す。だから、書く前に次の順で進める。

**構造分析（会社は何を欲しがっているか）→ 求める要素 R1〜R5 → 評価基準のD項目 → 素材の診断（本人の経験で、どこまで届くか）→ 足りなければ補強の質問 → 骨子**

## 1. 構造分析：6つの層を、上から順に読む
| 層 | 問い | 主な情報源（根拠カード） | 出すもの |
|---|---|---|---|
| L1 業界の構造 | この業界は、これからの5〜10年でどう変わるか（需要・規制・技術・競争の変化） | 官公庁・業界団体の統計、報道、各社の統合報告書の「リスクと機会」 | 業界で今、足りなくなっている力 |
| L2 会社の戦略 | 何で稼ぎ、どこを伸ばし、何に困っているか。競合と比べて何が違うか | 中期経営計画・統合報告書・決算説明資料・トップメッセージ・競合比較表 | この会社で、社員の仕事がどう変わるか |
| L3 公式の人物像 | 会社が公式に言っている、求める人物・行動指針・評価の枠組み。**会社が自分で書いた「足りない人材」** | 採用ページ・人事メッセージ（09の4）。**有価証券報告書の「人材戦略に関する基本方針等」「人材育成方針」（必要な人材像）、統合報告書の人材戦略**（04） | 公式の言葉を、自分の言葉で言い換えたもの。人材戦略に書かれた、戦略と人材のつながり |
| L4 コース・職種の仕事 | そのコース・インターン・職種で、実際に何をし、何が難しいか。成果物は何か | 募集ページ・社員インタビュー・説明会の話（本人の備考） | 入社後（参加後）の場面 |
| L5 設問の意図 | この設問は何を見極めたいか（01の裏の問い）。**設問文の独自の言葉**（例：「周囲を巻き込み」「前例のない」）と、設問の並び順・字数の配分 | 設問文そのもの（【ES依頼】）。調べるなら、同じ会社の過去の設問・説明会での説明 | 設問ごとの裏の問いと、落とされる人 |
| L6 通過者の傾向（仮説） | 公開されている通過ES・内定者の声では、どんな経験や切り口が通っているか | 体験記・就活メディア（ログインなしで見られるもの）・本人の備考 | 傾向。**公式と食い違ったら公式を優先** |

- **L2とL3は、会社自身が人材戦略でつないでいることが多い**。人的資本の開示では、会社は「経営戦略の重要項目 → あるべき人材の姿 → 今とのギャップ → 施策」の順で書く（04）。だから、有価証券報告書と統合報告書の人材戦略を読み、「どの戦略のために、どんな人材が足りないと会社自身が言っているか」を先に押さえる。これが一番強いRの根拠になる。ただし「DX人材」「経営人材」のような決まり文句だけなら、事業の具体（L2）と照らして中身を補い、確度は「仮説」にする。
- 層は上から読む。L1・L2（会社の状況）が分かると、L3（公式の人物像）が「なぜ今それを言っているのか」が分かる。L3の言葉だけを見て書くと、どの就活生とも同じESになる。
- 設問文の言葉は、会社からのいちばん直接のシグナル。同じ「ガクチカ」でも、「周囲を巻き込んで」と書いてある会社と、「自ら課題を設定し」と書いてある会社では、見ているものが違う。

### 構造の一文
6つの層をまとめて、一文にする。
> 〇〇社は今、〜（L1・L2）。だから〜コースでは、〜ができる人（L3・L4）が欲しい。この設問では、〜かどうか（L5）を見極めようとしている。

この一文が書けないなら、リサーチが足りない。足りない層を調べ直す。

## 2. 求める要素 R1〜R5
構造の一文から、ESで見せるべき要素を3〜5個に分ける。
```
R1 （名前：会社の言葉をそのまま使わず、自分の言葉で一言）
中身：どんな行動・考え方か（1〜2行）
なぜこの会社で：L1・L2のどの状況から来ているか（1行）
根拠：L2 C-11（中期経営計画の〜）／L4 C-05（社員インタビューの〜）
確度：高／仮説
重く見る設問：Q1・Q3
ESでの見え方：十分＝本文に〜の場面があり、〜まで書かれている／突出＝〜
足りない時の見え方：〜
```
- **確度**：2つ以上の層で裏づけがあり、そのうち1つが公式（L2〜L4）なら「高」。1つの層だけなら「仮説」。**自分（AI）の解釈だけでつないだ層は数えない**（例：設問文に直接その言葉がないのに、L5で裏づけたことにしない）。仮説のRは、狙い撃ちのリサーチで確かめるか、重みを下げる。
- **一般論のRは作らない**：「コミュニケーション力」「主体性」「粘り強さ」だけのRは、どの会社にも当てはまる。必ず「この会社のこの状況だから、この形の力が要る」まで具体にする。会社名を他社に差し替えても成り立つRは作り直す。
- 総合商社なら、「事業の視点（収益・事業性・市場の構造）で経験を語れるか」を、必ずRの1つにする（10の2）。
- 有価証券報告書の人材戦略で、会社が「足りない」と書いている人材は、Rの候補として必ず検討する。
- R1〜R5は、そのまま評価基準のD1〜D5になる。A〜C・E・Fは共通の項目のまま。
- 評価基準が先にできている時（構造分析を入れる前に作った会社）：RとDの対応表を作る。どのDにも対応しないRがあれば、評価基準を次の版にして、全部の版を判定し直す。

## 3. 素材の診断：本人の経験で、どこまで届くか
### 当てはめ表
求める要素（R）と、経験DBのエピソードの表を作る。
| 記号 | 意味 |
|---|---|
| ◎ | その要素が出る場面・判断・結果（数字）まで、経験DBにある |
| ○ | 場面はあるが、判断の中身か結果が薄い |
| △ | 要素はありそうだが、そう読める場面が経験DBにない |
| × | ない |

### 見込みの点数
- 設問ごとに、**今の素材で一番うまく書けた時**の、評価基準の各項目の段階を予想する。文章の出来ではなく、素材で決まる上限を見る。
- 段階を点に直す：不足＝20／ギリギリ＝50／十分＝80／突出＝100。評価基準の設問ごとの重み（**数字で書く：重い＝3／普通＝2／軽い＝1**）で平均して、設問の点にする。全体の点は、設問の点を字数の比で平均する。
- 点に入れるのは A・B・C・D・E。F（読みやすさ）は素材で決まらないので入れない。足切りは点とは別に見る。
- **点は2つ出す**：経験DBの事実だけの点（判定にはこちらを使う）と、盛り提案を本人が全部採用した場合の点。盛りは本人が決めるもので、まだ素材ではないため。
- 甘くしない。迷ったら低い方にする。点の理由は、必ず「どのRが、どの段階で、なぜか」で書く。

### 判定
| 全体の見込み | すること |
|---|---|
| 80点以上（通過ライン） | 質問しない。骨子だけを出す |
| 65〜79点 | 骨子と一緒に、伸ばせる質問を最大2つ出す（答えなくても進める） |
| 64点以下、またはどれかの設問で、その設問で一番重いRが△か× | 補強の質問を最大3つ出す。今の素材での骨子（暫定）も一緒に出し、「なし」と返されたらその骨子で進める |

止まるのは骨子の1回だけ。質問は骨子と同じメッセージに入れ、別に止まらない。

**質問に全部答えても80点に届かない時**は、それを正直に書く（例：「3つとも答えがあっても74点。素材の上限がここまで」）。そのうえで、①経験DBの別のエピソードに切り替える案 ②盛りの提案 ③ESでは届かない分を面接で補う準備、のどれで補うかを1行で推す。時間がある時は、深掘りチャットで経験DBを育てることを勧める。

## 4. 補強の質問の作り方
質問の形は、面接と記憶の研究にもとづく（04「経験を引き出す質問」）。
- **1問で1つのRを上げる**。どのRが上がるか、上がったら見込みが何点になるかを書く。
- 3つの種類がある。
  - **今の話を深める**：選んだエピソードの中に、その要素が出る場面がありそうな時。
  - **別の話を探す**：経験DBに、その要素が出るエピソードがない時。場面の種類を挙げて思い出しやすくする。例：「部活・アルバイト・ゼミ・家族、どれでもいいので、相手の言いたいことを先に聞いてから動いた時のことを、1回だけ思い出して教えてください」
  - **本人の考えを聞く**：志望動機の原体験・この会社でやりたいこと。経験DBにない、本人しか答えられないこと。

### 聞き方の決まり（どの種類でも守る）
| 決まり | 良い例 | 悪い例 |
|---|---|---|
| **一度きりの場面を1つ選ばせる**（最初・最後・一番覚えている時） | 「その中で一番覚えている1回を教えてください」 | 「普段はどうしていましたか？」 |
| **「なぜ」ではなく「どうやって」「何を」で聞く**（「なぜ」は後付けの理由を呼ぶ） | 「それが原因だと、どうやって分かりましたか？」「その時、何を考えていましたか？」 | 「なぜそうしたのですか？」 |
| **過去にしたことを聞く**（「もしこうなったら」は聞かない） | 「〜した時、最初に何をしましたか？」 | 「〜になったら、どうしますか？」 |
| **閉じた質問・誘導をしない**。答えの形を決めつけない | 「その時、周りの人はどんな反応でしたか？」 | 「反対した人はいましたか？」「頑張ったんですよね？」 |
| **「もっと詳しく」だけの追い質問をしない**（盛りを増やす） | 「その話し合いで、最初に誰が何と言いましたか？」 | 「もう少し詳しく教えてください」 |
| **「でも」を使わない**（責めているように聞こえる） | 「〜と聞いて、もう1つ知りたいのは…」 | 「でも、それって〜じゃないですか？」 |
| **ほめない・評価しない** | （事実を受け取って、次の質問に進む） | 「素晴らしい経験ですね！」 |
| **「ない」は1回で受け入れる**。同じことを二度聞かない（何度も迫ると、本人の迷いが深まる） | 「分かりました。今の素材で進めます」 | 「本当にありませんか？ 小さなことでも…」 |

- 例を1つ添えてよいが、答えを誘導しない（例は思い出すきっかけで、そのまま本文に使わない）。
- 経験DBを読めば分かることは聞かない。
- 本人の答えは、経験DBへの追記として記録する。本人の言葉をそのまま残す。
- 「なし」と言われたら、今の素材で一番良い骨子で進める。弱さは、盛りの提案（本人が決める）と、面接の準備で補う。
- 面接の準備（09の5、なぜを3段）は別。面接官は実際に「なぜ」と聞くので、そこでは「なぜ」で練習する。

## 5. 骨子のメッセージの形（これを先頭に出す）
```
【この会社が欲しい人】構造の一文
【求める要素】R1〜R5を1行ずつ（確度・根拠カード番号）
【今の素材での見込み】Q1 〇点／Q2 〇点／Q3 〇点 → 全体 〇点（このまま進む／質問あり）
理由：（どのRが、どの段階で、なぜか。2〜3行）
【聞きたいこと】（質問ありの時だけ。答えられるものだけでOK。「なし」でも、下の骨子で進めます）
1.〔今の話を深める・R2〕質問（一度きりの場面・「どうやって／何を」で） → 答えがあれば、R2が十分に上がり、見込み 〇点
2.〔別の話を探す・R4〕質問
【骨子】（es-create 4章の形）
```

## 6. 会社の種類ごとに、構造分析で特に見る層
傾向であって正解ではない。実際の中身は、毎回その会社の根拠カードで確かめる。
| 種類 | 特に見る層 | よく出るRの形（例） |
|---|---|---|
| 総合商社 | L1（資源・脱炭素・事業投資から事業経営への移行）・L2（事業の構成） | 事業の視点で経験を語れる／利害の違う人を動かす／ゼロから仕組みを作る |
| 消費財・食品メーカー | L1（国内市場の縮小・健康志向・値上げ）・L2（成長領域・海外）・L4（営業・マーケの仕事の中身） | 得意先や消費者の課題から提案を組む／数字で効果を確かめて直す |
| 外資コンサル・外銀 | L3（公式の資質の枠組み）・L5 | 枠組みの各資質の証拠になる場面を、端的に1つずつ（10の1） |
| メガバンク・信託・保険 | L2（手数料ビジネス・デジタル化）・L3（人財ポリシー） | 信頼を積み上げる／ルールの中で工夫する |
| IT・通信 | L1（技術の変化）・L4（職種ごとの仕事） | 技術と現場の間に立って形にする |
