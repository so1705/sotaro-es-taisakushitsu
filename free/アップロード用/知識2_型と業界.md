# 【02_業界別】

# 業界別：何を見られ、どこで差がつくか

ここに書いてあるのは業界の傾向。企業ごとの正解は、企業分析（research.md）の行動指針・中期経営計画・社員インタビューを優先する。各業界の「確認先」は、research.md を作るときに必ず読む資料。

---

## 総合商社
- **見ているもの**：立場や価値観の違う人を動かした経験、逆境でも当事者であり続けたか、将来経営を担えるか。
- **差がつくポイント**：「異質な他者」をどう動かしたか。仲の良いサークル内の話では弱い。利害がぶつかる相手に、相手の得を設計して動かした話が強い。
- **志望動機の罠**：「グローバル」「スケールが大きい」「人の魅力」は全員が書く。メーカー・コンサル・金融ではなく商社である理由（事業に投資し、自分も経営に入る当事者になれること）を、各社の注力事業と結びつける。
- **確認先**：中期経営計画の注力領域、統合報告書の事業ポートフォリオ、若手社員のキャリアの事例（どの年次で出向・駐在するか）。

## 戦略コンサル・総合コンサル
- **見ているもの**：論理的に考える力、知的好奇心、タフさ。ESより筆記試験とケース面接の比重が大きい会社が多い。
- **差がつくポイント**：課題を自分で定義し直した経験（与えられた課題をそのまま解いたのではなく、本当の課題は別だと気づいた話）。
- **志望動機の罠**：「様々な業界に関われる」「成長できる」は全員が書く。当事者（事業会社）ではなく支援者を選ぶ理由を、自分の経験から説明する。総合系では、戦略だけでなく実行・IT導入まで関わる点との接続。
- **確認先**：その会社が強い領域（業界・テーマ）、事例紹介、社員インタビューで語られる仕事観。

## 投資銀行・証券・アセットマネジメント
- **見ているもの**：数字への強さ、ハードワークに耐えられるか、市場や企業への関心が本物か。
- **差がつくポイント**：金融への関心を、具体的な行動（投資の経験、企業分析、資格の勉強）で示せるか。「なぜ金融か」を原体験から語れるか。
- **志望動機の罠**：「経済を動かしたい」は抽象的すぎる。関わりたい取引の種類（M&A・資金調達・運用）まで落とし込む。
- **確認先**：リーグテーブル（実績順位）、注力分野、部門ごとの業務内容。

## 銀行（メガバンク・地方銀行）
- **見ているもの**：誠実さ、信頼を積み上げる力、お客様の立場で考えられるか。
- **差がつくポイント**：長い時間をかけて信頼を得た経験。短期の成果より継続性。近年は、金融以外の事業（DX・コンサル・地域創生）への理解が差になる。
- **志望動機の罠**：「金融で企業を支えたい」はどこの銀行にも出せる。その銀行の顧客基盤や地域、グループの機能と、自分の原体験を結びつける。
- **確認先**：中期経営計画、新規事業・非金融事業、地域との取り組み。

## 保険（生保・損保）
- **見ているもの**：人の不安や困りごとに寄り添えるか、粘り強さ、リスクへの感度。
- **差がつくポイント**：保険商品の話ではなく「リスクを引き受ける仕組み」への理解。損保なら新しいリスク（自然災害・サイバー・モビリティ）、生保なら健康や長寿社会との接続。
- **確認先**：新商品・新しいリスク分野、代理店営業などの職種の実態。

## メーカー（素材・化学・部品などのBtoB）
- **見ているもの**：長い目線で物事を進められるか、技術を事業につなぐ視点、地道な調整力。
- **差がつくポイント**：素材そのものではなく「その素材の先にいるお客様（完成品メーカーや最終消費者）」まで想像できているか。事務系は「技術を理解して、事業にする翻訳者」の役割で語ると強い。
- **志望動機の罠**：「縁の下の力持ち」「世界シェアが高い」は全員が書く。どの製品がどの最終製品に使われていて、そこにどう関わりたいかまで書く。
- **確認先**：製品別の売上構成、主な顧客業界、研究開発の方針、統合報告書。

## メーカー（消費財・食品・日用品）
- **見ているもの**：消費者の気持ちを理解する力、それをビジネスにする力（営業・マーケティング）。
- **差がつくポイント**：「商品が好き」は差別化にならない。好きな理由を、ブランドの作り方・流通（小売との関係）・営業の仕組みまで分解して語る。事務系の多くは営業から始まる現実を理解しているか。
- **確認先**：ブランドの戦略、海外展開、配属の実態（最初の配属先）。

## IT・SaaS・メガベンチャー
- **見ているもの**：自分で動く力、学ぶ速さ、事業を自分ごととして考える姿勢（オーナーシップ）、数字で改善を回せるか。
- **差がつくポイント**：仮説→検証→改善を数字で回した経験。プロダクトや事業の数字（解約率・顧客あたりの売上など）を理解した上で語れると強い。
- **志望動機の罠**：「裁量が大きい」「成長環境」は全員が書く。そのプロダクトの課題を自分なりに指摘し、自分ならどう改善するかまで書く。
- **確認先**：プロダクトのユーザーとしての実体験、決算説明資料（成長率・注力領域）、エンジニアやPMのブログ。

## 広告・マスコミ・エンタメ
- **見ているもの**：発想の独自性と、それを形にする実行力。ES自体が作品として見られる。
- **差がつくポイント**：設問が変わったもの（写真・自由記述・お題）が多い。他の設問の焼き直しではなく、読み手を楽しませる編集ができるか。
- **志望動機の罠**：「人を感動させたい」は全員が書く。自分が実際に人を動かした・楽しませた経験を、具体的な作品や企画で示す。
- **確認先**：その会社の代表的な仕事・作品、クリエイターや社員の発信。

## 不動産・デベロッパー
- **見ているもの**：長期間かけて多くの関係者をまとめる力、街や社会への視点。
- **差がつくポイント**：関係者の多い調整の経験。会社が開発しているエリア・物件を実際に歩いて見て、自分の言葉で語れるか。
- **志望動機の罠**：「街づくりがしたい」は全員が書く。その会社の開発エリア・アセットの特徴と、自分の街への原体験を結びつける。
- **確認先**：主要な開発プロジェクト、保有アセット、まちづくりの方針。

## インフラ（電力・ガス・鉄道・通信）
- **見ているもの**：社会を支える使命感、安定して運用する責任感、同時に変革を進められるか。
- **差がつくポイント**：「当たり前を守る」と「変える」の両方の視点。脱炭素・DX・地方の人口減少など、業界の構造的な課題をどう見ているか。
- **確認先**：中期経営計画、エリアや事業の多角化（不動産・生活サービスなど）。

## 人材・教育
- **見ているもの**：人の人生の選択に関わる責任感と、それをビジネスとして成立させる力（営業成果へのこだわり）。
- **差がつくポイント**：「人の役に立ちたい」だけではなく、ビジネスとしての仕組み（誰からお金をもらうのか）を理解しているか。
- **確認先**：事業ごとの収益構造、主力サービス。

## 官公庁・公的機関・団体
- **見ているもの**：公共への使命感、関係者が多い中での調整力、制度への理解。
- **差がつくポイント**：民間ではなく公共を選ぶ理由を、具体的な政策課題と結びつけて語れるか。
- **確認先**：所管する政策・最近の白書、職員の仕事紹介。

# 追補：トップ層の業界の論点（v2 / 2026-10-20）
上の各業界に重ねて使う。ここに書いた会社ごとの特徴は、就活メディアの整理や一般に知られている内容で、**ESに使う前に、必ずその会社の統合報告書・中期経営計画・採用ページで確認する**（09の2の競合比較表に、出典つきで入れる）。

## 総合商社
- **ESで使える論点**：「トレード（仲介）」から「事業投資と経営」へ、という役割の変化。商社パーソンは、投資先の経営に入り、事業の価値を上げる。だから見ているのは「異質な人を動かして、事業を前に進めた経験」と「経営人材として伸びるか」
- **各社の違いの軸**（就活メディアの整理。要確認）：資源と非資源の比重、強い分野（エネルギー・食料・生活消費・インフラ・自動車関連など）、社風を表す公式の言葉、若手の任され方
- **なぜ商社か**で必ず答えること：メーカー（自社製品がある）・コンサル（当事者ではない）・金融（資金だけ）ではなく、商社でなければならない理由。「事業の当事者として、業界をまたいで価値をつくれる」を、本人の経験でどう裏づけるか
- **よくある誤り**：「グローバル」「スケール」「人の魅力」だけ／トレード中心の古い商社像／他社名に差し替えても通じる志望動機

## 戦略コンサル（外資）
- **ESの扱い**：ES自体で落ちることは少ないとも言われるが、面接の材料になる。短い字数で、結論から構造的に書けているかを見られる（09の3）
- **ESで使える論点**：与えられた課題ではなく、**課題を自分で定義し直した経験**／仮説を立てて検証した経験／立場の違う人を動かした経験（公式の資質と対応させる：09の4のマッキンゼーの4資質など）
- **なぜコンサルか**：事業会社の当事者ではなく、支援者を選ぶ理由。「多くの業界を見られる」「成長できる」だけでは弱い
- **よくある誤り**：抽象的な「論理的思考力」の自称／ケース面接の知識を、ESでひけらかす

## 総合コンサル・IT系コンサル
- 戦略だけでなく、実行やシステム導入まで関わる点。ESは戦略コンサルより重く見られ、志望理由が序盤の面接で問われることがある
- 「戦略から実行まで一貫して関わりたい」は、通過ESでも多い言い方。本人の「戦略が現場で実行されなかった経験」と結びつけると差がつく（08の通過ES）

## 外資系投資銀行
- **ESで使える論点**：関わりたい取引の種類（M&A・資金調達・資本政策）まで具体的に。数字に強いこと、長時間でも質を落とさないタフさ、チームでの責任感
- **なぜ投資銀行か**：「経済を動かしたい」では弱い。企業の重大な意思決定（買収・上場・資金調達）を支える立場を選ぶ理由を、本人の経験（投資の経験、企業分析、家業など）で
- **よくある誤り**：給与や激務の印象に触れる／業界の用語を、意味を外して使う

## 外資メーカー（消費財）
- **ESの中心**：行動を問う設問（リーダーシップ・困難を乗り越えた経験）を、公式の評価の枠組み（P&GのPEAKなど）に沿って面接で深掘りする（09の4）
- **ESで使える論点**：肩書きのないリーダーシップ（役職がなくても、周りを動かした）／数字と消費者の気持ちの両方で考えた経験
- **よくある誤り**：「商品が好き」だけ／リーダー経験を役職名で語る

## メガバンク・日系大手金融
- 公式の人財ポリシーや求める人物像を、ESの設問でそのまま聞く会社がある（SMBCの「プロフェッショナル・チームワーク・挑戦」など）。それぞれの言葉の定義を、公式の説明で確認してから書く
- 3つの資質を別々に聞かれた時は、同じエピソードの使い回しでもよいと書かれていることがある。ただし、切り口を必ず変える（06 発見10）

## 日系大手メーカー・インフラ
- 長期で関わる意思、技術や社会基盤への敬意、配属先の現実（最初は営業・工場・地方など）の理解
- 公式のパーパス・中期経営計画の言葉と、本人の経験を結びつける（通過ES：パーパスや求める人物像に当てはまる人材であることを示した、という本人の注意点）

# 【06_通過ES分析】

# 通過ES分析（v2 / 2026-10-20）

就活サイトに掲載されていた通過ES・内定者ESを、要素の単位に分けて分析した。全文を読んだのは16本（IT・SIer 5、メガバンク 1、航空 2、玩具 1、広告 1、小売 1、食品 1、デベロッパー 2、総合商社 1、総合コンサル 1）。それに加えて、商社・金融の内定者ESの冒頭 約50本と、同じ会社・同じ設問（総合商社の「将来の夢と志望理由」）への回答の冒頭 10本を比べた。個人が特定できる情報と、本文の転載は載せない。著作権と掲載元の規約に配慮して、本文は載せず、要素と傾向だけを記録する。

## 発見1：企業自身が「線」を設問にしている
- 小学校・中学校・高校・大学のそれぞれについて、自分史を200〜600字で書かせる設問（デベロッパー）
- 自分史グラフ（モチベーションの上下と、変化の理由）（玩具）
- 中長期のビジョン3つ、原動力3つ、その2つを1つにまとめた「等身大の個性」、らしさが出たエピソード6つ（苦手なことも含む）（広告）
- 「あなたはどんな人ですか」→ その人物像がよく表れたエピソード（デベロッパー）
→ 線は、ESを書くための裏の理論ではなく、**企業がそのまま設問で聞いてくるもの**。レベル3の経験DBは、この形式の設問に、そのまま答えられる状態にしておく。

## 発見2：強いESは「同じ動きが人生の中で繰り返されている」ことを証明している
- 幼少期からの習い事での挫折と雪辱 → 大学のサークル → アルバイト。同じ「失敗を糧に、泥臭く努力する」動きを3つの時期で示す（SIer）
- 小学校で副キャプテン → 中学で副キャプテン → 高校で副キャプテン → 大学で副将。「支えながら組織を変える」役割の繰り返し（デベロッパー）
- 17年間ずっと主将 → 一人ひとりと対話して組織をつなぐ → それを街づくりに（デベロッパー）
- 中学の部長 → 大学のアルバイトで先輩と後輩の橋渡し（航空）
→ 「行動のパターン」は、2つの時期以上で示せると一気に説得力が上がる。**小・中・高の深掘りは、レベル3のおまけではなく、強みを証明するための材料。**

## 発見3：原体験は、身近で小さなことが多い
- 弟が4月1日生まれ → 生まれ月による教育格差の研究テーマ（デベロッパー）
- アルバイト先の勤怠管理がITシステムで改善されたのを見た → ITで課題を解決したい（SIer）
- 海外ボランティアで、暮らしは違っても笑うツボは同じだと感じた → 人の心を動かす仕事（広告）
- 高校受験の失敗 → 厳しい環境に挑む性格（IT）
→ 原体験を聞くときは、「人生の大きな出来事は？」ではなく「**今の関心につながっている、身近な人や出来事は？**」と聞く。

## 発見4：強いESには、本人の言葉で作った表現がある
- 自分の性格を、身近な道具・アプリ・ことわざにたとえた一言や、仕事の理想像を五感で描いた一文のような、自分で作った言い回し・比喩（航空・広告・デベロッパー・総合商社）
- 各ESの「注意した点」には、「自分の言葉で」「嘘をつかない」「面接で応用が効くように本音で」という記述が繰り返し出てくる
→ インタビューでは、本人が口にした比喩や口癖を拾って残す。「自分を一言で、たとえで言うと？」を聞く。

## 発見5：志望動機の「その会社でなければ」は、現場での接点から生まれている
- インターンで社員から聞いた一言を引用 → アルバイトのレジで実際に見た購買行動 → 具体的な施策 → 2年以内に店長、その後VMD（小売）
- 何度もその会社の街に足を運んで、自分の目で見た工夫を列挙（デベロッパー）
- その会社が開発した具体的なエリア名を挙げる（デベロッパー）
→ 経験DBに「**企業・業界との接点**」（アルバイト先・インターン・店舗や施設の訪問・説明会やOB訪問で聞いた言葉）を記録する欄を作る。ESの企業固有の項目（D）の素材になる。

## 発見6：強いガクチカは「原因をどう突き止めたか」を書いている
- 参加率が下がった原因を、メンバーとの面談で特定（SIer）
- 試合映像の分析と、一人ひとりへのヒアリングで課題を特定（デベロッパー）
- 「雰囲気が良いことが、逆に問題を指摘しづらくしていた」という逆説的な難しさ（食品）
- 「規律の強化」ではなく「作品の質を上げること」に目的を定義し直した（食品）
→ 点の深掘りに「**原因をどうやって突き止めたか**」と「**目的を定義し直したか**」を足す。難しさの型に「逆説（良いことが、逆に問題を難しくしていた）」を足す。

## 発見7：深掘りが浅くても通過しているESがある
- 抽象語だけで書かれた長所・志望動機・ガクチカ（IT）
- 3つの資質を同じエピソードで書き分けているが、どれも中身が一般論（メガバンク）
→ 企業によってはESの通過ラインが低く、面接で決めている。**「通過した」は「良いES」の証明にはならない**。通過ESをお手本にするときは、内定まで行ったESと、強い要素を持つESを優先する。そして、ESが浅いまま通過すると、面接の深掘りで崩れる（00_本質原則 1）。

## 発見8：変わった形式の設問に、経験DBがそのまま効く
| 設問の形式 | 経験DBの何を使うか |
|---|---|
| 時期ごとの自分史（各200〜600字） | 年表（時期ごとに、熱中・役割・出来事・気持ち・学び） |
| モチベーショングラフ | 年表の気持ちの上下と、その理由 |
| 自分を表す言葉3つ／30字のビジョン・原動力 | 横断のまとめ（価値観・行動パターン）と、本人の比喩 |
| らしさが出たエピソード×6（苦手も含む） | 小さなエピソード集（下記） |
| 写真で自己紹介 | 小さなエピソード集の中で、写真が残っているもの |
| 10年後のニュース | 関心のある社会課題と、その理由 |
→ 深掘りの対象は、メインのエピソードだけでは足りない。**80字で書ける小さなエピソードを10個以上**集めておくと、変わった形式の設問に困らない。

## 発見9：上位企業では「線」は当たり前。差がつくのは原体験の固有さ
- 総合商社の「将来の夢と志望理由」への回答10本は、ほぼ全員が「夢 → 原体験 → その会社の手段 → 目指す姿」の線で書いていた。
- そのうち複数が、「海外で日本の製品や企業が信頼されているのを見て、うれしかった」という似た原体験だった。
- 内定した1本は、原体験の場面（訪れた国の数、そこで見た、移動に困っている人の現実）と、会社の手段（まだ開拓されていない市場での商流づくり、現場主義）が、どちらも具体的だった。本人の「注意した点」にも、「原体験となりたい社会人像を、その会社に寄せた」と書かれていた。
→ 線があるだけでは、上位企業では横並びになる。深掘りでは「その原体験は、他の就活生も持っていそう？ あなたにしかない場面・人・言葉は？」まで聞く。

## 発見10：内定者は、1つの強いエピソードを複数の会社で使い回している
- 同じ人が、課外活動を立ち上げた同じ経験を、4社の違う設問（最も打ち込んだこと／大切にしたいこと／挑戦から学んだこと／挑戦した理由）で、切り口を変えて使っていた（専門商社など）。
- 留学先のチームに一人で飛び込んだ経験を、2社（保険）で使っていた。
→ 経験DBは、浅いエピソードをたくさん持つより、**深いエピソードを少数持つ方が強い**。ES作成側の仕事は、同じエピソードの「どの面を、その会社向けに前に出すか」を決めること。

## 発見11：強みと弱みの「裏表」を、そのまま聞く設問がある
- 長所と短所をそれぞれ一言で書かせ、それを自覚した理由を行動の事実で説明させる設問（信託銀行）。内定者は、長所が「周りを見渡して全体を良くする力」、短所が「責任感が強いぶん、一人で抱え込む」という、同じ性質の裏表で答えていた。
→ 線の点検表の「強み ↔ 弱み」は、そのまま設問になる。

## 発見12：「原因の定義し直し」は、業界を問わず強いガクチカの共通点
- 部員が減った原因は、勧誘ではなく、入部した後の仕組みにあった（商社）
- 対立の原因は、評価の基準が競技の実力だけに偏っていたことだった（総合商社）
- 全員が納得しないまま物事が決まっていたことが原因だと、対話で突き止めた（信用金庫）
→ 発見6の補強。深掘りでは「最初に原因だと思っていたことと、本当の原因は違った？」を必ず聞く。

## 発見13：数字が具体的でも、動機が浅いまま通過しているESがある
- 成果の数字（偏差値の上げ幅、面談の頻度）は具体的なのに、「なぜその壁を越える必要があったか」の動機が一文で終わっているもの（メガベンチャー・インターン選考・1次通過）。
→ 発見7と同じ。数字が具体的なだけでも初期の選考は通るが、動機（線の「価値観 → 動機」）が浅いと、面接の深掘りで止まる。

## 発見14：業界ごとに、よく出る設問の形と素材の傾向
- 総合商社：「将来の夢・目標」と志望理由をセットで聞く。原体験は海外経験・留学・地元の課題が多く、そのぶん似通いやすい。
- 総合コンサル：会社の動画や事例を見た感想を書かせる。内定者は、内容の要約ではなく「つまり、この会社は〇〇という姿勢を示していると解釈した」という**自分の解釈**まで書いていた。
- 金融（銀行・証券・保険・信金）：ガクチカは、塾・予備校のアルバイトでの校舎の課題解決、飲食・小売のアルバイトでの売上改善、留学先のチームへの参加が多い。志望動機は、地域・中小企業を支える（地銀・信金）、専門性で他人の意思決定を支える（投資銀行）、成長環境（大手証券）に分かれる。
- インフラ・メーカー系：会社が定義した「求める人物像」を選ばせて、それに沿って志望動機を書かせる設問がある（SIer）。評価基準の項目D（企業固有）を、会社がそのまま明かしている例。
→ ES作成のSkillでは、設問の形から業界の傾向を参照する（02_業界別 と合わせて使う）。

## インタビューへの反映（自分史インタビュアーとSkillに入れたもの）
1. 点の深掘りに「原因をどう突き止めたか」「目的を定義し直したか」を追加
2. 難しさの型に「逆説」を追加
3. レベル2〜：「企業・業界との接点」「小さなエピソード集（10個以上、苦手なことも含む）」「本人の比喩・口癖」を追加
4. レベル3：行動のパターンを、2つ以上の時期（小・中・高・大）で確認する
5. 原体験の聞き方を「身近な人や出来事」に変更
6. 原体験の固有さの確認（「他の就活生も持っていそう？」）と、原因の定義し直し（「最初に思った原因と、本当の原因は違った？」）を追加
7. 経験DBは、エピソードの数より深さを優先する（レベル1の3エピソードを深くすることが、どの会社にも効く）

# 【08_設問タイプ別の型】

# 設問タイプ別の型（v1 / 2026-10-20）

通過ES・内定者ES 約30本（コンサル・金融・総合商社・デベロッパー・メーカー・IT・航空・エンタメ・小売・化粧品）を、設問の種類ごとに分けて、強い型と弱い型を抽出した。本文は載せず、型と判定だけを記録する。通過していても弱いESは多い（06 発見7）ので、「通過した」ではなく「要素が強い」ものを型にした。

## 1. 志望動機・志望理由
**強い型**：人生の目標・夢（一言）→ それを持つようになった原体験 → なぜこの業界か → **なぜこの会社か（その会社にしかない具体名）** → 入社後に何をするか（部署・商材・地域・年次まで）
- 会社固有の具体名が入っている：開発思想の名前と具体的な地名（デベロッパー）、主力の技術基盤の名前とその特性（IT）、事業の種類と担当したい地域（海運）、自社商品の具体名と販売先の地域と健康課題（食品メーカー）
- 入社後の具体性：10年後・20年後のキャリアの段階、2年以内に店長、その後に売場づくり、のように時間軸がある
- 「自分の夢 → この会社の手段」の順で書き、「会社の説明 → 共感」の順にしない
- 本人の注意点にも「業界 → 企業 → 職種の順」「なぜ資産運用か → なぜこの会社か → どう貢献するか」「なぜこの会社か → その中でなぜこの部門か → そこで何をしたいか」と、**絞り込みの順番**を意識した記述が繰り返し出てくる

**弱い型**（通過していても、要素は弱い）
- 理念・パーパスへの共感だけ／「多様な事業」「グローバル」「社会への影響力」など、どの会社にも言える言葉
- 「持続可能な社会」「技術革新」を並べた、抽象度の高い文章（AIっぽさも強い）

## 2. インターン・コース・部門・職種の志望理由（Q2型）
**強い型**：なぜその領域か → **その会社のそのインターン（部門）で、具体的に何をするのか** → 自分の経験の何がつながるか → 何が足りず、何を確かめたい／得たいか → どう貢献するか
- インターンや説明会に参加した後なら、**現場で見たもの・聞いたことを1つ具体的に**書き、挑戦したい業務を具体名で挙げる（航空：インターンで見た困難な場面への社員の対応 → 挑戦したい業務を2つ具体的に）
- 部門を選ぶ理由は、その部門の事業の構造（市場の課題・その会社の立ち位置・使える資源）まで踏み込む（EC：国内のEC化の遅れ → 中小企業の課題 → その会社の市場シェアとポイント経済圏）
- 希望分野ごとに理由を書き分ける。「まだ決めきれないので、社員の方に業務を伺って見極めたい」という正直な書き方も、理由があれば通る（IT）
- 必要なリサーチ：インターン・部門の中身（テーマ・期間・成果物・社員の関わり）、その事業の今（伸びている所・課題）、過去の参加者の声

**弱い型**：会社の一般的な魅力（若手の裁量・成長環境）だけで、インターンの中身に触れていない

## 3. ガクチカ・最も力を入れたこと・困難を乗り越えた経験
**強い型**：想い・目標 → 課題（数字で）→ **原因をどう突き止めたか**（面談・アンケート・データ・フィードバック）→ 施策2〜3（頻度・期間・量まで具体的）→ 結果（数字）→ 学び
- 2段階の変化：施策で伸びた → 新しい課題（定着率など）→ 原因を突き止め直す → 理念は守りつつ活動を調整、の流れは特に強い
- 施策の具体性：週2日×2時間×1か月、毎週最初の30分を勉強の時間にする、役割を新設する、など
- 想いを最初に置く：「全員が本気で喜べる勝利を」「このステージに立つのが憧れだったという言葉に、成功させたいと思った」
- 他の人のセリフが1つ入ると、場面が立つ

**弱い型**：「リーダーシップとプロジェクトマネジメントのスキルを培った」のような、能力名だけで終わる学び

## 4. 自己PR・強み
**強い型**：自分らしい言い方の強み（例：「全力でおせっかいを焼いてしまう人間」）→ それが出たエピソード（想い → 施策2つ → 相手の反応・感謝の言葉）→ 仕事でどう使うか
- 強みを3つ求められた時は、それぞれ別の場面で示す
- 長所は「具体的な行動と数字」、短所は「強みの裏返し＋今やっている対策」（例：責任を抱え込みやすい → 事実と仮説を分けて整理し、一定時間で解決しなければ早めに共有する）

## 5. 価値観・人生に影響を与えた出来事
**強い型**：出来事（家族の病気、役職で一人で抱え込んだ経験、友人の口癖）→ その時の気づき → 今の行動の変化
- 他人の言葉から価値観が生まれた話（友人の「お互い様だから」）は、本人らしさが出やすい
- 弱さを認めた話（助けを求めるのが恥ずかしかった → 人を頼ることは成長のための選択）は、素直さとして評価されやすい

## 6. 変わった形式の設問
| 形式 | 強い答え方 |
|---|---|
| 行動指針から1つ選ぶ | 選んだ言葉の意味を、自分の失敗経験（相手を一方的に判断していた → 対話で背景を知った）で裏づける |
| ハッシュタグ×3 | 30字の中に動詞を入れ（想像し尽くす・揺さぶる・つなぐ）、理由でそれぞれ別の場面を示す |
| 取扱説明書 | 特徴（エピソード）＋注意事項（弱み）＋「こう声をかけてくれると力を発揮する」まで書く。少しのユーモアは可 |
| 自分を表す要素と割合 | 比重をつけて、大事な順に並べる。割合の小さい要素で、日常の小さなこだわりを見せる |
| 単語を使った自由作文 | 物語にしながら、最後に自分の価値観（変わらない価値を守る、など）に着地させる |
| 商品の企画・売り方のアイデア | テーマ／商品／時期／ターゲット／販売場所／背景（市場の数字）／内容、と項目立てで構造化する |
| 時期ごとの自分史・影響の大きい順のエピソード | 時期ごとに1行で、役割と気持ちの変化を入れる（06 発見8） |
| キャッチフレーズ | 比喩＋補足で、どんな時に発揮されるかを書く（「チームの心の火付け役」→ 劣勢の時こそ） |

## 7. 本人たちの「注意した点」から分かる書き方
- 書類選考を通ることではなく、**面接でどう聞かれても答えられるエピソード**にする。深掘りしてほしい部分に興味を持たせる（00 原則1）
- そのエピソードを知らない人に読んでもらい、分かりにくい部分を指摘してもらう
- やったことの羅列ではなく、**なぜそれをやったか**と、**その時の感情**を書く
- 他の就活生と被らないエピソードを選ぶ（06 発見9）
- 字数が少ない時は、**絶対に入れたい言葉を先に決めてから**書く
- 業界 → 企業 → 職種の順に絞り込み、他社との比較で「なぜこの会社か」を言えるようにする
- 制限字数ぎりぎりまで書く。誤字・ブランド名の表記（大文字小文字・空白・英語かカタカナか）まで確認する

# 【09_トップ層の型】

# トップ層の型（v1 / 2026-10-20）

外資戦略コンサル・外資系投資銀行・外資メーカー・総合商社・日系大手の選考で、通過ラインを超えるための型。08（設問タイプ別の型）の上に重ねて使う。
トップ層の通過ESでの校正（評価基準の「突出」の具体例を、実際の通過ESで合わせること）はまだ。

## 1. 意見・提案型の設問（G2）
「当社で取り組むべき事業」「日本の課題とその解決策」「新しい売り方・売り場」「10年後のニュース」「業界の未来」など、経験ではなく**考える力**を問う設問。トップ層ほど出る。

### 型
1. **結論**：提案を一言で（誰に・何を）
2. **背景（事実）**：市場・社会の事実を数字で1〜2つ（根拠カードから。出典があるもの）
3. **論点**：なぜ今まで解かれていないのか（構造的な理由）。ここが一番差がつく
4. **提案**：その会社の資産（事業・顧客基盤・技術・ブランド・拠点）を使う形で、具体的に
5. **実現性**：最初の一歩・誰が困るか・リスクを1つ
6. **自分との接続**：その視点を持てたのは、自分のどんな経験からか（1文）

### 工程（ES作成のSkillで、この種類の設問だけ追加で行う）
1. 業界と会社の事実を集める（市場規模・成長率・課題・その会社の資産）
2. 論点の候補を3つ出し、それぞれ「他の学生も思いつくか」を判定する。誰でも思いつくもの（「海外展開」「DX」「若者向けSNS」だけ）は捨てる
3. 経験DBから、本人ならではの視点（現場で見たこと・原体験）を1つ選び、論点と掛け合わせる
4. 会社の資産を必ず1つ以上使う（使わない提案は「どの会社でもできる」になる）

### 弱い型
- 会社の説明や、一般論の課題（「少子高齢化」）だけで、論点がない
- 会社の資産を使っていない
- 実現の最初の一歩がない

## 2. 競合との比較（G3）
志望動機・「なぜ当社か」の設問では、**同業の主要2〜4社との比較表を、リサーチで必ず作る**。
| 比べる軸 | 当社 | 競合A | 競合B |
|---|---|---|---|
| 事業の構成・稼ぎ頭 | | | |
| 今の戦略の方向（中期経営計画） | | | |
| 公式の価値観・行動指針の言葉 | | | |
| 若手の仕事の任され方（公式の社員紹介） | | | |
| 本人の軸と重なる点 | | | |

### 書き方
- 競合を下げない。「A社もB社も〇〇に強い。その中で貴社は△△を持つ」の形にする
- 違いは1つに絞る。3つ並べると、どれも浅くなる
- 違いは、本人の経験・やりたいことと必ずつなげる（違いを知っているだけでは、志望の理由にならない）

## 3. 短い設問の圧縮（G6）
外資戦略コンサルなどは、100〜200字の設問が多い。見られるのは「結論から書けて、構造化されているか」。

| 字数 | 入れるもの |
|---|---|
| 30字（キャッチ・一言） | 動詞を含む自分の言葉＋比喩。名詞を並べない |
| 100字 | 結論＋根拠1つ＋数字1つ |
| 200字 | 結論＋背景1文＋行動2つ＋結果（数字） |
| 300〜400字 | 08の型をそのまま（原因の突き止め方・2段階の変化まで） |

### 工程
1. 書く前に、**絶対に入れる言葉を3つ**決める（強み・一番の数字・判断の分岐など）
2. 長く書いてから削る。削る順番：修飾語 → 背景の説明 → つなぎの言葉 → 2つ目の行動
3. 最後まで残すもの：結論・数字・判断の分岐

## 4. 公式の評価の枠組み（G7）
リサーチの最初に、その会社が**公式に出している評価の枠組み・行動指針**を探す。あれば、それが評価基準のD項目になる。
| 会社・業界 | 公式の枠組み（例） | 確認状況 |
|---|---|---|
| マッキンゼー | 4つの資質：Personal impact／Entrepreneurial drive／Inclusive leadership／Problem solving。過去の経験を問う形で聞く | 公式ページで確認済み（04） |
| Google | 役割に関する知識・問題解決・リーダーシップなどを、4段階の評価基準で採点 | 公式（re:Work）で確認済み（04） |
| Amazon | 行動指針（Leadership Principles）。過去の行動を問う質問で見る | 公式の採用ガイドで確認済み。項目数は年で変わるので、毎回確認する |
| P&G | PEAK Performance Factors。リーダーシップ・思考力・誠実さなどで、ESの行動を深掘りする | 外資就活の記事のみ。公式で要確認 |
| 三井住友銀行（SMBCグループ） | 人財ポリシー：プロフェッショナル・チームワーク・挑戦（ESでそれぞれの発揮事例を聞く） | 通過ESの設問で確認 |
| NTTデータ | 求める人財像を3つ定義し、ESで1つ選ばせる（「変革力」など） | 通過ESの設問で確認 |
| 三菱商事 | 三綱領（所期奉公・処事光明・立業貿易） | 報道で確認。採用での使われ方は要確認 |
| 総合商社の各社 | 企業理念・行動指針（例：伊藤忠の「三方よし」、丸紅の社是「正・新・和」） | 一般に知られている内容。公式で要確認 |
| サイバーエージェント | ミッションステートメント15項目、「素直でいい人」 | 公式で確認済み（企業/サイバーエージェント/根拠カード） |

公式の枠組みがある会社では、ESの各エピソードが、枠組みのどの項目の証拠になっているかを設計（design.md）に書く。

## 5. 面接まで通した一貫性（G8）
トップ層は、面接でESを何段も深掘りする。v1を出す時に、ES作成のSkillが次も作る。
- **想定問答**：ESの各文について「なぜ？」を3段重ね、経験DBの素材で答えを用意する。答えられない文は、ESの書き方を変えるか、深掘り候補に記録する
- **一貫性の表**：同じ会社の全設問、他社に出したES、面接で話す予定の内容で、同じエピソードの数字・時系列・役割がそろっているか
- **崩れやすい場所の警告**：推定の数字、盛りとして採用した表現、創作に近い言い回しには、面接で聞かれた時の答え方を必ず添える

## 2. ガクチカ・困難を乗り越えた経験
**G-a 6段の基本形**（外部：unistyle）
結論（何に取り組んだか）→ 動機（なぜ取り組んだか。価値観とつなげる）→ 目標と困難 → 取り組みと結果（工夫と数字）→ 人柄（行動の裏の姿勢）→ 学びと、社会での活かし方
- 弱い例：結果だけで工夫がない／「多くを学んだ」だけ／1つのエピソードに要素を詰め込みすぎ

**G-b 逆説型**（通過ES）
良い状態（雰囲気が良い・常連の居心地が良い）が、逆に課題を難しくしていた → 両方を立てる解決策

**G-c 却下 → 作り直し型**（通過ES・居酒屋デモ）

**G-d 2段階の変化型**（通過ES）
施策1で伸びた → 新しい課題（定着しない・続かない）→ 原因を突き止め直す → 理念は守りつつ調整 → 結果

**G-e キーマンを口説く型**（通過ES・伊藤忠）
全体への呼びかけという従来の手法を捨てる → キーマンを1人ずつ、相手の動機に直結する言葉で口説く → 断られても続ける → 自走する体制

**G-f 5分割型**（設問の形式。10の4）
