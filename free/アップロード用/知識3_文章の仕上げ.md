# 【07_文体と盛り】

# 文体と盛り（v1 / 2026-10-20）

通過ES・内定者ESと、実際に選考を通ってきた本人のESから作った、自然に読めるESの書き方。ES作成・ラリーの両方で使う。

## 1. 文章の流れ（自然な型）
多くの通過ESは、次の順に素直に流れている。型に当てはめることより、読み手が一度で追えることを優先する。

**ガクチカ・自己PR**
強みや取り組みを一言で → 背景（何をしていたか）→ 壁・挫折（うまくいかなかったこと）→ 反省・原因（なぜそうなったか）→ 考え方や行動の切り替え → 打ち手（2〜3個）→ 結果（数字）→ 培った力 → 再現性・入社後

**志望動機**
やりたいこと（将来の姿）→ それを持つようになった経験 → これまでやってきたこと → まだ足りないもの → それがこの会社で得られる理由 → 入社後

- 挫折や失敗から入って、考え方を切り替える流れは、人柄が伝わりやすい（「半年間売上ゼロ」→「この反省から」）。
- 結果の数字は、打ち手の後にまとめて置く。途中に数字を散らしすぎない。

## 2. つなぎの言葉
自然に読める通過ESでよく使われているもの：
しかし／そこで／この反省から／その中で／その結果／結果として／この経験を通じて培ったのは〜です／〜と確信しており、貴社においても〜

## 3. 避けること
- **口語**：「潰す」「張りつく」「会ってくれません」「〜しまくる」。書き言葉に直す（「一つずつ改善する」「付きっきりで指導する」「信頼を得られない」）。
- **否定の対比の連発**：「〜ではなく〜」は1設問に1回まで。何度も使うと、説教くさく、作った文章に見える。
- **名詞の詰め込み**：「・」でつないだ名詞を3つ以上並べない。数字は1文に2つまで。
- **体言止めの連続**、説明のない略語（GAS・KPIは一度だけなら可。読み手が分からなければ言い換える）。
- **文末の混在**：です・ます調か、だ・である調のどちらかに統一する。企業の指定がなければ、本人が普段使う方。
- 1文は60字くらいまでが目安（厳守ではない。通過ESにはもっと長い文も多い）。読みにくければ2文に分ける。

## 4. 盛りの扱い
**盛りは、ESの表現を強くするための正当な工夫で、必要な要素。** 通過ESの多くも、表現を整え、強く見せている。ただし、本人が知らないうちにAIが盛ると、面接で本人が答えられなくなる。だから、**盛りは必ず本人に提案して、本人が決める**。
盛りを禁止はしない。自己表現をうまくできることも、その人の力の1つ。ただ、生成AIのESが増えて、企業の6割は面接でESの中身を深掘りして確かめる（04）。だから、採用した盛りには必ず「面接で聞かれたら」の答えをセットにし、本人が自分の言葉で話せる状態にする。

### 盛りの種類
| 種類 | 例 | 基本の扱い |
|---|---|---|
| 言い方の盛り | 「手伝った」→「主導した」、「改善した」→「仕組みを作り替えた」 | 積極的に提案する |
| 数字の見せ方の盛り | 端数を丸める、一番良い期間・一番良い指標を選ぶ、累計で見せる | 積極的に提案する |
| 解釈の盛り | 当時は意識していなかった意図を、振り返って言葉にする（「わざと自社で全部やった」） | 提案する。本人が「確かにそう考えていた」と言えれば採用 |
| 事実の盛り | 経験DBにない出来事・数字を足す | 提案はできるが、面接で聞かれた時の答え方まで本人と決めてから採用する |

### 提案の出し方（ES作成・ラリー共通）
```
【盛り提案】
元の事実：〇〇
提案する表現：△△
良くなる点：（どの評価項目が上がるか）
面接で聞かれたら：（本人がそう答えれば一貫する、という答え方）
```
- 本人がOKしたら採用し、経験DBの該当エピソードに「ESでの表現」として記録する（他社のESや面接と一貫させるため）。
- 本人がNGなら、元の事実のまま書く。
- 同じエピソードを、会社ごとに違う数字で書かない（一貫性の監査で確認する）。

# 【12_文章の仕上げ】

# 文章の仕上げ（v1 / 2026-10-20）

ESを出す前に、最後に必ずこの観点で書き換える。07（文体と盛り）の上に重ねる。
出典：stop-slop（Hardik Pandya, MIT License, https://github.com/hardikpandya/stop-slop）、yomiyasu（MIT License, https://github.com/nanaism/yomiyasu）。どちらもAIが書いた文章の目印を、人が読む言葉に戻すためのルール。ESに合わせて要点だけを取り込んだ。

## 1. カギ括弧を減らす
- 残すのは**人が実際に言った言葉**と、正式な名称だけ。1つの設問で、カギ括弧は多くても1組にする
- 強調のためのカギ括弧（「学生の成長」「なりたい姿」）は外す
- 発話も、2つ以上あるなら間接話法にする（「〜と言われ」「〜と話してくれました」）

## 2. 物や出来事を主語にしない（人を主語にする）
- 「一人ではできないことが動き出す」「あの瞬間が私を動かす」「データが教えてくれた」のように、物や出来事に人の動作をさせない。誰が何をしたかを書く
- 受け身の文は、動作をした人を主語にして書き直す

## 3. 演出の構文を使わない
- 対比の演出：「AではなくB」「AだけでなくB」「AよりB」。言いたいBをそのまま書く
- 否定を並べてから言う：「Aでもない、Bでもない、Cだ」
- 名言のような締め：「あの瞬間が私を動かしています」「〜が事業の出発点だと学びました」。事実か、その後の行動で終える
- 3つ並べ。2つで足りるなら2つにする

## 4. AIが好む語を、ふだんの言葉にする
| 見直す語 | ふだんの言葉の例 |
|---|---|
| 土台・入口・核心・主役・両輪・〜のカギ・〜の第一歩 | 何のことかを具体的に書く |
| 勝ち筋・刺さる・定石・別物・桁違い | うまくいくやり方・響く・いつものやり方 |
| 解像度・腹落ち・熱量・温度感・肌感・言語化・軸・落とし込む・紐解く | その語が指すことを、そのまま書く |
| 潰す・倒す・溶かす・踏み込む | 直す・選ぶ・費やす・詳しく調べる |
| 本質・本質的・等身大・泥臭い | 削るか、具体的に |
| 活用する・実施する・〜を図る・〜に資する・〜が可能です・担保 | 使う・行う・〜できます |
| 圧倒的・最前線・大きな価値・新たな価値を創出 | 数字や具体的な中身に置き換える |
| 想いを重ねる・場をつくる（何の場か書かない） | 誰と誰を、何でつないだかを書く |

## 5. 読点とリズム
- 短い主語のすぐ後の読点は外す（「私は、」→「私は」）。長い主語や節のあとは残す
- 同じ長さの文を3つ続けない。文末（〜ました）が4回続いたら、1つを変える
- 1文60字までは07のとおり

## 5-2. 人事がAIだと感じる2つ（採用担当503人の調査。04）
- **洗練されているのに、具体がない文**：表現はきれいなのに、場面・数字・固有の言葉（誰が・何と言った・何をどれだけ）が入っていない文。言い方を直すのではなく、経験DBの具体に置き換える。具体がなければ、その文は削るか、本人に聞く
- **整いすぎて、誰が書いても同じ完成度に見える**：どの設問も同じ型・同じ長さの文・同じ締め。本人の口癖や、少し不器用な言い回しを残す（経験DBの「本人の比喩・口癖」）

## 6. 書き換えの手順
1. カギ括弧を数えて、1〜2組まで減らす
2. 主語が物や出来事になっている文を探し、人を主語にする
3. 対比・否定の並べ・名言の締めを、言いたいことをそのまま書く形にする
4. 4の表の語を探して直す
5. 読点とリズムを直す
6. 5-2の2つを探す（洗練されているのに具体がない文・整いすぎ）
7. 字数を数え直す
意味・数字・事実は変えない。直すのは書き方だけ。
