# 通過ES分析（v2 / 2026-10-20）

就活サイトに掲載されていた通過ES・内定者ESを、要素の単位に分けて分析した。全文を読んだのは16本（IT・SIer 5、メガバンク 1、航空 2、玩具 1、広告 1、小売 1、食品 1、デベロッパー 2、総合商社 1、総合コンサル 1）。それに加えて、商社・金融の内定者ESの冒頭 約50本と、同じ会社・同じ設問（総合商社の「将来の夢と志望理由」）への回答の冒頭 10本を比べた。個人が特定できる情報と、本文の転載は載せない。著作権と掲載元の規約に配慮して、本文は載せず、要素と傾向だけを記録する。

## 発見1：企業自身が「線」を設問にしている
- 小学校・中学校・高校・大学のそれぞれについて、自分史を200〜600字で書かせる設問（デベロッパー）
- 自分史グラフ（モチベーションの上下と、変化の理由）（玩具）
- 中長期のビジョン3つ、原動力3つ、その2つを1つにまとめた「等身大の個性」、らしさが出たエピソード6つ（苦手なことも含む）（広告）
- 「あなたはどんな人ですか」→ その人物像がよく表れたエピソード（デベロッパー）
→ 線は、ESを書くための裏の理論ではなく、**企業がそのまま設問で聞いてくるもの**。レベル3の経験DBは、この形式の設問に、そのまま答えられる状態にしておく。

## 発見2：強いESは「同じ動きが人生の中で繰り返されている」ことを証明している
- 幼少期からの習い事での挫折と雪辱 → 大学のサークル → アルバイト。同じ「失敗を糧に、泥臭く努力する」動きを3つの時期で示す（SIer）
- 小学校で副キャプテン → 中学で副キャプテン → 高校で副キャプテン → 大学で副将。「支えながら組織を変える」役割の繰り返し（デベロッパー）
- 17年間ずっと主将 → 一人ひとりと対話して組織をつなぐ → それを街づくりに（デベロッパー）
- 中学の部長 → 大学のアルバイトで先輩と後輩の橋渡し（航空）
→ 「行動のパターン」は、2つの時期以上で示せると一気に説得力が上がる。**小・中・高の深掘りは、レベル3のおまけではなく、強みを証明するための材料。**

## 発見3：原体験は、身近で小さなことが多い
- 弟が4月1日生まれ → 生まれ月による教育格差の研究テーマ（デベロッパー）
- アルバイト先の勤怠管理がITシステムで改善されたのを見た → ITで課題を解決したい（SIer）
- 海外ボランティアで、暮らしは違っても笑うツボは同じだと感じた → 人の心を動かす仕事（広告）
- 高校受験の失敗 → 厳しい環境に挑む性格（IT）
→ 原体験を聞くときは、「人生の大きな出来事は？」ではなく「**今の関心につながっている、身近な人や出来事は？**」と聞く。

## 発見4：強いESには、本人の言葉で作った表現がある
- 自分の性格を、身近な道具・アプリ・ことわざにたとえた一言や、仕事の理想像を五感で描いた一文のような、自分で作った言い回し・比喩（航空・広告・デベロッパー・総合商社）
- 各ESの「注意した点」には、「自分の言葉で」「嘘をつかない」「面接で応用が効くように本音で」という記述が繰り返し出てくる
→ インタビューでは、本人が口にした比喩や口癖を拾って残す。「自分を一言で、たとえで言うと？」を聞く。

## 発見5：志望動機の「その会社でなければ」は、現場での接点から生まれている
- インターンで社員から聞いた一言を引用 → アルバイトのレジで実際に見た購買行動 → 具体的な施策 → 2年以内に店長、その後VMD（小売）
- 何度もその会社の街に足を運んで、自分の目で見た工夫を列挙（デベロッパー）
- その会社が開発した具体的なエリア名を挙げる（デベロッパー）
→ 経験DBに「**企業・業界との接点**」（アルバイト先・インターン・店舗や施設の訪問・説明会やOB訪問で聞いた言葉）を記録する欄を作る。ESの企業固有の項目（D）の素材になる。

## 発見6：強いガクチカは「原因をどう突き止めたか」を書いている
- 参加率が下がった原因を、メンバーとの面談で特定（SIer）
- 試合映像の分析と、一人ひとりへのヒアリングで課題を特定（デベロッパー）
- 「雰囲気が良いことが、逆に問題を指摘しづらくしていた」という逆説的な難しさ（食品）
- 「規律の強化」ではなく「作品の質を上げること」に目的を定義し直した（食品）
→ 点の深掘りに「**原因をどうやって突き止めたか**」と「**目的を定義し直したか**」を足す。難しさの型に「逆説（良いことが、逆に問題を難しくしていた）」を足す。

## 発見7：深掘りが浅くても通過しているESがある
- 抽象語だけで書かれた長所・志望動機・ガクチカ（IT）
- 3つの資質を同じエピソードで書き分けているが、どれも中身が一般論（メガバンク）
→ 企業によってはESの通過ラインが低く、面接で決めている。**「通過した」は「良いES」の証明にはならない**。通過ESをお手本にするときは、内定まで行ったESと、強い要素を持つESを優先する。そして、ESが浅いまま通過すると、面接の深掘りで崩れる（00_本質原則 1）。

## 発見8：変わった形式の設問に、経験DBがそのまま効く
| 設問の形式 | 経験DBの何を使うか |
|---|---|
| 時期ごとの自分史（各200〜600字） | 年表（時期ごとに、熱中・役割・出来事・気持ち・学び） |
| モチベーショングラフ | 年表の気持ちの上下と、その理由 |
| 自分を表す言葉3つ／30字のビジョン・原動力 | 横断のまとめ（価値観・行動パターン）と、本人の比喩 |
| らしさが出たエピソード×6（苦手も含む） | 小さなエピソード集（下記） |
| 写真で自己紹介 | 小さなエピソード集の中で、写真が残っているもの |
| 10年後のニュース | 関心のある社会課題と、その理由 |
→ 深掘りの対象は、メインのエピソードだけでは足りない。**80字で書ける小さなエピソードを10個以上**集めておくと、変わった形式の設問に困らない。

## 発見9：上位企業では「線」は当たり前。差がつくのは原体験の固有さ
- 総合商社の「将来の夢と志望理由」への回答10本は、ほぼ全員が「夢 → 原体験 → その会社の手段 → 目指す姿」の線で書いていた。
- そのうち複数が、「海外で日本の製品や企業が信頼されているのを見て、うれしかった」という似た原体験だった。
- 内定した1本は、原体験の場面（訪れた国の数、そこで見た、移動に困っている人の現実）と、会社の手段（まだ開拓されていない市場での商流づくり、現場主義）が、どちらも具体的だった。本人の「注意した点」にも、「原体験となりたい社会人像を、その会社に寄せた」と書かれていた。
→ 線があるだけでは、上位企業では横並びになる。深掘りでは「その原体験は、他の就活生も持っていそう？ あなたにしかない場面・人・言葉は？」まで聞く。

## 発見10：内定者は、1つの強いエピソードを複数の会社で使い回している
- 同じ人が、課外活動を立ち上げた同じ経験を、4社の違う設問（最も打ち込んだこと／大切にしたいこと／挑戦から学んだこと／挑戦した理由）で、切り口を変えて使っていた（専門商社など）。
- 留学先のチームに一人で飛び込んだ経験を、2社（保険）で使っていた。
→ 経験DBは、浅いエピソードをたくさん持つより、**深いエピソードを少数持つ方が強い**。ES作成側の仕事は、同じエピソードの「どの面を、その会社向けに前に出すか」を決めること。

## 発見11：強みと弱みの「裏表」を、そのまま聞く設問がある
- 長所と短所をそれぞれ一言で書かせ、それを自覚した理由を行動の事実で説明させる設問（信託銀行）。内定者は、長所が「周りを見渡して全体を良くする力」、短所が「責任感が強いぶん、一人で抱え込む」という、同じ性質の裏表で答えていた。
→ 線の点検表の「強み ↔ 弱み」は、そのまま設問になる。

## 発見12：「原因の定義し直し」は、業界を問わず強いガクチカの共通点
- 部員が減った原因は、勧誘ではなく、入部した後の仕組みにあった（商社）
- 対立の原因は、評価の基準が競技の実力だけに偏っていたことだった（総合商社）
- 全員が納得しないまま物事が決まっていたことが原因だと、対話で突き止めた（信用金庫）
→ 発見6の補強。深掘りでは「最初に原因だと思っていたことと、本当の原因は違った？」を必ず聞く。

## 発見13：数字が具体的でも、動機が浅いまま通過しているESがある
- 成果の数字（偏差値の上げ幅、面談の頻度）は具体的なのに、「なぜその壁を越える必要があったか」の動機が一文で終わっているもの（メガベンチャー・インターン選考・1次通過）。
→ 発見7と同じ。数字が具体的なだけでも初期の選考は通るが、動機（線の「価値観 → 動機」）が浅いと、面接の深掘りで止まる。

## 発見14：業界ごとに、よく出る設問の形と素材の傾向
- 総合商社：「将来の夢・目標」と志望理由をセットで聞く。原体験は海外経験・留学・地元の課題が多く、そのぶん似通いやすい。
- 総合コンサル：会社の動画や事例を見た感想を書かせる。内定者は、内容の要約ではなく「つまり、この会社は〇〇という姿勢を示していると解釈した」という**自分の解釈**まで書いていた。
- 金融（銀行・証券・保険・信金）：ガクチカは、塾・予備校のアルバイトでの校舎の課題解決、飲食・小売のアルバイトでの売上改善、留学先のチームへの参加が多い。志望動機は、地域・中小企業を支える（地銀・信金）、専門性で他人の意思決定を支える（投資銀行）、成長環境（大手証券）に分かれる。
- インフラ・メーカー系：会社が定義した「求める人物像」を選ばせて、それに沿って志望動機を書かせる設問がある（SIer）。評価基準の項目D（企業固有）を、会社がそのまま明かしている例。
→ ES作成のSkillでは、設問の形から業界の傾向を参照する（02_業界別 と合わせて使う）。

## インタビューへの反映（自分史インタビュアーとSkillに入れたもの）
1. 点の深掘りに「原因をどう突き止めたか」「目的を定義し直したか」を追加
2. 難しさの型に「逆説」を追加
3. レベル2〜：「企業・業界との接点」「小さなエピソード集（10個以上、苦手なことも含む）」「本人の比喩・口癖」を追加
4. レベル3：行動のパターンを、2つ以上の時期（小・中・高・大）で確認する
5. 原体験の聞き方を「身近な人や出来事」に変更
6. 原体験の固有さの確認（「他の就活生も持っていそう？」）と、原因の定義し直し（「最初に思った原因と、本当の原因は違った？」）を追加
7. 経験DBは、エピソードの数より深さを優先する（レベル1の3エピソードを深くすることが、どの会社にも効く）
