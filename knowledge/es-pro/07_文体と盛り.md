# 文体と盛り（v1 / 2026-10-20）

通過ES・内定者ESと、実際に選考を通ってきた本人のESから作った、自然に読めるESの書き方。ES作成・ラリーの両方で使う。

## 1. 文章の流れ（15の2章が正。通過ES 236回答の実測）
**起きた順ではなく、役割の順に並べる。** 通過ESのガクチカは、1文目で立場＋行動＋成果を言い切り（63%）、そのあと課題 → 原因の見立て → 打ち手 → 結果 → 学び・活かし方（合わせて2文まで）と、判断の区切りで組む。経緯（いつ・誰に頼まれて）は独立した文にせず、1文目か課題の文の中に節として入れる。起きた順と役割の順がずれたら、役割の順を優先する。

**ガクチカ・自己PR**：見出しの1文（立場＋行動＋成果）→ 課題（数字で）→ 原因の見立て（当初は〜と考えた → 〜で〜だと分かった）→ そこで、打ち手1・2 → 結果、数字 → 学びか入社後（1文）
**志望動機**：15の2-4（やりたいこと → それを持った経験 → 業界・顧客の課題 → その会社にしかない事実 → 入社後）
**挫折・困難の設問**：挫折から入って、考え方を切り替える流れは人柄が伝わりやすい（この設問に限る）

## 2. つなぎの言葉（15の2-6。実測で多いもの）
結果、／そこで／また／その結果／この経験から／中でも／しかし。判断の区切りは「課題は〜だった」「原因は〜だと考えた」「そこで」「結果、」で示す

## 3. 避けること
- **口語**：「潰す」「張りつく」「会ってくれません」「〜しまくる」。書き言葉に直す（「一つずつ改善する」「付きっきりで指導する」「信頼を得られない」）。
- **ESとしてあり得ない表現**：方言（「〜ちゃいます」「〜やん」「〜へん」「〜ねん」）、タメ口・くだけた口調（「〜っす」「マジで」）、ネットの言い回しは、カギ括弧のセリフの中でも使わない。本人の発言を入れたい時は、書き言葉に直して地の文にする（「たまたまちゃいます？と疑った」→「偶然ではないかと疑いました」）。相手のセリフも、人事が読んで品位を下げない一言だけを選ぶ。判断の基準は「通過ESに、この一文が載っていて違和感がないか」
- **否定の対比の連発**：「〜ではなく〜」は1設問に1回まで。何度も使うと、説教くさく、作った文章に見える。
- **名詞の詰め込み**：「・」でつないだ名詞を3つ以上並べない。数字は1文に2つまで。
- **体言止めの連続**、説明のない略語（GAS・KPIは一度だけなら可。読み手が分からなければ言い換える）。
- **文体**：**既定は常体（だ・である調）**（通過ESの72%。IT・デベロッパーはほぼ全員、総合商社も9割以上）。敬体にするのは、航空の客室乗務員・小売の店舗職・外資（コンサル・投資銀行）・動画の原稿・企業の指定がある時。ES全体で統一する。敬体でも「〜ました」は2文まで続ける（15の1-2・5章）
- 1文は中央値40〜55字（実測の中央値46字）。80字を超える文は分ける。
- **感想文にしない**（15の1-6）：「〜ました」の連続、時の語（〇月・当初・すると・続けるうちに）で始まる文、時刻・分・月日などの細部の数字、打ち手の間の気持ちの文。数字はガクチカ2〜3個・志望0〜1個

## 4. 盛りの扱い
**盛りは、ESの表現を強くするための正当な工夫で、必要な要素。** 通過ESの多くも、表現を整え、強く見せている。ただし、本人が知らないうちにAIが盛ると、面接で本人が答えられなくなる。だから、**盛りは必ず本人に提案して、本人が決める**。
盛りを禁止はしない。自己表現をうまくできることも、その人の力の1つ。ただ、生成AIのESが増えて、企業の6割は面接でESの中身を深掘りして確かめる（04）。だから、採用した盛りには必ず「面接で聞かれたら」の答えをセットにし、本人が自分の言葉で話せる状態にする。

### 盛りの種類
| 種類 | 例 | 基本の扱い |
|---|---|---|
| 言い方の盛り | 「手伝った」→「主導した」、「改善した」→「仕組みを作り替えた」 | 積極的に提案する |
| 数字の見せ方の盛り | 端数を丸める、一番良い期間・一番良い指標を選ぶ、累計で見せる | 積極的に提案する |
| 解釈の盛り | 当時は意識していなかった意図を、振り返って言葉にする（「わざと自社で全部やった」） | 提案する。本人が「確かにそう考えていた」と言えれば採用 |
| 事実の盛り | 経験DBにない出来事・数字を足す | 提案はできるが、面接で聞かれた時の答え方まで本人と決めてから採用する |

### 提案の出し方（ES作成・ラリー共通）
```
【盛り提案】
元の事実：〇〇
提案する表現：△△
良くなる点：（どの評価項目が上がるか）
面接で聞かれたら：（本人がそう答えれば一貫する、という答え方）
```
- 本人がOKしたら採用し、経験DBの該当エピソードに「ESでの表現」として記録する（他社のESや面接と一貫させるため）。
- 本人がNGなら、元の事実のまま書く。
- 同じエピソードを、会社ごとに違う数字で書かない（一貫性の監査で確認する）。
