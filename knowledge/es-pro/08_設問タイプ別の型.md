# 設問タイプ別の型（v1 / 2026-10-20）

通過ES・内定者ES 約30本（コンサル・金融・総合商社・デベロッパー・メーカー・IT・航空・エンタメ・小売・化粧品）を、設問の種類ごとに分けて、強い型と弱い型を抽出した。本文は載せず、型と判定だけを記録する。通過していても弱いESは多い（06 発見7）ので、「通過した」ではなく「要素が強い」ものを型にした。

## 1. 志望動機・志望理由
**強い型**：人生の目標・夢（一言）→ それを持つようになった原体験 → なぜこの業界か → **なぜこの会社か（その会社にしかない具体名）** → 入社後に何をするか（部署・商材・地域・年次まで）
- 会社固有の具体名が入っている：開発思想の名前と具体的な地名（デベロッパー）、主力の技術基盤の名前とその特性（IT）、事業の種類と担当したい地域（海運）、自社商品の具体名と販売先の地域と健康課題（食品メーカー）
- 入社後の具体性：10年後・20年後のキャリアの段階、2年以内に店長、その後に売場づくり、のように時間軸がある
- 「自分の夢 → この会社の手段」の順で書き、「会社の説明 → 共感」の順にしない
- 本人の注意点にも「業界 → 企業 → 職種の順」「なぜ資産運用か → なぜこの会社か → どう貢献するか」「なぜこの会社か → その中でなぜこの部門か → そこで何をしたいか」と、**絞り込みの順番**を意識した記述が繰り返し出てくる

**弱い型**（通過していても、要素は弱い）
- 理念・パーパスへの共感だけ／「多様な事業」「グローバル」「社会への影響力」など、どの会社にも言える言葉
- 「持続可能な社会」「技術革新」を並べた、抽象度の高い文章（AIっぽさも強い）

## 2. インターン・コース・部門・職種の志望理由（Q2型）
**強い型**：なぜその領域か → **その会社のそのインターン（部門）で、具体的に何をするのか** → 自分の経験の何がつながるか → 何が足りず、何を確かめたい／得たいか → どう貢献するか
- インターンや説明会に参加した後なら、**現場で見たもの・聞いたことを1つ具体的に**書き、挑戦したい業務を具体名で挙げる（航空：インターンで見た困難な場面への社員の対応 → 挑戦したい業務を2つ具体的に）
- 部門を選ぶ理由は、その部門の事業の構造（市場の課題・その会社の立ち位置・使える資源）まで踏み込む（EC：国内のEC化の遅れ → 中小企業の課題 → その会社の市場シェアとポイント経済圏）
- 希望分野ごとに理由を書き分ける。「まだ決めきれないので、社員の方に業務を伺って見極めたい」という正直な書き方も、理由があれば通る（IT）
- 必要なリサーチ：インターン・部門の中身（テーマ・期間・成果物・社員の関わり）、その事業の今（伸びている所・課題）、過去の参加者の声

**弱い型**：会社の一般的な魅力（若手の裁量・成長環境）だけで、インターンの中身に触れていない

## 3. ガクチカ・最も力を入れたこと・困難を乗り越えた経験
**強い型**：想い・目標 → 課題（数字で）→ **原因をどう突き止めたか**（面談・アンケート・データ・フィードバック）→ 施策2〜3（頻度・期間・量まで具体的）→ 結果（数字）→ 学び
- 2段階の変化：施策で伸びた → 新しい課題（定着率など）→ 原因を突き止め直す → 理念は守りつつ活動を調整、の流れは特に強い
- 施策の具体性：週2日×2時間×1か月、毎週最初の30分を勉強の時間にする、役割を新設する、など
- 想いを最初に置く：「全員が本気で喜べる勝利を」「このステージに立つのが憧れだったという言葉に、成功させたいと思った」
- 他の人のセリフが1つ入ると、場面が立つ

**弱い型**：「リーダーシップとプロジェクトマネジメントのスキルを培った」のような、能力名だけで終わる学び

## 4. 自己PR・強み
**強い型**：自分らしい言い方の強み（例：「全力でおせっかいを焼いてしまう人間」）→ それが出たエピソード（想い → 施策2つ → 相手の反応・感謝の言葉）→ 仕事でどう使うか
- 強みを3つ求められた時は、それぞれ別の場面で示す
- 長所は「具体的な行動と数字」、短所は「強みの裏返し＋今やっている対策」（例：責任を抱え込みやすい → 事実と仮説を分けて整理し、一定時間で解決しなければ早めに共有する）

## 5. 価値観・人生に影響を与えた出来事
**強い型**：出来事（家族の病気、役職で一人で抱え込んだ経験、友人の口癖）→ その時の気づき → 今の行動の変化
- 他人の言葉から価値観が生まれた話（友人の「お互い様だから」）は、本人らしさが出やすい
- 弱さを認めた話（助けを求めるのが恥ずかしかった → 人を頼ることは成長のための選択）は、素直さとして評価されやすい

## 6. 変わった形式の設問
| 形式 | 強い答え方 |
|---|---|
| 行動指針から1つ選ぶ | 選んだ言葉の意味を、自分の失敗経験（相手を一方的に判断していた → 対話で背景を知った）で裏づける |
| ハッシュタグ×3 | 30字の中に動詞を入れ（想像し尽くす・揺さぶる・つなぐ）、理由でそれぞれ別の場面を示す |
| 取扱説明書 | 特徴（エピソード）＋注意事項（弱み）＋「こう声をかけてくれると力を発揮する」まで書く。少しのユーモアは可 |
| 自分を表す要素と割合 | 比重をつけて、大事な順に並べる。割合の小さい要素で、日常の小さなこだわりを見せる |
| 単語を使った自由作文 | 物語にしながら、最後に自分の価値観（変わらない価値を守る、など）に着地させる |
| 商品の企画・売り方のアイデア | テーマ／商品／時期／ターゲット／販売場所／背景（市場の数字）／内容、と項目立てで構造化する |
| 時期ごとの自分史・影響の大きい順のエピソード | 時期ごとに1行で、役割と気持ちの変化を入れる（06 発見8） |
| キャッチフレーズ | 比喩＋補足で、どんな時に発揮されるかを書く（「チームの心の火付け役」→ 劣勢の時こそ） |

## 7. 本人たちの「注意した点」から分かる書き方
- 書類選考を通ることではなく、**面接でどう聞かれても答えられるエピソード**にする。深掘りしてほしい部分に興味を持たせる（00 原則1）
- そのエピソードを知らない人に読んでもらい、分かりにくい部分を指摘してもらう
- やったことの羅列ではなく、**なぜそれをやったか**と、**その時の感情**を書く
- 他の就活生と被らないエピソードを選ぶ（06 発見9）
- 字数が少ない時は、**絶対に入れたい言葉を先に決めてから**書く
- 業界 → 企業 → 職種の順に絞り込み、他社との比較で「なぜこの会社か」を言えるようにする
- 制限字数ぎりぎりまで書く。誤字・ブランド名の表記（大文字小文字・空白・英語かカタカナか）まで確認する
