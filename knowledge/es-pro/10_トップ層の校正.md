# トップ層の校正（v1 / 2026-10-20）

トップ層の通過ES・内定者ES 約25本（総合商社 11：丸紅5・伊藤忠3・三菱商事1・その他2／外資コンサル 4：マッキンゼー3・その他1／外銀・外資運用 2／メガバンク・信託・カード 4／日系大手メーカー・IT 3）で、評価基準の「突出」を校正した。本文は載せず、型と判定だけを記録する。

## 1. ESの重みは、会社の種類で違う（ESにかける力を変える）
| 種類 | 観察 | ESの役割 | システムの方針 |
|---|---|---|---|
| 外資戦略コンサル・外資系投資銀行 | 一般論のESでも通過している例が複数ある（「圧倒的な成長機会」「論理的思考力と粘り強さ」） | 足切りの回避と、面接の台本。合否は学歴・筆記試験・面接で決まりやすい | 端的・構造的に（09の3）。面接で深掘りされる核のエピソードを1つに絞り、そこを経験DBで固める |
| 総合商社・メガバンク・信託・日系大手 | 設問が多く、構造化されている。中身で差がつく | 選考の材料そのもの。面接もESに沿って聞かれる | 設問全体で1本の線。下の2〜4を必ず入れる |

## 2. 総合商社で差がつく：学生の経験を、事業の言葉で語る
- 塾講師の経験を「新しいサービスの導入 → 収益の多角化 → 経営基盤への貢献」まで語る
- 研究を「技術を社会に実装するには事業性が必要だと痛感した」と、事業の視点につなげる
- 志望の理由を、総合商社が市場から評価されにくいという課題（事業の幅広さ・資源の景気への敏感さ）と、財務・投資家への発信という切り口から語る
- 部署の志望理由で、その商材の市場の構造（地政学リスク・需給のバランス・24時間の価格変動）まで踏み込む
→ **総合商社の評価基準には、「事業の視点（収益・事業性・市場の構造）で経験を語れているか」を、企業固有の項目として必ず入れる。**

## 3. トップ層でほぼ必須：利害の違う人を、相手の要望を組み込んで動かす
- 監督やOBの反対 → その要望を取り組みに組み込み、協力を引き出す
- 上の立場の人に却下される → お試し期間と条件を提案して承諾を得る。協力者には負担に見合う手当（見返り）を用意する
- 全体への呼びかけという従来の手法を捨て、キーマンを1人ずつ、相手の動機に直結する言葉で口説く
→ 08の「判断の分岐」と、02の「異質な他者を動かす」を、具体的にした型。評価基準のA（判断の過程）で「突出」をつける時の目安にする。

## 4. 設問の形式ごとの型
| 形式 | 強い答え方 |
|---|---|
| チームの成果を5分割（30字の見出し／背景・目的／目標／課題とアクション／結果） | 見出しは「動詞＋成果」（例：目的を定義し直し、自走する組織をつくった）。背景で原因が判明した経緯を書く。目標は**チームの目標と個人の目標の両方**で、個人の目標に経営の視点（持続する仕組み・収益）を入れる。課題の欄で、捨てた手法と、断られても続けたことを書く。結果は数字と、その後も続いていること |
| 原動力（200字）→ ガクチカ → なぜ商社・なぜその会社・なぜその部署 | 原動力は、原体験に根ざした一言と、対になる気づき（勝ちは向上心に、負けは執着心に）。原動力・ガクチカ・志望の3つが、同じ線でつながっている |
| 実績を3つ挙げる → その中から詳しく | 3つの実績を、別々の能力の証拠として配置する（専門・事業・人）。詳しく書く設問は、3つのうちの1つを、別の切り口で |
| 時期ごとの生活（小・中・高を各100字） | 時期ごとに、役割と気持ちの変化。同じ動き方が繰り返されている線（06 発見1・2） |
| 長所・短所を20字＋行動の事実200字 | 長所と短所を、同じ性質の裏表で（06 発見11）。行動の事実は、場面と数字 |
| 300字×3（学業の実績／実務経験／課外活動）の外資系 | 結論 → 前提 → 課題 → 解決策 → 結果。数字で効果を示す |
| 研究内容（800字） | 専門外の人に平易に。研究の目的（社会で何に役立つか）→ 手法 → 分かったこと → 次の課題 |

## 5. 評価基準の「突出」の具体例（校正後）
| 項目 | 突出の具体例（型） |
|---|---|
| A 判断の過程 | 従来の手法を捨てた理由と、新しい手法を選んだ理由が両方ある。断られても、相手の動機に合わせて言い方を変えて続けた |
| B 熱意（志望） | 原体験 → その会社にしかない手段、の線に加えて、その会社・業界の課題を、自分の切り口で1つ指摘している |
| C 可能性（再現性） | 個人の目標に、仕組み・持続・収益の視点がある（自分がいなくなっても回る、翌年も採用された） |
| D 企業固有（競合比較） | 競合との違いを、具体的な事実1つで言える（例：グループの顧客基盤に加え、融資業務の移管で信託業務に特化している） |
| D 企業固有（総合商社） | 学生の経験を、事業の言葉（収益・事業性・市場の構造）で語っている |
| E 本人性 | 相手のセリフ・自分が言った言葉（「あなたにしかできない役割がある」）がある |
| F 読みやすさ | 30字の見出しや20字の要約で、何をした人かが一度で分かる |

## 6. 通過していても、真似しないもの
「圧倒的な成長機会」「ダイナミックな環境」「業界一の前向きな社風」「風通しの良い爽やかな印象」「論理的思考力と粘り強さ（の自称）」。学歴・筆記試験・面接など、ES以外の要素で通っているだけで、ESとしては弱い。06 発見7と同じく、通過したことは良いESの証明にならない。
