# 通過ESの文体と構成（v1 / 2026-10-21）

通過ES・内定者ES（internal/通過ESサンプル の3ファイル）を、回答の単位に分けて数えた結果と、全部を読んで分かった書き方。ES作成・審査（ai-slop-reviewer を含む）の両方で、07・12より先にこれを見る。
本文は載せない。引用は15字以内の言い回しだけで、出典は書かない。

- 数えた範囲：重複を除いた271回答のうち、100字以上の236回答（ガクチカ67・自己PR34・志望動機74・挫折／困難10・その他51）。ガクチカと志望動機は全部を通して読んだ
- 数え方：文を「。」で区切り、文末の形で分けた（スクリプトは作業用で、ここには置かない）。設問の種類と業界は、設問文と会社名から手で分けた
- 注意：通過ESには弱いものも多い（06 発見7）。数字は「通過ESの普通」であって「上限」ではない。また「◯◯」の伏せ字が1回答あたり約1.8か所あり、その一部は数字（ガクチカで1本あたり約0.3個）

## 1章 トーン

### 1-1 言い切り方
- ガクチカ・挫折の1文目は、**「何の立場で、何をして、どうなったか」を常体の過去で1文にする**のが6割強。「〜ことです」で始めて、次の文から経緯を語る形は1割しかない
- 見出しの1文に、成果の数字を1つ入れることが多い（数字の12%は1文目にある）
- 強みの設問は「私の強みは〜だ」「〜な人間だ」と言い切る。自己PRの1文目は、能力名より、人柄が見える言い方（〜してしまう人間だ、など）に強いものが多い
- 志望動機の1文目は「〜したいから」「〜と考え、志望する」で、やりたいことを先に言い切る。「〜に魅力を感じた」から入るものは弱い（08の1と同じ）
- 文末の「〜と考える」「〜と考えている」は、常体の志望動機では普通に使われている。言い切りを避けるための「〜と思います」は少ない

### 1-2 常体と敬体の使い分け
- **既定は常体（だ・である調）**。通過ESの72%が常体で、ガクチカの文末の過半は「〜した。」
- 敬体が多いのは、①客室乗務員（航空）、②小売の店舗職、③外資のコンサル・投資銀行（英語圏の書式。「二つあります」と番号で並べる形と一緒に出る）、④動画選考の原稿、⑤長所・短所のような短い自己紹介の設問。IT・デベロッパー・総合商社では、ほぼ全員が常体
- メーカー・金融は半々。会社で決めるより、その人がES全体で統一している（1回答の中で混ぜている例はほぼない）
- 敬体で書くなら、過去の出来事の文末を「〜ました」だけにしない。通過ESの敬体の回答でも、判断・説明の文は「〜です」「〜と考えました」「〜ことが課題でした」で区切られている

### 1-3 1文の長さとリズム
- 中央値46字、半分が34〜59字の間。志望動機は少し長い（中央値54.5字）
- 1回答は6文前後（400字で7〜8文）。**1文に1つの役割**（状況・課題・原因・打ち手・結果）を持たせると、この長さに自然に収まる
- 通過ESのガクチカでも「〜した。〜した。」と同じ文末が3〜4文続くのは普通（最長の連続の中央値4）。読みにくさの原因は文末の繰り返しそのものより、**「〜ました」で出来事を順に足していくこと**。常体なら「〜だ」「〜と考えた」「〜した」が混ざり、判断の文が区切りになる

### 1-4 主語の置き方
- 「私は」は1本あたり0.7回。1文目か、打ち手の文（そこで私は〜）に1回置くのが典型。文頭が「私は」で始まる文は1本あたり0.4文
- 主語のない文は、ほぼ全部が本人の行動。チームやメンバーの変化を書く文だけ主語を立てる（メンバーが〜、参加率は〜）
- 挫折・困難では「私は」がほぼ出ない（0.2回）。状況の説明から入るため

### 1-5 具体と抽象の配分
- 通過ESのガクチカは、**状況と結果は数字で具体に、打ち手は「何を、どの単位で」まで具体に、学びは1文で抽象に**、という配分が多い
- 具体の量は、出来事の細部（時刻・何分迷ったか・誰が何年生か）ではなく、打ち手の中身（週何回・何人に・何を変えたか）に使う
- 志望動機は抽象が多い（数字が1つもない回答が74%）。代わりに、会社の固有名（事業名・技術の名前・地名・部門名）と、本人の経験の名詞で具体にしている

### 1-6 感想文との違い（何が「感想文」に見せるのか）
通過ESと対策室の出力を並べると、感想文に見せている原因は次の5つ。どれも数えられる。
1. **敬体の過去形の連続**：「〜ました」が3文以上続く（通過ESの中央値は0）
2. **時の順に並べる**：「〇月に」「初めは」「すると」「続けるうちに」で文を始める（通過ESは1本0.3文、対策室のガクチカ系は1.0文）
3. **判断の区切りがない**：「課題は〜だった」「原因は〜だと考えた」「そこで」「結果、」が書かれていない。読み手が、どこが判断でどこが出来事かを自分で切り分けないといけない
4. **出来事の細部の数字**：時刻・迷った分数・月・学年。結果の数字ではない数字が多いと、日記に見える
5. **気持ちの描写が打ち手の位置にある**：「迷いました」「不思議でした」「〜してほしいと思っていました」。通過ESでも感情は書くが、**動機（最初）か、原因に気づく場面に1回**で、打ち手の間には挟まない
- 逆に、通過ESの「感想文でない」書き方は、**出来事を「課題 → 原因の見立て → 打ち手 → 結果」の役割に割り当て、役割の順に並べ直す**こと。起きた順と役割の順がずれる時は、役割の順を優先する

### 1-7 型にはめすぎない（やりすぎの歯止め）
役割の順に組み直すと、今度は「型にはめすぎてAIっぽい」文章になりやすい（A君のQ1で、人事役2人が2人ともそう判定した）。通過ESは骨組みだけが整っていて、中身は行動と事実で書かれている。
- **理由づけを連ねない**：「〜と捉えていた」「〜と考え」「〜と判断し」「そのため」を1本に合わせて2つまで。通過ESは「そこで〜した」と行動を書き、なぜそうしたかは書かないか、短い節で済ませている
- **先回りの説明をしない**：打ち手の理由を一般論で説明しない（例：「グループでは既読だけで終わる人が多いため」）。理由は面接で聞かれる所として残す
- **本人らしさを1か所だけ残す**：本音の一言か、迷い・細部の1つ（例：最初は相手のせいにしていた、の本音）。全部消すと人物が見えず「呼びたい」と思われない。2つ以上は感想文に戻る
- **行動の細部は1つ残してよい**：3-1の「時刻・分は0」の例外。打ち手の文の中に、その人の動き方が見える細部を1つ（例：前日の夜に一人ずつ送った・送る前に毎回迷った）。人事役の比較で、細部を全部消した版は2回中3回「整っているが淡白、人物が薄い」と判定された。細部は打ち手の文の節に入れ、独立した気持ちの文にしない
- **締めを格言にしない**：「〜には見えない事情があった」「〜と学んだ」のような一般論で終えるより、結果の後の具体（その後どうなったか・自分のやり方がどう変わったか）か、結果で終える
- **定型の締めを避ける**：「この経験から〜と学んだ」で終えるなら、学びは本人の言葉に近い具体（誰の・何が分かったか）にする。結果で終えてもよい（通過ESの40%）

## 2章 設問の種類ごとの構成

文ごとの役割の記号：【見】見出しの一文／【状】状況／【課】課題（数字）／【因】原因の見立て／【判】判断（捨てた案・選んだ理由）／【打】打ち手／【結】結果（数字）／【後】その後・学び・活かし方

### 2-1 ガクチカ（最も力を入れたこと）
**基本の並び（400字・7〜8文）**
1. 【見】立場＋行動＋成果を1文、常体の過去。成果の数字はここか【結】のどちらか
2. 【状】【課】背景を1文に圧縮し、課題を数字で（〜が課題だった／〜という問題があった）
3. 【因】原因をどう突き止め、どう見立てたか（面談・アンケート・映像分析で〜が原因だと分かった／〜と考えた）
4. 【判】【打】打ち手1。「そこで」で始め、何をどの単位で変えたか。捨てた案があれば同じ文か直前に1つ
5. 【打】打ち手2（「また」「さらに」「2つ目は」）
6. 【結】「結果、」で数字。最後の2文の中に置く
7. 【後】学び1文、または入社後1文（通過ESでは結果で終わるものが40%、学びが24%。両方書くなら合わせて2文まで）

- 経緯（いつ、誰に頼まれて、どう始めたか）は【見】か【状】の中に節として入れ、独立した文にしない
- **最初に思った原因と、本当の原因が違った**話（11の核4）は、【因】を2つに分けるだけで書ける：「当初は〜が原因だと考えた」→「〜と話す中で、〜が理由だと分かった」。時系列の物語にしない
- 施策が効いた後に新しい課題が出た話（2段階）は、【課】【因】【打】【結】をもう1周繰り返す（11の G-d）
- 段落：400字ならほぼ改行なし（1本あたり1.5段落）。改行するのは、施策を番号で分ける時だけ
- 番号づけ：施策が2つ以上の時、16%が「1つ目は〜だ。」「2点目に〜」を使う。番号の文は、名詞で言い切って（1つ目はワークショップの実施だ）、次の文で中身を書く形が多い

**設問が分かれている時（背景／目標／課題とアクション／結果、のような5分割）**：1つの設問に1つの役割だけを書く。結果の設問（100字）は【結】＋持続性（翌年も続いた・仕組みとして残った）で、学びは書かないか1句。

### 2-2 挫折・困難
1. 【見】何が壁だったかを1文（〜だったことだ／〜という壁に直面した）。ここは「〜ことだ」で始めても自然（30%）
2. 【状】【課】その時の状態を数字か具体で
3. 【因】なぜそうなったか。自分の見落としを書く（ここに気持ちを1回置いてよい）
4. 【判】【打】考え方をどう変え、何をしたか
5. 【結】どこまで回復したか
6. 【後】学び（30%が学びで終わる）

### 2-3 自己PR・強み
1. 【見】強みを一言で言い切る（私の強みは〜だ／〜な人間だ）
2. 【状】【課】それが出た場面と課題
3. 【打】強みを使った行動（2つまで）
4. 【結】結果、または相手の反応（感謝の言葉）
5. 【後】入社後にどう使うか（29%）
- 長所・短所は「長所は〜だ。（行動の事実1文）。短所は〜だ。（今の対策1文）」の4文が基本形。短所は長所の裏返し（08の4）

### 2-4 志望動機
1. 【見】やりたいことを言い切る（〜したいと考え、貴社を志望する）
2. 【状】それを持った経験を1〜2文（本人の現場の名詞で）
3. なぜこの業界か（「〜だからこそ」「そのため」）
4. 「中でも」「特に」で、なぜこの会社か。会社の固有名を1〜2個（事業名・技術名・地名・部門名）
5. 【後】入社後に何をするか。最後の文は「〜したい」（72%）
- 数字はほぼ使わない（0.5個）。カギ括弧は、自分の目標の一言か、会社の標語をくくるのに使う（58%の回答に1組以上）
- 理由を2つ並べる時は「1点目は〜だ。2点目は〜だ。」。3つ並べる例は少ない

### 2-5 その他（原動力・価値観・自分史・キャッチフレーズなど）
- 原動力・価値観：言い切り → 原体験 → だからどんな場面で力が出るか。感情の語が許されるのはこの種類（11の5）
- 自分史・時期ごとのエピソード：ここだけは時系列で書く。各時期1〜2文、役割と気持ちの変化
- 変わった形式は08の6

### 2-6 つなぎの言葉の実際
| 役割の境目 | 通過ESでよく使う言葉 |
|---|---|
| 課題 → 打ち手 | そこで（ガクチカの37%） |
| 打ち手 → 打ち手 | また・さらに・2つ目は・まず〜。次に〜 |
| 打ち手 → 結果 | 結果、（46%）・その結果（21%） |
| 結果 → 学び | この経験から（21%）・この経験を通じて |
| 業界 → 会社 | 中でも（19%）・特に（16%） |
| 逆転・壁 | しかし（16%） |
- 「初めは」「すると」「続けるうちに」のような物語の言葉は、通過ESではほぼ使わない

## 3章 数字・カギ括弧・固有名の使い方

### 3-1 数字
- ガクチカは**2〜3個が目安**（平均2.1、中央値1、伏せ字分を足しても3弱）。志望動機は0〜1個
- 置く場所：【課】の数字（〜位／参加率30%）と【結】の数字（〜から〜へ）の**対になる2つ**が基本。3つ目を使うなら打ち手の量（週5回・十数人）
- 数字の多くは中の文（73%）。最後の2文に数字が続くのは16%
