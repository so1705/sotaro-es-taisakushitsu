# 判定基準（v1.1 / 2026-10-23）

ES対策室の審査と執筆の「正」。ESを書く時・審査する時は、まずこれを見る。文体の細かい数字（1文の長さ・数字の数・つなぎの言葉）は15の実測を使う。設問ごとの型（文の並び・1文目・締め・字数配分）は17を使う。15・07・11・12・17・各審査役の指示とこの基準が食い違う時は、**この基準を優先する**（0-4に一覧）。
本文は載せない。引用は15字以内の言い回しだけで、出典は書かない。

**v1.1で足したもの（監修者の2回目の判定から）**：1-9 読後の人物印象／1-10 日本語の不自然／4-5 減点（人物印象・日本語・詰め込み・無理な接続・締めの形）／2-2 強みの一文と会社の人物像／2-3 挫折の7段／4-3 熱量の接点／5-5 最終チェック6項目（17の6章）

**使い方（審査も執筆の自己チェックも同じ順）**
1. 1章の足切りを探す → 1つでもあれば「落とす（書き直し）」。素材の点は別に出す
2. 2章の必須要素（必須A）がそろっているかを見る → 欠けていれば69点が上限
3. 4章の採点表で100点をつけ、4-5の減点を引く → 通す70以上／迷う55〜69／落とす54以下
4. 難関企業なら、3章の突出の条件が2つ以上あるかを見る
5. 通す（70以上）でも、17の6章の最終チェック6項目に1つでも×があれば出さない

## 1章 足切り（1つでも当てはまれば落とす）

見つけたら、その文を引用し、どの項目かを書く。判定は「落とす（書き直し）」。素材の点（足切りが無かった場合の点）は4章で別に出す。素材が良い時は「直せば通る」と書く。

### 1-1 感情の描写の文
- **探すもの**：自分の感情・心の状態が述語になっている文。悩んだ・迷った・嬉しかった・楽しかった・悔しかった・不安だった・緊張した・大変だった・辛かった・焦った・情けなかった・感動した・眠れなかった・鳥肌が立った・慣れていった、と、その「とても」「本当に」つき
- **見分け方**：その文から感情の言葉を消すと、行動が何も残らないか。残らなければ足切り
- **例外**
  - 動機の節として1回だけ：「〜という想いから、〜を始めた」「このままでは〜と危機感を持ち、〜した」。同じ文の中に行動があり、感情がその理由になっている
  - 「〜と分かった」「〜と気づいた」「〜と考えた」は認知・判断で、感情ではない
  - 相手の反応（感謝された・笑顔で報告してくれた）は結果の事実として1回まで。ただし自分の感情（嬉しかった）を続けない
  - 設問が感情を聞いている時（原動力・価値観・モチベーショングラフ・自分史）
  - 挫折の反省・相手への申し訳なさを、行動の動機の節として1回だけ（「〜に申し訳なく、〜に一人ずつ連絡した」）。挫折では、むしろ反省が無いと4-5で減点
- **「〜したいと思った」の独立した文**は足切りではなく、型の減点（4章）。動機の節にまとめる

### 1-2 物語調・演出
- **探すもの**
  - セリフで始まる冒頭、2つ以上のセリフ
  - 比喩・見立て（いわば・まるで・〜のような・魔法・舞台・主役・武器・墓場・〜の常習犯）
  - 造語を“ ”や「」でくくって名付ける（自分で作った呼び名を地の文で使い回す）
  - 物や出来事が主語で人のように動く（あの日が私を変えた）
  - 余韻・回想の語（あの日・あの瞬間・一生忘れない・〜に立ち会えた）
  - 相手を茶化す・上から見る言い方（相手の失敗を面白がる、「発明した」）
- **例外**：自由形式の設問（キャッチフレーズ・ハッシュタグ・作文・取扱説明書）。会社の標語・商品名・制度名をくくるカギ括弧。強みの名前を一言でくくる（「相手の事情を聞きに行く力」）は1組まで可
- 冒頭のつかみが良くても、比喩が1つあれば足切り（9）

### 1-3 ポエム・キャッチコピー
- **探すもの**：中身のない決め台詞・異名（〜と呼ばれていた）、抽象名詞の連打、体言止めの連続、説明のない詩的な一文（〜は家族の小さな舞台だ）
- **例外**：キャッチフレーズを求める設問。ただしその設問でも、補足の文は行動の事実で書く（08 6）

### 1-4 話し言葉・方言・くだけた口調
- **探すもの**：方言（〜ねん・〜やん・〜へん・ほんま・〜もうた・〜ちゃう）、くだけた口調（〜っす・マジ・そしたら・〜って大事やな・〜みたいな）、心の中の独り言（ほんまにそうなん？と思い）。地の文でもカギ括弧のセリフの中でも探す
- **例外**：なし（07の3）。本人の言葉は、書き言葉に直して地の文にする
- 素材が良い時（16）は、点は素材で出し、判定は「落とす（直せば通る）」とする

### 1-5 主体性を下げる不要な情報
- **探すもの**：始めたきっかけが人任せの文（友人の紹介で・誘われて・なんとなく）、慣れ・適応の描写（最初は緊張したが慣れた）、時期と経緯だけの文（大学1年の春に働き始めた）、他人のせいにする説明。どれも**独立した文**になっているもの
- **見分け方**：その文を消しても、課題・打ち手・結果の理解が変わらないか。変わらなければ不要。不要な文が自分の主体性を下げる向き（人に連れられて・慣れただけ）なら足切り
- **例外**：任された役職・担当（店長から〜を任され、〜係を引き受け）は責任の範囲を示すので可。ただし、そのあとに自分で決めた行動が続くこと

### 1-6 日記の形（細部の数字・時の順の羅列）
- **探すもの**：結果と比べられない数字（時刻・月日・曜日・小数点の比率・学年・何分迷ったか）が3個以上／300〜400字で算用数字が8個以上／文の過半が「〇月に〜した」で始まる
- **例外**：研究の設問で条件として要る数字。設問が「期間・頻度」を書くよう指定している時
- 数字が多すぎると「勉強しかできない」人に見える（12）

### 1-7 場面ゼロ（主張だけ）
- **探すもの**：ガクチカ・自己PR・挫折・チームの設問で、いつ・どこで・何をしたかの場面が1つもない（様々な場面で・意識してきた・貴社でも、だけ）
- **例外**：20〜50字の一言の設問（長所・短所の見出しなど）

### 1-8 文体の混在
- **探すもの**：1つの回答の中に、敬体（です・ます）と常体（だ・である）の文が2文以上ずつある（通過ES 236回答中4本だけ。15の0-2）
- **例外**：カギ括弧の中の発話

### 1-9 読後の人物印象が負に倒れる（v1.1）
- **探すもの**：頑固・強気・他人を下げる・上から・言い訳・反省がない、に見える書き方（一覧と書き換えは17の4章）。特に、相手（上の立場の人・仲間・依頼主）の案や要望を**退けた・譲らなかった・押し切った・断った・変えなかった**と、自分の行動として書く文
- **足切りになる時**：次のどちらか
  - 負の印象の書き方が、1つの回答に**2か所以上**ある
  - **1文目か締めの文**にある（締めで「〜を断る時は」「〜は譲らない」と、自分の型として宣言する）
- 1か所だけで本文の中なら、足切りではなく4-5で減点
- **見分け方**：反対した人・相手が出てくる文を全部抜き出し、その人がこのESを読んで気持ちよく読めるか。通過ESでは「退けた・譲らなかった」の書き方は0本（0-3）
- **例外**：相手の案を取り入れた所・相手の懸念に応えた条件が、同じ文か次の文にあり、合意で閉じている（「〜は残しつつ、〜さんの〜を取り入れ、了承を得た」）。この形は負の印象にならない

### 1-10 日本語の不自然（1文目・締め）（v1.1）
- **探すもの**：1文目か締めの文にある、次のもの（種類と直し方は17の5章）
  - 不自然な使役：自分が主語で、相手の自発的な行動に「〜させた」（来なくならせた・離れさせた）
  - 不自然な受け身：自分の失敗を「〜された」でぼかす
  - 主語のねじれ：文頭の主語と文末の述語が合わない
  - 抽象語の連続：中身のない動詞・名詞（確かめる・作り替える・合わせる・事情・理由）が1文に3つ以上
- 1文目と締めは読後の印象を決めるので足切り。それ以外の文なら4-5で減点
- **見分け方**：声に出して1回で読み切れるか。主語と述語だけを抜き出して読み、文になっているか

### 提出の条件（足切りとは別）
指定字数の9割以上。足りない時は提出しない（足切りではなく、書き足す）。付録の24本は判定用に短く作ったので、この条件は外して当てはめた。

## 2章 合格の必須要素（設問の種類ごと）

### 2-0 共通の定義
文の役割の記号は15と同じ（【見】見出し／【状】状況／【課】課題／【因】原因の見立て／【判】判断／【打】打ち手／【結】結果／【後】学び・活かし方）。この章で足す記号：【壁】壁と越え方／【こ】こだわり／【人】人柄・熱量の文／【仕】仕組み・残ったもの／【会】なぜこの会社か／【将】将来像。

- **必須A**：欠けたら通さない（4章で69点が上限）
- **必須B**：欠けても一般の会社は通るが、大手・難関で届かない。通すの判定に「大手は届かない」と書く

監修者の言葉を、文で確かめられる形にした定義。

| 言葉 | 文で確かめる形（これが書かれていれば満たす） | 満たさない書き方 |
|---|---|---|
| (a) 施策の具体 | 1つの打ち手について、①何を（名詞で名付ける）②どの単位で（頻度・人数・時間・範囲・金額）③何から何へ変えたか（前→後）の3つ | 提案した・徹底した・工夫した・改善した、で止まる |
| (b) たまたまに見えない因果と仕組み | ①原因の見立て ②確かめ方（聞いた・数えた・見返した・記録した）③打ち手が原因に1対1で対応 ④効いた証拠（前後を同じ物差しで比べる）。さらに【仕】（自分が抜けても続いた・他に広がった・翌年も採用された）か、なぜ効いたかの理屈1句があると突出 | 観察 → 提案 → 成果が、理由なしにつながる（3店中2店が導入、だけ） |
| (c) 努力のベクトル | 【壁】打ち手を実行する時に邪魔したもの（人の反対・非協力・資源の制約・自分のやり方を変える難しさ）＋越えた方法（何を変えたか）。【こ】捨てた案と理由か、「〜は残しつつ、相手の〜を取り入れた」を1句（「譲らず」の書き方は1-9） | 諦めずに・何度もお願いして・全員を説得し、で止まる。最初の打ち手が効かなかった事実だけ |
| (d) 人柄・熱量 | 次の3つのどれかが具体的に書かれている。①**動機の理由**：なぜ自分がやると決めたか（自分の経験・立場から）を節で ②**役割を超えた行動量**：担当外・毎日・直前まで・全員に、を頻度か数で ③**相手への配慮を施策に組み込んだ工夫**：相手の事情を聞き、それに合わせて形を変えた | 感情の言葉（嬉しかった・悔しかった）、「寄り添った」「熱意を持って」の自称。これらは数えない |
| (e) 強みの再現性のロジック | ①強みを行動の型で定義（〜な時に、〜する）②根拠の場面 ③2つ目の場面か、その強みができた原点 ④仕事の場面に当てる。①〜④が同じ強みで一貫 | 強みの名前と「貴社でも活かしたい」だけ。締めで別の強みにすり替わる |
| (f) この会社でなければ | 【会】①独立した文で答える（中でも貴社は・理由は2点ある）②会社固有の事実（事業名・商品・制度・部門・地域・強み・社員から聞いた話）1〜2個 ③自分のやりたいことの手段としてつながる | 理念への共感・社風・若手の裁量だけ（どの会社にも言える）。固有の事実が最後の文の節に埋もれる |
| (g) 将来像 | 【将】職種・相手・何をするか。突出は時間軸（〇年で〜、その次に〜） | 貴社の発展に貢献したい、で止まる |

### 2-1 ガクチカ（学生時代に力を入れたこと）
並び：【見】→【課】→【因】→【判・打】（1〜2）→【壁】→【結】→【後】（15の2-1に【壁】を足す。壁は打ち手の間か直後）
| 区分 | 要素 | 満たす条件 |
|---|---|---|
| 必須A | 型 | 1文目で立場＋行動（＋成果）。役割の順。課題か原因を名指す文がある |
| 必須A | (a) 施策の具体 | 打ち手1つ以上で3要素 |
| 必須A | (b) 因果 | ①〜③がある |
| 必須B | (c) 努力のベクトル | 【壁】と越えた方法 |
| 必須B | (d) 人柄・熱量 | 3つのうち1つ |
| 必須B | 学び | 仕事で使える考え方の言葉で1文（結果で終えてもよい。通過ESの40%） |
- 200字以下は「1つの課題と1つの打ち手」でよい。必須Bは問わない（23）
- よくある不足：打ち手は具体だが人柄がない（1・13）／打ち手が名前だけ（24）／成果が理由なしに出る（20）
- 壁は「合意の形」で書く：相手の懸念を1句で認め、自分が出した条件・相手の案を取り入れた所を書き、了承・合意で閉じる（17の2-1 G2）
- 締めは17の3章の「この経験から」の形か、結果＋残ったもので終える（17の2-1 G3）

### 2-2 自己PR
並び：【見】強みの言い切り → 強みの中身（行動の型）→【状・課】→【打】→【結】→【後】仕事の場面
| 区分 | 要素 | 満たす条件 |
|---|---|---|
| 必須A | 型 | 1文目で強みを言い切る（P2の場面が先の型では、最後に強みを言い切る）。強みの一文は20字以内・動詞1つが目安（通過ESの中央値17字）。最後の文が同じ強みに戻る |
| 必須A | (e) 再現性のロジック | ①②④（根拠の場面と仕事の場面が同じ強み） |
| 必須A | 会社の人物像 | 強みが、その会社・コースの求める働き方・ポジション・人物像と同じ向きで、締めの文で入社後の姿（誰に・何をするか）が浮かぶ（v1.1。監修者の「必須の考え方」） |
| 必須A | (a) 施策の具体 | 強みを使った行動が3要素で書かれている |
| 必須B | (e)③ | 2つ目の場面か原点 |
| 必須B | (c)(d) | 壁と、人柄の出し方の1つ |
- 強みの名前は能力名（課題解決力）より、行動の型か人柄が見える言い方が強い（11 P-c）
- よくある不足：場面の重みが軽く、強みと仕事がつながらない（6）／締めが別の主張（15）／場面がない（5）
- 場面は1つが基本（通過ES 12本中10本）。(e)③の原点・2つ目の場面は、同じ種類の相手・同じ課題で同じ動き方をしている時だけ足し、「また」「このように」でつなぐ。別の場面を「〜の失敗から身につけた」と因果でつなぐのは無理な接続（4-5）。要素を全部入れるより、1つの場面を厚く（v1.1）

### 2-3 挫折・困難
並び（v1.1。監修者の7段。自分のミスの時）：①挫折の結論（何をしてしまったか）→ ②自分の役割 → ③どういう理由でミスしたか → ④原因をどう考えたか（確かめ方と、自分のどんな考え方から来たか。**ここのロジックが一番大事**）→ ⑤具体的にどう行動したか（向きを変えた。人柄・考え方・努力が見える）→ ⑥結果分かったこと → ⑦この経験からどう思ったか。外からの壁（けが・環境）の時は17の2-3 F2
| 区分 | 要素 | 満たす条件 |
|---|---|---|
| 必須A | 型 | 1文目で、何をしてしまったかを自分が主語の普通の日本語で（使役・受け身でぼかさない）。感情の独立した文がない |
| 必須A | (b) 因果 | 自分の側の原因と、確かめ方。原因が「表の理由 → その奥の自分の考え方」の2段で書かれている |
| 必須A | 反省 | 自分のやり方が原因だったと認める文がある。相手への申し訳なさは動機の節で1回まで可（1-1）。綺麗事・ポエムで締めない |
| 必須A | (c) 努力のベクトル | 何を変えたか（量ではなく向き：シュート練習から守備練習へ、など） |
| 必須B | 学び | 今も続けている行動の型（〜するようにしている） |
| 必須B | (d) | こだわり・動機の理由 |
- 「諦めずに努力した」「毎日練習した」は量で、向きではない（10）
- よくある不足：悔しさの描写で字数を使い、原因と変えたことが無い

### 2-4 チームでの役割
並び：【見】自分の役割の名前（まとめ役・橋渡し・推進役）と成果 →【課】チームの課題 →【因】→【打】自分の役割ならではの行動 → 他のメンバーの変化（主語を他者にした文を1つ）→【結】チームの成果 →【後】
| 区分 | 要素 | 満たす条件 |
|---|---|---|
| 必須A | 型 | 1文目で役割と成果 |
| 必須A | (a) 施策の具体 | 自分がした行動の3要素 |
| 必須A | 役割と影響 | 自分がいなかったら起きなかったことが1文で分かる（00の9）。主語が「私たち」だけの文が続かない |
| 必須B | (c) | 利害の違う人・上の立場の人を動かした場面 |
| 必須B | (d) | 3つのうち1つ |
| 必須B | まとめの一言 | 300字以上なら、最後に「この経験から〜」の一言（何を得たか）。無いと4-5で減点（v1.1） |

### 2-5 志望動機
並び：【見】やりたいこと＋志望する →【状】それを持った経験 → 業界・仕事の理由 →【会】中でも貴社は →【将】入社後（15の2-4）
| 区分 | 要素 | 満たす条件 |
|---|---|---|
| 必須A | 型 | 1文目で志望の理由（やりたいこと）を言い切る |
| 必須A | (f) この会社でなければ | ①②③すべて |
| 必須A | (g) 将来像 | 職種・相手・何をするか（少なくとも1つは具体） |
| 必須B | 原体験の具体 | 自分の現場の名詞と、自分がしたこと |
| 必須B | 熱量 | 現場で確かめた接点（説明会・インターン・OB訪問・店舗や施設・商品を使ってきた事実）。**人から直接聞いた話**（OB・OG訪問・社員面談・インターン・座談会）が1つあると強い。説明会だけは弱い（v1.1。通過ES 25本で説明会だけは0本） |
| 必須B | (g) 時間軸 | 〇年で〜、その次に〜 |
- 経験が良くても、会社の理由が節に埋もれると迷う（7・17）。逆に「理由は2点ある」と独立して書くと、監修者は通す（22）。対策室は独立させたうえで、固有の事実を入れる
- よくある不足：理念・社風・成長環境だけ（8）

## 3章 突出（大手・難関で通る水準）の条件

### 3-0 題材の業種・格では決めない
通過ES・内定者ESでも、塾講師・飲食や小売のアルバイト・サークルの題材が、総合商社・大手IT・メガバンクに通っている。差は題材ではなく、次の6つの厚み。例：塾の新しい個別指導の案が却下されたあと、試す期間と条件を出して通し、翌年度から正式に採用された（総合商社）。テーマパークのアルバイトで、反対意見を受けて並び方の変え方を工夫し、合意を取った（大手IT）。焼肉店で、アンケートで弱点を特定して役割を新設した（菓子メーカー）。
→ 題材を選ぶ時は「場面が具体的か」より、「下の条件をいくつ書けるか」で選ぶ（5-1）。

### 3-1 突出の6つの条件
| # | 条件 | 文で確かめる形 | 通過ESの傾向 |
|---|---|---|---|
| ① | 施策の厚み | 打ち手2つ以上が別々の原因に対応している／施策が効いた後の新しい課題に、もう1周取り組んだ（2段階）／自分が作った仕組みが、自分抜きで続いた・翌年も採用された | 内定者ESでは、結果の欄に「翌年度から採用」「自走する体制」が書かれている |
| ② | 壁の大きさ | 立場が上の人（監督・OB・塾長・社員・店長）の反対や却下／多数の非協力／良い状態が逆に障害になっていた（逆説） | 強いガクチカの約4割に反対・却下・非協力がある。逆説は06 発見6 |
| ③ | 自分の役割の大きさ | 責任の範囲（数十人以上・複数の班・予算）か、本来の担当の外まで踏み込んだことが書かれている | 見出しの文に組織の規模と役職（15の3-3） |
| ④ | 人を動かした場面 | 相手の要望を自分の案に組み込んだ／条件・試す期間・見返りを出した／全体への呼びかけをやめ、キーマンを1人ずつ口説いた／相手の言葉に合わせて言い換えた | 10の3。総合商社・外資の内定者ESにほぼ必ずある |
| ⑤ | 事業の視点 | 学生の経験を、収益・コスト・持続・顧客の先の顧客の言葉で語っている | 10の2。総合商社では企業固有の項目として必須 |
| ⑥ | 志望の突出 | 業界や会社の課題を自分の切り口で1つ指摘している／現場で確かめた接点がある／時間軸のある将来像 | 10の5 B・D、06 発見5 |

### 3-2 使い方
- **難関企業**（総合商社・外資系の戦略コンサルと投資銀行・倍率が特に高い企業。13の構造分析で決める）：4章で70点以上、かつ突出の条件が**2つ以上**。満たさなければ「迷う」にして、足りない条件を書く
- **一般の企業**：突出が0でも70点以上なら通す。ただし「大手・難関では届かない」と一言添える（監修者が4・19につけた注記と同じ）
- **大きさは書くだけでは点にならない**：「反対が多かったが全員を説得した」「劇的に改善」は、②③④の中身（どう説得したか・何を越えたか）とセットで初めて突出（14）
- 通過していても突出にしないもの：10の6

## 4章 100点の採点表

### 4-0 段階と計算
- 項目ごとに4段階：**突出＝配点の100%／十分＝85%／ある＝60%／なし＝0**。迷ったら低い方
- 合計を四捨五入せず、そのまま判定の線と比べる
- **必須Aのどれかが「十分」未満なら、69点が上限**（志望動機の将来像だけは「ある」で足りる）
- **足切りが1つでもあれば、49点が上限**。素材の点（足切りを無視した点）も並べて出す
- **4-5の減点は、項目の合計から引き、そのあとで上限（69・49）を当てる**（v1.1）
- **200字以下**のガクチカ・自己PR・チーム：壁・人柄・再現性は採点せず、残りの項目の合計を100点に換算する
- 判定：**通す70以上／迷う55〜69／落とす54以下**。難関は3-2

### 4-1 設問ごとの配点
| 項目 | ガクチカ | 自己PR | 挫折 | チームでの役割 |
|---|---|---|---|---|
| 型と言い切り | 20 | 20 | 20 | 20 |
| 施策の具体 | 20 | 15 | 15（立て直しの行動） | 15 |
| 因果と仕組み | 15 | 10 | 15（自分の側の原因） | 10 |
| 壁と努力のベクトル | 15 | 10 | 20 | 15 |
| 役割の大きさと人を動かした場面 | 10 | 10 | 5 | 20 |
| 人柄・熱量 | 10 | 10 | 10 | 10 |
| 再現性 | 10 | 25 | 15 | 10 |
| 必須A（69点上限の対象） | 型・施策・因果 | 型・施策・再現性・会社の人物像 | 型・因果・壁・反省 | 型・施策・役割 |

v1.1の必須A：自己PRの「会社の人物像」は再現性の項目で見る（強みが人物像と別の向きなら、再現性は「ある」止まり）。挫折の「反省」は因果の項目で見る（自分の側の原因を認める文が無ければ、因果は「ある」止まり）。

志望動機：型と言い切り15／原体験の具体15／業界・仕事の論理15／この会社でなければ25／将来像20／熱量10。必須Aは型・この会社でなければ・将来像。

### 4-2 各項目の段階の見え方（エピソード系）
**型と言い切り**
- 突出：次の5つ全部。①1文目で設問に答える（ガクチカは立場＋行動＋成果／自己PRは強み／挫折は壁／チームは役割）②起きた順ではなく役割の順 ③課題・原因（理由）を名指す文がある ④文頭に時の経過の語がない（〇か月たっても・その後・すると・続けるうちに・初めは。原因を確かめた節「答案を見直すと」は数えない）⑤最後の文が、結果か、1文目と同じ主張
- 十分：①②があり、③〜⑤のうち1つが欠ける
- ある：①か②が欠ける（「〜ことです」から経緯に入る・起きた順に語る）／敬体の「〜ました」が3文以上続く／「〜したいと思った」の独立した文がある／締めが1文目と別の主張・設問から逸れる
- なし：何の話か最後まで分からない・設問に答えていない

**施策の具体**（2章(a)）
- 突出：打ち手2つ以上がそれぞれ3要素そろい、うち1つは自分で作った仕組み・道具・ルール（名前がある）
- 十分：打ち手1つ以上で3要素（何を・どの単位で・何から何へ）
- ある：打ち手はあるが、中身が分からない（提案・徹底・工夫・改善止まり）か、3要素のうち2つ以下
- なし：打ち手がない

**因果と仕組み**（2章(b)）
- 突出：十分＋【仕】（自分が抜けても続いた・他に広がった・翌年も採用された）
- 十分：見立て＋確かめ方＋打ち手が見立てに対応（当初の見立てと本当の原因の違いがあれば、なお良い）
- ある：原因は書いてあるが確かめ方がない、または打ち手との対応が弱い
- なし：原因がない。観察 → 提案 → 成果が理由なしにつながり、たまたまに見える

**壁と努力のベクトル**（2章(c)）
- 突出：人の壁（上の立場の反対・却下、多数の非協力、利害の対立）を、方法を書いて越え、合意で閉じた＋こだわり（捨てた案、または残した点と取り入れた相手の案）
- 十分：打ち手を実行する時の壁が具体的で、越えた方法（何を変えたか）が書いてある。挫折では、自分のやり方の向きを変えたこと
- ある：壁らしきもの（最初の打ち手が効かなかった・厳しい状況）はあるが、越えた方法がない／「諦めずに」「何度もお願いして」「全員を説得し」止まり
- なし：壁がない（思いついて実行して成功）

**役割の大きさと人を動かした場面**
- 突出：責任の範囲が大きい（長・数十人以上・担当外まで）＋利害の違う人か上の立場の人を動かした＋成果が外にも認められた・広がった
- 十分：役割を超えて、他者（店長・監督・仲間・外部）を動かした場面が1つ
- ある：役割・担当は書かれているが、一人で完結している
- なし：自分の立場が分からない

**人柄・熱量**（2章(d)。感情の言葉は数えない）
- 突出：3つの出し方のうち2つ以上が具体的
- 十分：1つが具体的（動機の理由が自分の経験から／役割を超えた行動量が頻度か数で／相手の事情に合わせて形を変えた）
- ある：動機・配慮が一言（どうにかしたい・相手の立場で考えた）
- なし：どれもない

**再現性**
- ガクチカ・チーム ― 突出：「この経験から」で経験と結び、学びが行動の形（〜な時は〜する）で、仕事の場面に当てている／十分：「この経験から〜を学んだ・得た・考えた」の形で、中身がエピソード固有の言葉／ある：一般論（〜の大切さ・重要性を学んだ）・打ち手の言い直し・設問から逸れる・結果で終わる（ガクチカは、結果＋残ったもの〔翌年も続いた等〕で終えていれば十分）／なし：締めがエピソードと矛盾
- 自己PR（2章(e)）― 突出：①〜④すべて、かつ強みが会社の人物像と同じ向き／十分：①②④が同じ強みで一貫し、仕事の場面が会社の人物像に合う／ある：強みの名前と仕事への接続だけ・強みが会社の人物像と別の向き／なし：締めがない、または締めの主張が1文目の強みと別
- 挫折 ― 突出：「この経験から」の今の行動の形＋それが出た別の場面／十分：「この経験から〜するようになった」と今も続けている行動の形／ある：一般論（諦めない大切さ）・格言（〜にこそ本質がある）／なし：学びがない

## 5章 書く時の手順

### 5-1 題材選び
「場面が具体的か」だけで選ばない。経験DBの候補を、次の8問で点検し、答えられる数が多いものを選ぶ。
| 問い | 対応する要素 |
|---|---|
| 打ち手を2つ、名詞で名付けられるか。それぞれ、どの単位で何を何に変えたか言えるか | 施策の具体・突出① |
| 原因を、どうやって確かめたか言えるか。最初に思った原因と違ったか | 因果 |
| 自分が抜けた後も続いたもの・広がったものはあるか | 仕組み・突出① |
| 打ち手を実行する時、誰に・何に邪魔されたか。どう越えたか | 壁・突出② |
| 譲らなかった点、捨てた案はあるか | こだわり |
| なぜ自分がやると決めたかを、自分の経験から言えるか。担当の外までやったことはあるか | 人柄・熱量 |
| 自分の立場・責任の範囲はどこまでか。誰を動かしたか | 役割・突出③④ |
| 同じ動き方を、別の時期の場面でもしているか | 再現性（自己PR） |
- 題材の業種や格（コンビニ・塾・サークル）は点に入れない
- 候補が2つ以上ある時は、4章の素材の点（経験DBの事実だけの点）を比べる（13の3）。点が近ければ、突出の条件が多い方
- 答えが足りない時は、13の4の聞き方で本人に聞く。「ない」は1回で受け入れる

### 5-2 設問の意図
- 設問の種類を決め、2章の並びを選ぶ（設問に「役割」「チーム」があればチーム、「困難」「挫折」があれば挫折）
- 設問文の独自の言葉（周囲を巻き込み・前例のない・自ら課題を設定し）は、その会社が見たい要素。その要素を、必須Bから必須Aに格上げして書く（13 L5）
- 難関企業かどうかを決める（3-2）

### 5-3 構成
- 17の設問別の型から1つ選び（2〜3パターンから、素材と会社の人物像で選ぶ）、その表の並びに、経験DBの事実を1文ずつ割り当てる。1文に1つの役割（15の1-3）。表にない要素は入れない
- 字数ごとの文の数：200字＝4〜5文（課・因・打・結）／300字＝5〜6文（＋壁か人柄）／400字＝7〜8文（＋壁・人柄・後）／600字以上＝2段階か打ち手2つ（15・00の12）
- 人柄の文をどこに置くか先に決める：動機の理由は【見】か【課】の節、行動量と配慮は【打】の節。独立した感情の文にしない

### 5-4 文
- 文体は常体が既定（15の1-2）。1文46字前後、80字を超えたら分ける
- 1文目は設問への答え。課題・原因・そこで・結果、で区切る（判断の言葉は数を制限しない）
- 数字はガクチカ2〜3個・志望0〜1個。結果と比べられない数字は使わない（15の3-1）
- 比喩・セリフの冒頭・造語は使わない。セリフを入れるなら1つ、書き言葉で、課題か結果の場面に
- 大きい言葉（劇的・圧倒的・全員）を使うなら、その中身（何人が・どう変わった・どう説得した）を同じ文か次の文に書く
- 盛りは07の4のとおり、本人に提案して本人が決める

### 5-5 自己チェック（この順で）
1. 1章の足切り8つを、文ごとに探す（特に1-1は、感情の言葉を消して行動が残るか）
2. 2章の必須A・必須Bに、文の記号を振って確かめる
3. 4章で点をつける。69点以下なら、一番配点の大きい「なし・ある」の項目から直す
4. 難関企業なら、突出の条件を数える（2つ以上）
5. 15の5章のチェック（`python3 scripts/es-check.py`）と、字数9割以上
6. 設問どうしで同じ話・同じ締めになっていないか（11の0）
7. 1-9・1-10と4-5を探す：相手が出てくる文（人物印象）、1文目と締め（日本語）、型の表に余る要素（詰め込み）、2つの場面のつなぎ（接続）、締めの形
8. 17の6章の最終チェック6項目（自然さ／人柄と努力の方向性／会社の求める要素／AIっぽさがない／本人の言葉でスラスラ／面接したいか）。1つでも×なら出さない
