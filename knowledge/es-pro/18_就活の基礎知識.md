# 就活の基礎知識（v1 / 2026-10-26）

書き手（es-writer・es-pro）と審査役（reviewer-hr・reviewer-company）が、**就活の言葉を正しい意味で使い、会社の仕組みと食い違わないESを書く・見抜く**ための知識。材料は `research/就活基礎/` の5本（A 全体像とルール／B 自己分析と軸とキャリア／C 企業業界職種と配属／D 選考手法と評価／E 調査データ）。調査日はすべて2026-10-26、対象は28卒（2028年3月卒）。
16（判定基準）・17（設問別フォーマット）と食い違う時は16を優先する。このファイルは16・17の「中身の正しさ」（軸の意味・配属の現実・会社の事実）を補う。

**きっかけ（監修者の3回目の指摘）**
1. 志望動機で「目に入る所まで運ぶのが私の軸」と書いた → 軸と言えず、意味が分からない（→ 2章）
2. OB訪問で「入社直後に告知を任された」話を書き、自分も告知を担いたいと書いた → 実際は2〜3年目まで営業などから始まる可能性があり、「うちを分かっていない」と思われるリスクのヘッジがない（→ 3章）
3. 就活の用語・定義・具体例を広く深く入れてほしい（→ 4〜6章）

**確度の書き方**：高＝官公庁・提供会社・企業の公式を本文で確認／中＝公式だが検索要約のみ、または信頼できる二次資料／低＝就活メディアのみ／仮説＝調査者・編集者の推論や作例／未確認＝裏が取れていない。数字は必ず「調査名・年」をつけて使う。**未確認のものを、ESや審査で事実として書かない。**
本文の長い転載はしない。出典URLは確認先として残す。

### 0-2 まず覚える5つ（この順で効く）
1. **軸は「仕事を選ぶ基準」、志望動機は「その基準で選んだ結果、この会社」**。軸に作業や比喩を置かない（2章）
2. **新卒の配属は、多くの会社で「希望と適性を聞いて会社が決める」**。最初の仕事は営業・現場・管理・補佐が多い。キャリアプランは「入口が違っても成り立つ」形で書く（3章）
3. **社員紹介・OB訪問の話は「1人の例」**。全員の道として書かない（3-6）
4. **企業が選考で重く見るのは、コミュニケーション能力・主体性・チャレンジ精神・協調性・誠実性**（経団連 2018年度調査）。成績・専門性は低い（6章）
5. **ESは面接の台本になる**。書いた事実・会社の事実は、面接で説明できる範囲だけ（4章D-1・6章）

## 2章 就活の軸（厚く）

### 2-1 定義
- **軸＝仕事や会社を選ぶ、自分の判断基準**。条件（給与・勤務地）より、自分の価値観とキャリアの方向に根ざした基準を指すことが多い（条件も軸に含める説明もあり、定義は分かれる）
- **軸と志望動機の関係**：軸は「基準」、志望動機は「その基準で選んだ結果、この会社を志望する理由」。例：軸「若手から活躍しやすいこと」→ 志望動機「裁量権が大きく実力主義の社風だから」と具体化する（リクナビ、曽和利光氏監修 https://job.rikunabi.com/contents/howto/9956/ 確度 高）
- 編集者の言い方（作業用）：**軸＝「私は〇〇を大事にする（価値観）。だから〇〇な仕事・環境を選ぶ（仕事の特徴）」の2段**。価値観だけだと会社選びに使えず、仕事の特徴だけだと理由が無い

### 2-2 企業が軸を聞く理由
1. 価値観が自社に合うか（学生が求めるものを自社が提供できるか）
2. 話に一貫性があるか（価値観と志望理由がつながれば、入社後も意欲的に働くと期待できる）
3. 自己理解の深さ。ミスマッチ・早期離職を防ぐ
出典：リクナビ（上記、確度 高）／キャリタス https://job.career-tasu.jp/guide/selfanalysis/050/ ほか（検索要約、確度 中）
- 学生側の数字：就職先を「安易に決めた」と感じる学生は43.6%。**重視する基準が分からなかった学生では65.8%、そうでない学生は31.1%**（就職白書2025、リクルート就職みらい研究所、確度 中）。軸があると決め方の納得が違う

### 2-3 一本の線（軸と各設問の関係）
| 層 | 問い | 例（作例・仮説） | 人事が見る点 |
|---|---|---|---|
| 価値観 | 何を大事にするか | 人が「続けられる状態」を作りたい | 自己理解・本物か |
| 原体験 | なぜそう思うか | 部活で辞めかけた後輩と個別に話し、続けてもらえた | 深掘りに耐えるか |
| ガクチカ | その価値観で実際にどう動いたか | 一人ずつ面談し、練習の役割を組み直した | 思考・工夫・再現性（Why・How） |
| 自己PR | そこから言える強みは | 一人ひとりの事情を聞き、仕組みを変える力 | 仕事に合うか |
| 軸 | 仕事に何を求めるか | 人の成長や継続に長く関われる仕事 | 自社との適合・一貫性 |
| 志望動機 | なぜこの会社か | 〇〇事業・制度・社員の話が軸を満たす | 他社でなく自社の理由 |
| キャリアプラン | 入社後どうなるか | 最初は現場で〇〇を学び、数年後〇〇、長期で軸を実現 | 現実感・方向 |

- **線の引き方**：価値観（なぜ）は全設問で同じ。見せる面を設問で変える。ガクチカ＝行動の証拠／自己PR＝強みの名前／軸＝仕事への基準／志望動機＝会社への接続／キャリア＝時間の展開
- **チェック**：①同じ価値観が全設問に流れているか（言い方は変えてよい）②ガクチカの「なぜやったか」が軸の理由と一致するか ③自己PRの強みが、キャリアプランで「磨く力」と一致するか ④同じエピソードを使い回しすぎていないか（11の0）
- 根拠：リクナビ（軸＝基準／志望動機＝結果、高）、富山大学 自己分析資料（自己分析が不十分だと志望動機・ガクチカが弱くなる、高）、厚労省 job-card（キャリアプランは学生時代の努力と一貫しているかを見る、高）。表の構造そのものは調査者の整理（仮説）

### 2-4 軸の作り方（8手順）
根拠：キャリタス（自分理解→項目の書き出し→企業と照合→志望動機へ、中〜高）、ZEIN人事 一関由美子氏（本音で、過去・現在・未来で変わらないものを選ぶ。スキルは軸の中心にしない、中〜高）、富山大学（「なぜ」を重ねて価値観を取り出す、高）。下の手順はそれを統合した形（仮説）。
1. **材料を集める**：経験DB・自分史から、感情が動いた出来事を10個
2. **「なぜ」を3回**：各出来事に「なぜ嬉しかった／悔しかったか」を重ね、価値観を1文に（例：友達と話すのが好き→人の話を聞くのが楽しい→違う考えに触れられる→「多様な考えを受け入れたい」。富山大の例題）
3. **原体験を選ぶ**：価値観が最もはっきり出た経験を1〜2個。劇的でなくてよい（曽和氏「無理に探さない」）
4. **変わらないものだけ残す**：過去・現在・未来で変わらない共通項。スキル習得（英語・プログラミング）は軸の中心にしない
5. **価値観を「仕事の特徴」に翻訳する**：顧客との距離（直接か・裏方か）、関わる期間（単発か・長期か）、意思決定の位置、扱う物（形のある物・情報・お金・人）、成果の見え方（数字ですぐか・長い時間か）
6. **基準で会社を比べる**：事業・制度・社員の話で、基準を満たす理由を1社ごとに探す
7. **志望動機に落とす**：軸（基準）＋その会社ならではの根拠＋入社後に自分がすること
8. **反証テスト**：「他社でも言えるか」「軸が叶わない配属でも志望するか」に自分で答える（答えられなければ5に戻る）

### 2-5 良い軸と悪い軸の判定テスト（書いた軸を必ず通す）
書き手は軸の文を書いたら、審査役は軸の文を見つけたら、次の7問に○×をつける。**×が1つでもあれば直す。×が2つ以上、または比喩（T1）なら16の4-5 #9（または1-2の足切り）**。

| # | テスト | ×になる形 | 見分け方 |
|---|---|---|---|
| T1 | **比喩・標語になっていないか** | 「目に入る所まで運ぶ」「人の心を動かす架け橋」「笑顔の連鎖」 | 比喩の言葉を外して「誰に・何を・どの状態まで」を普通の言葉で言い直せるか。言い直した方を書く |
| T2 | **行動の言い換えにすぎないか** | 「告知を届けること」「データを分析すること」「人と話すこと」（ガクチカでやった作業をそのまま軸にした） | 「なぜその行動が大事なのか」を1回聞く。その答えの方が軸。行動は軸の証拠（ガクチカ）に回す |
| T3 | **価値観ではなく作業・職種名か** | 「営業がしたい」「マーケティングに携わる」「SNS運用」 | 職種名を消しても意味が残るか。職種は軸を満たす「手段」として志望動機で書く |
| T4 | **どの会社にも言えないか** | 「成長できる環境」「人の役に立つ」「社会に貢献」「グローバル」「人が良い」 | 志望先の競合3社の名前に差し替えても成り立つなら×。「何を・どの場面で」を足す |
| T5 | **自分の経験とつながっているか（借り物でないか）** | 受けの良さで選んだ軸。経験の裏づけが無い | 「その軸はどこから来た？」に経験1つで30秒答えられるか |
| T6 | **条件だけになっていないか** | 「安定」「福利厚生」「年収」「勤務地」だけ | 「なぜその条件が大事か」の価値観に戻せるか（例：安定→長く同じ技術を磨きたい） |
| T7 | **志望動機・キャリアプランと矛盾しないか** | 軸「顧客と直接向き合う」なのに、将来像が本社企画だけ | 軸の言葉が、将来像の文の中でも満たされているか |

- 根拠：T4はリクナビ（「他社でもいいのでは」への接点が要る、高）・マイナビ転職の採用担当者ヒアリング（「人の役に立つ」では「なぜ当社か」が見えない、中）・CROOZ 松岡弘樹氏（「成長環境」は目標と覚悟が伴わないと没個性、高。個人note）。T5はリクナビ（持っていない成長欲求を取り繕うと入社後に苦しむ、高）。T6はZEIN一関氏（中〜高）。T1〜T3は監修者の指摘と、調査で「比喩をそのまま軸にした例」の出典が見つからなかったことからの判断（仮説）
- 「成長できる環境」は最も多い軸の1つで、言葉そのものが即NGではない（内定者アンケートで最多、検索要約、中）。**ダメなのは「どの会社にも言える形のまま」**。成長を「何を・どの仕組みで」まで落とせば良い軸になる

### 2-6 良い軸・悪い軸の例（作例・仮説。自分の経験に置き換える前提）
**良い軸（価値観＋仕事の特徴＋原体験が言える）**
| 業界の例 | 軸 | 原体験からの言い換え（素朴な体験→軸の文） |
|---|---|---|
| 素材メーカー | 目に見えない部分で、他の人のものづくりを支える | 文化祭で配線の裏方 →「前に出る人が力を出せる状態を作ることに価値を感じる」 |
| 消費財メーカー | 使い手の反応が数字と声で返ってくる仕事 | バイトの手書きPOPが売上に出た →「工夫の結果が早く見える環境で試したい」 |
| 総合商社 | 立場の違う相手の間に入って、合意を作る | 留学生と日本人のサークル間の調整 →「利害が違う相手の共通点を探す役割を担いたい」 |
| 銀行（法人） | 中小企業のお金の相談を、継続して受ける | 家業の資金繰りを聞いた →「お金の面から事業の続け方を一緒に考えたい」 |
| 保険 | 起きてほしくないことの後で、人の生活を立て直す | 家族の入院時の手続き →「困った時の最初の相談相手になりたい」 |
| IT | 業務の不便を、現場の人の話を聞いて仕組みに落とす | バイト先のシフト表を改善 →「不便の原因を聞き出して形にする」 |
| コンサル | 複雑な問題を分解して、関係者が動ける形にする | サークルの運営課題を分解して担当を決めた |
| 広告・メディア | 商品の魅力を、受け手の言葉に置き換えて届ける | 学祭の集客で、相手ごとにSNSの文面を変えた |
| インフラ | 止まらないことが前提の仕事を、守り続ける | 部活の連絡網を途切れさせない工夫を続けた |
| 教育・人材 | 人が自分の強みに気づく場面に関わる | 家庭教師で生徒が自分から勉強し始めた |
| 成長を軸にする時 | 顧客に直接提案し、成否が数字で見える仕事で提案力を伸ばす | 「成長」を、成長が起きる仕組みまで落とした形 |

**悪い軸と直し方**

| 人の役に立つ仕事 | T4 | 役立つ相手・場面・方法を、自分の経験の相手から |
| ものづくりが好き | T3・T5 | 好きになった経験と、作る物の特徴（裏方か・長く使われる物か） |
| 安定・福利厚生 | T6 | 安定が大事な理由（長く技術を磨きたい等）に戻す |
| グローバルに働きたい | T4 | 海外経験の具体と、扱う商材・地域 |
| 社会の基盤を支えたい | T1・T4 | 融資・決済・送電など、支える機能の名前と経験 |
| 最先端の技術に触れたい／DXで社会を変えたい | T3・T4 | 作ったもの・現場の不便と、その解き方 |
| 華やかな業界／CMを作りたい | T3・T5 | 受け手に届けた経験と、届けて何が変わったか |
| 街づくりに関わりたい | T4 | 用地・企画・運営など、どの部分に関わるか |
| 社風が良い・人が良い | T4 | 誰と会って、何が自分の価値観と合ったか |
| 告知を届けること（行動の言い換え） | T2・T3 | 「なぜ届けたいのか」の答え（2-7） |
| 目に入る所まで運ぶ（比喩） | T1・T2 | 2-7 |

### 2-7 監修者の例の診断と直し方
**元の文**：「目に入る所まで運ぶのが私の軸」
| テスト | 判定 | 理由 |
|---|---|---|
| T1 比喩 | × | 「運ぶ」「目に入る所」が何の比喩か、誰の目か、何をか、が文から分からない |
| T2 行動の言い換え | × | ガクチカでやった「告知を届ける」作業を言い換えただけ。なぜ届けたいかが無い |
| T3 作業 | × | 価値観ではなく、作業の到達点（見える所に置く）を言っている |
| T4 どの会社にも | △ | 広告・PR・メディア・小売のどこにも言える |
| T5 経験 | ○ | 告知の経験から来ている（素材はある） |

**直し方の手順**：「なぜ目に入る所まで運びたいのか」を本人に3回聞く。答えの例（仮説）：良いものを作った人の努力が、知られないことで報われない状態を見た → **価値観**「作り手の努力が、届くべき相手に届かないまま終わる状態を変えたい」→ **仕事の特徴**「受け手の反応を見て、届け方を変えられる仕事」→ **会社**「〇〇（その会社の事業・番組・商品）で、それができる理由」。
- 書く時は、価値観の1句を【見】か【原】の節に置き、「目に入る所」という比喩は使わない。告知の経験はガクチカ・志望動機の【原】で「行動の証拠」として書く
- 本人の答えが上の例と違えば、本人の答えを使う（作例を事実として入れない）

### 2-8 面接での聞かれ方と答えの型
- 聞かれ方（確度 中：就活メディア・口コミ）：「就活の軸は」「企業選びで大切にしていることは」「その軸はどこから来た」「その軸なら他社でも良いのでは」「軸が叶わない配属でも志望するか」「軸が変わったことは」
- 答えの型（キャリタス https://job.career-tasu.jp/guide/howto/142/ を基に、仮説）：①結論「私の軸は〇〇です」1文 ②根拠の原体験（30秒）③接続「その軸が実現できる環境として貴社を見ている。理由は〇〇（会社固有の事実）」④貢献「入社後は〇〇で貢献したい」。合計1〜2分
- 「軸が叶わない配属でも？」への答えの形：軸を「部署名」ではなく「価値観と力」で持っていれば、「どの部署でも〇〇の場面はある。そこで〇〇を磨き、将来〇〇に挑みたい」と答えられる（3-4 型C）。**軸を作業・部署で書くと、ここで崩れる**
- 軸は就活中に変わってよいという見解がある（検索要約、中）。変わった時は「何を知って、なぜ変わったか」を言えるようにする

### 2-9 軸を文に置く場所（ESでの書き方）
- **志望動機（17のM1・M4）**：軸は独立した1文で「私の軸は」と書かなくてよい。1文目の「〇〇したいと考え」か、M4の【原】の「そこで育った価値観」の1句が軸の役。そこに2-5を当てる
- **「就活の軸を教えてください」の設問**：1文目で軸（価値観＋仕事の特徴）を言い切る → 原体験 → 軸を満たす仕事の特徴 → 志望先との接点（固有の事実1つ）→ 入社後。軸は2〜3個以内、順位をつけるか1文に統合（数の指定は公式資料で未確認、仮説）
- **自己PR・ガクチカ**：軸の言葉は出さない。動機の節（〜という想いから）に価値観が見えればよい
- 「軸」という単語を本文に多用しない。価値観の中身が伝われば足りる

## 3章 キャリアプランと配属の現実（厚く）

### 3-1 事実：新卒の配属はどう決まるか
**共通の事実**
- 日本の新卒は職務を決めずに一括で採り、社内で配置・育成する「メンバーシップ型」が中心という整理が多い（JIL・内閣府資料、確度 中）
- 配属は**人員計画・事業上の必要と、本人の希望・適性の調整**で決まり、希望が通らないことがあると複数の採用ページ・解説が明記（確度 中）
- 配属先は内定式・入社式・研修後に知らされることが多い。内々定から入社まで約1年分からない（カオナビ 配属ガチャ https://www.kaonavi.jp/dictionary/haizokugacha/ 確度 中〜高）
- **2024年3月卒業時点で配属先が確定していた学生は46.9%**（リクルート就職みらい研究所、J-CAST経由、確度 中）。**希望どおりでない配属は約4割、「配属ガチャに外れた」と感じる11.1%**（マイナビ 2024年調査、J-CAST経由、確度 中）
- ジョブローテーション導入企業は5割超、1000人以上では約7割（JILPT調査としてITmedia記事が紹介、検索要約、確度 中）

**配属の決まり方の型（会社ごとに確かめる）**
| 型 | 中身 | 公式で確認できた例 | ESの書き方 |
|---|---|---|---|
| ①職種・コース確約型 | 入社時に職種・初期配属が決まる | 東京海上日動のコース別採用は初期配属を確約（入社後は希望・適性でローテーション）／ADKは6職種のどれかに配属／サイボウズは選考の中で3職種から決める | その職種の仕事を具体的に書いてよい。ただし年次・役割は会社のモデルの範囲内 |
| ②研修後に会社が決める型 | 研修中に希望を聞き、適性と人員計画で決める | 三井不動産（研修中に希望調査、5月中旬配属、3〜5年でローテーション、10年で3部署ほど）／信越化学（研修終了後に最終決定）／講談社（研修後に職種決定）／東京海上日動のオープンコース（営業・損害サービス・コーポレートのいずれか） | 希望は書いてよいが、確定のように書かない。入口が違っても成り立つ形（3-4） |

出典はすべて5章の各行。確度は5章を見る。

### 3-3 書く前に調べる5つ（構造分析L4・根拠カードに入れる）
1. **採用の型**：職種・コース別か、総合職で入社後に決まるか（3-1の①〜⑤のどれか）
2. **配属の決まり方**：誰が・いつ決めるか（FAQ・募集要項の言い回しを根拠カードに）
3. **初期配属の範囲**：最初に行く可能性がある部署・職種の一覧（募集要項の「配属の可能性」「勤務地」）
4. **異動の仕組み**：ローテーションの有無と間隔、社内公募（キャリチャレ・ジョブエントリー等）、異動の条件（現部署1年以上など）
5. **若手の実例**：社員紹介・OB訪問で、1〜3年目に何をしていたか（複数人。1人だけなら「例」と書く）
- 調べても分からない時は「未確認」として根拠カードに書き、ESでは確定の書き方を避ける（3-4の型C）。本人がOB訪問・説明会で聞けるなら、質問として渡す（「配属はどう決まりますか」「1年目は何をしますか」「異動の希望はどう出しますか」）

### 3-4 決め打ちせずに熱量を出す型
熱量は「行きたい部署の名前」ではなく、**①自分の軸（価値観）②どの入口でも磨く力 ③その会社の実際の道筋 ④長期で挑みたいこと**で出す。配属の仕組みに触れるのは1句でよい（ヘッジで字数を使いすぎると熱量が下がる）。

| 型 | 使う会社 | 形（〇〇は伏せ字） |
|---|---|---|
| **型A 希望＋柔軟（ローテーション型）** | 総合職・研修後に決まる会社（3-1の②③） | 「〇〇の領域を希望している。配属は希望と適性をもとに決まると理解しており、どの部署でも〇〇の力を磨き、将来は〇〇に挑みたい。」 |
| **型B 入口理解（現場・営業から）** | 最初は店舗・支店・営業が原則の会社（3-1の⑤）・営業から始まる例がある会社 | 「最初は〇〇（営業・支店・店舗）として現場を学び、〇〇（顧客の課題・売場の数字）を身につけたい。その経験を土台に、〇年目以降は〇〇に挑戦したい。」 |
| **型C 力基準（部署を書かない）** | 配属が全く読めない会社（3-1の③④）・自己PRの締め | 「どの部署でも、〇〇（相手）の〇〇を聞き、〇〇を〇〇する力を磨き、〇〇として貢献したい。長期的には〇〇（軸）を実現する仕事を担いたい。」 |
| **型D 職種確約（具体に）** | 職種別・コース別採用（3-1の①） | 「1〜3年目は〇〇を習得し、〇年目には〇〇を担う。その先に〇〇。」年次・役割は会社のモデルキャリアの範囲内 |
| **型E 入口をつなぐ（営業が目的とつながる）** | 希望の仕事と、最初の仕事が違いそうな会社 | 「〇〇（最初の仕事：広告枠の営業）は、〇〇（自分がやりたいこと：番組を届ける）を〇〇の側から支える仕事だと理解している。まずそこで〇〇を学び、将来は〇〇に関わりたい。」 |

- 根拠：job-card（キャリアプランは経営理念・事業戦略・業務内容を理解したうえで、身につけるスキル・成果・なりたい人物を話す。「どの企業にも当てはまる答え」は避ける、確度 高）。配属希望は特定部署に固執せず、経験を通じて近づく流れで伝える（転職系ガイドの一般論、確度 中）。型A〜Eの文面は作例（仮説）
- **チェック5つ**：①最初の担当は公式情報に載っているか ②年数は会社の実例より早すぎないか ③「任されたい」でなく「担う・挑む・提案する」の能動 ④軸とつながるか ⑤**配属が違っても文が成り立つか**（部署名を別の部署に変えて読んでみる）

### 3-5 危ない書き方と安全な書き方の対
| 場面 | 危ない書き方 | なぜ危ないか | 安全な書き方 |

### 3-6 OB訪問・社員紹介の話の扱い（監修者の例）
**問題の形**：「OB訪問で、入社直後に告知を任されたと伺った。私も入社後は告知を担いたい」
- **何が危ないか**：1人の配属の例を、自分の確定の道として書いている。サイバーエージェントでは、宣伝本部に新卒が配属され1年目からSNS・番組マーケティングを担当した公式の例は2件あるが（2019年・2022年入社。うち1件は内定者バイトで同部署に約10か月いた）、広告枠の営業（BD本部）から始まる例も3件ある（2019・2021・2022年入社）。配属は「本人希望のヒアリング→適性→最終は経営判断」。母数・比率は未確認（C_企業業界職種と配属 第2部、確度 高〜中）。読み手には「うちの配属の仕組みを分かっていない」「営業になったら意欲が下がる人」に見える
- **安全な形（4つの部品）**：①聞いた事実を「その人の例」として書く ②配属の仕組みを1句で理解していると示す ③どの入口でも磨く力 ④将来挑みたいこと
  - 作例（仮説）：「OB訪問で、宣伝本部の方が1年目から番組のSNSを担当していると伺った。配属は希望と適性をもとに決まり、広告枠の営業から始まる道もあると理解している。どの入口でも、視聴者や広告主の反応を見て届け方を変える力を磨き、将来は番組を届ける仕事を担いたい。」
  - 型Eで書く手もある：「広告枠の営業は、番組の価値を広告主に伝え、番組を支える仕事だと理解している。」
- **社員の話の一般化を避ける言い回し**：「〇〇の方は〜していると伺った」（その人の事実）／「〜という例もあると知った」／「〜から始まることもあると理解している」。避ける：「貴社では入社直後に〜を任される」（全員の事実のように書く）
- 社員紹介ページも同じ。**社員紹介は活躍した人の選抜例で、平均ではない**（C2）

### 3-7 ヘッジの言い方（1句で足りる）
- 「配属は希望と適性をもとに決まると理解しており、」
- 「〇〇から始まる道もあると伺っている。どの入口でも、」
- 「まず〇〇として現場を学び、」
- 「第一希望は〇〇だが、どの部署でも〇〇の場面はあると考えている。」
- 「〇年目以降、〇〇（社内公募・ジョブエントリー等、会社に実在する制度）も活用し、」（制度名は根拠カードにある時だけ）
- 使わない：「どこでも構いません」「配属ガチャ」（俗称）、「任されたい」（受け身）、「必ず〜になる」（確定）

### 3-8 キャリアプランの時間の書き方
- **3年後・5年後・10年後**は「身につける力 → 担う仕事の幅 → 貢献」の順で段階的に（job-card、高）。数字や役職名は、会社の公開キャリアパスにあるものだけ
- 年次は会社の実例より早くしない（例：主担当まで約6か月の銀行、約5か月補佐のコンサル、2年目で既存顧客を引き継ぐ証券）
- 「なぜそのために学生時代に〜したか」と続けて聞かれる（job-card）。キャリアプランで磨く力は、自己PRの強みと同じ向きにする（2-3）

## 4章 用語辞典

各語の並び：**定義**（自分の言葉）／**例**（良い例・悪い例、または具体の場面）／**ESと面接で**（使い方・注意）／**誤解**／**確度と出典**。調査で「未確認」のものは未確認と書いた。

### A 全体像とルール

**A1 就活ルール（日程）**
- 定義：企業が広報を始めてよい日（3月1日）、面接など選考を始めてよい日（6月1日）、正式に内定を出してよい日（10月1日）の目安。国（内閣官房・文科省・厚労省・経産省）が経済団体に「要請」する形で、法的拘束力はない。ES提出・Webテストは学生に日程の裁量があるため「選考活動」と区別されている
- 例：3月1日にナビサイトで本エントリー解禁、6月から面接が本格化、10月1日に内定式。実態は大きく前倒しで、4月までに約7割、6月までに約9割が内々定（政府の関係省庁連絡会議の整理）。29卒以降は日程の見直し検討が公式に明記された
- ESと面接で：「6月解禁」を信じて準備を遅らせると、秋冬の早期選考ESに間に合わない。「いつから就活しているか」は正直に答えてよい
- 誤解：「6月前に選考を受けると違反」→ 学生側に罰則も規則もない。「経団連のルールがまだある」→ 2018年に経団連が指針の策定をやめ、今は政府要請
- 確度と出典：高。関係省庁連絡会議「2027年度卒業・修了予定者の就職・採用活動日程に関する考え方」令和7年12月26日 https://www.mhlw.go.jp/content/11800000/001640807.pdf ／内閣官房ほか「要請等について」令和8年3月24日 https://jsite.mhlw.go.jp/saga-roudoukyoku/content/contents/002616859.pdf 。倫理憲章・就職協定の経緯の細部は二次情報（中）

**A2 インターンシップの4類型**
- 定義：三省合意（令和4年6月13日一部改正）で、学生のキャリア形成支援を4つに分けたもの。タイプ1 オープン・カンパニー（説明・PR、就業体験なし）／タイプ2 キャリア教育／タイプ3 汎用的能力・専門活用型インターンシップ（就業体験必須、5日間以上・専門型は2週間以上）／タイプ4 高度専門型（試行）。**「インターンシップ」と呼べるのはタイプ3・4だけ**。タイプ3は5要件（就業体験が期間の半分超・社員の指導とフィードバック・期間・長期休暇の時期・募集要項での情報開示）を満たせば、得た学生情報を3月以降は広報に、6月以降は選考に使える
- 例：良「5日間の就業体験で、社員から『〇〇』とフィードバックを受け、〇〇を直した」／悪「1dayインターンに参加し、仕事の魅力を学んだ」をインターン経験の主役にする
- ESと面接で：インターン欄ではタイプ（何日・就業体験の有無）を区別して書く。面接では「何日・どんな業務・誰からどんなフィードバック」を言えるように。タイプ3の参加時の姿勢は評価材料になる前提で臨む
- 誤解：「1dayもインターンシップ」→ 三省合意の定義ではタイプ1（ただしナビサイト・企業は今も1dayを「インターン」と呼ぶことが多い）。「5日間なら何でもタイプ3」→ 5要件すべてが要る
- 確度と出典：高。三省合意本文 https://www.mhlw.go.jp/content/11800000/000949684.pdf ／厚労省等「令和5年度から取扱いが変わります」 https://www.mhlw.go.jp/content/11800000/000986401.pdf ／産学協議会 2024年度報告書 https://www.keidanren.or.jp/policy/2025/030.pdf 。タイプ4の学生情報の扱いの細部は未確認

**A3 1day・短期・長期インターン**
- 定義：法律上の区分ではなく期間の通称。1day＝1日完結（多くはタイプ1）／短期＝数日〜2週間（5日以上で要件を満たせばタイプ3）／長期＝数か月〜通年の実務（ベンチャーに多い）
- 例：26卒ではプログラムの82.7%が1日以下（就職白書2026、検索要約、中）。28卒の4〜9月に5日〜1週間程度のプログラムへの参加は37.1%（前年比+3.0pt、マイナビ 2028年卒キャリア意向調査、中）
- ESと面接で：長期インターンは役割・成果・数字を語れる強い題材になりやすい。1dayは「学んだこと」中心で主役には薄い。守秘義務の範囲を確認して書く
- 誤解：「長期＝有利」→ 中身次第（仮説）。「無給は違法」→ 見学・体験型なら労働者ではなく違法でない。業務をして成果が企業に帰属すれば労働者性が問題になりうる
- 確度と出典：中。マイナビキャリアリサーチLab https://career-research.mynavi.jp/reserch/20261023_116376/ ／厚労省 労働者性の通達 https://www.mhlw.go.jp/content/001462702.pdf

**A4 早期選考**
- 定義：政府日程（6月選考開始）より前に、インターン参加者や特別ルート（リクルーター・スカウト・推薦）の学生に限って行う選考の通称。制度名ではない。公式の例外は専門活用型インターン（2週間以上）参加者の6月前選考だけ
- 例：26卒の56.7%が早期選考に参加、企業の実施は67.0%。卒業前年の2月までに内々定を出し始めた企業は17卒の約1%→26卒の約40%（就職白書2026、検索要約、中）。インターン参加者の約7割が早期選考の案内を受ける（政府連絡会議、高）
- ESと面接で：早期選考のESは、インターンで見せた姿勢・学びと矛盾しない内容にする（同じ人を二度評価する）。「そのインターンで何を見て、何が決め手になったか」を深く問われる
- 誤解：「早期で受かると他社を受けられない」→ 他社の活動をやめさせるのはオワハラ（A14）。断ってよい
- 確度と出典：高〜中。連絡会議「考え方」（A1）／就職白書2026 https://shushokumirai.recruit.co.jp/white_paper_article/20260220001/

**A5 本選考**
- 定義：通常の採用枠の正式選考。ES・Webテスト → 面接（複数回）→ 内々定
- 例：4月までに累計約9割が面接を受け約7割が内々定（政府連絡会議）。就活に9か月以上かかった学生は令和2年度約3割→令和6年度約5割（同）
- ESと面接で：早期選考の延長でなく、その会社の設問・字数に合わせて作る。参加企業ならインターン時の評価が組み込まれている可能性
- 誤解：「6月が本選考のスタート」→ 実質はそれ以前に進む
- 確度と出典：高（連絡会議）。キャリタス就活 https://job.career-tasu.jp/guide/howto/schedule/ （中）

**A6 通年採用**
- 定義：卒業年度の春夏の一括採用に限らず、通年で応募を受けて採る方式。日本はまだ一括採用が中心
- 例：政府は海外留学者・既卒者に「通年採用も含め様々な機会」を、**卒業後少なくとも3年以内の既卒者は新卒枠に応募できるよう**要請（令和8年3月）。具体的な企業名の実例は未確認
- ESと面接で：留学・休学の経緯と入社時期を、自分の言葉で説明できるように
- 誤解：「通年採用が普及していつでも受かる」→ 秋冬・既卒採用の規模は春夏より限定的（産学協議会）
- 確度と出典：高。経団連「今後の採用と大学教育に関する提案」2018年12月 https://www.keidanren.or.jp/policy/2018/113_honbun.html ／政府要請（A1）

**A7 秋冬採用・既卒応募**
- 定義：卒業年度の10月以降に行う採用、卒業後の応募（卒後就活）
- 例：産学協議会（2025年5月）は秋冬・既卒採用を拡大する方向で合意。企業側の課題は4月入社までの配属決定・研修。具体的企業名は未確認
- ESと面接で：「なぜ今まで内定がないか」を聞かれうる。進路を見直した・研究を優先した、など一貫した理由を。「なぜその会社が残ったか」を示すと強い
- 誤解：「秋冬は残り物」→ 満足のいくマッチングの例も少なくないと産学協議会は記載。ただし枠は少ない傾向
- 確度と出典：高。産学協議会 2024年度報告書 https://www.keidanren.or.jp/policy/2025/030.pdf

**A8 推薦（学校推薦・教授推薦）と自由応募**
- 定義：学校推薦＝大学・学部経由で企業の推薦枠に学内選考して推薦。教授推薦＝研究室と企業の関係の枠（理系に多いとされる、仮説）。自由応募＝学生が直接応募する通常ルート
- 例：学習院大学は2026年4月から、自由応募の学生に推薦状を発行しない方針を企業に通知（内々定の辞退防止に使われ職業選択の自由を妨げる恐れ、と理由を説明）
- ESと面接で：推薦でもESと面接は普通ある。推薦の内定は辞退しにくい慣行なので、応募前に第一志望か決める。自由応募の途中で推薦状を求められたらキャリアセンターに相談
- 誤解：「推薦は100%受かる」→ 学内選考も企業選考もある（内定率の数字は出典が弱く未確認扱い）。「推薦を断ると法的に問題」→ 辞退は法的に自由。大学との信頼の問題は残る
- 確度と出典：高（学習院 https://www.univ.gakushuin.ac.jp/career/docs/3a022cc325d8a688798fb152ac135be308667dc5.pdf ）。教授推薦の公的定義は未確認

**A9 リクルーター面談**
- 定義：企業側が学生に声をかけて行う面談。多くは同じ大学の若手社員。雑談風でも選考の一部のことがある
- 例：リクルーターとの接触は26卒で19.1%、24卒17.6%（就職白書、検索要約、中〜低）
- ESと面接で：面接と同じ準備で臨む。ESと話す内容をそろえる。位置づけが分からなければ「選考の一部ですか」と確認してよい
- 誤解：「選考ではない」→ 選考に影響しうる。「OB訪問と同じ」→ 主導が違う（企業主導がリクルーター、学生主導がOB訪問）
- 確度と出典：中〜低。公的・学術資料による定義と評価の実態は未確認

**A10 OB・OG訪問**
- 定義：学生が自分から、志望先で働く先輩に会い、仕事や職場の話を聞く活動
- 例：実施割合は26卒16.7%、24卒15.2%（就職白書、検索要約、中〜低）。28卒は3年10月ごろから始める学生が多い（キャリタス、中）
- ESと面接で：志望動機の熱量の根拠になる（16の4-3。通過ES 25本で社員と直接の接点は7本、説明会だけは0本）。**ただし聞いた話は「その人の例」として書く（3-6）**。社名の内部情報・個人名は出しすぎない。質問の準備なしに会うと評価が下がることもある（民間記事、仮説）
- 誤解：「しないと不利」→ 実施率は2割未満で必須ではない。「選考と無関係」→ 企業によっては人事に共有される
- 確度と出典：中〜低。就職白書 https://shushokumirai.recruit.co.jp/white_paper_article/20260220001/

**A11 座談会・説明会**
- 定義：座談会＝社員数人が学生に仕事・社風・選考を話すイベント。説明会＝企業の会社説明。多くはタイプ1（オープン・カンパニー）に当たる（仮説）
- 例：オープン・カンパニー参加後に志望度が上がった学生67.5%（マイナビ 2026年卒総括、中）
- ESと面接で：座談会で社員に質問して得た話は「人から直接聞いた話」として使える。説明会の話だけを根拠にすると弱い（16の4-3）
- 誤解：「選考に関係ない」→ 出席がエントリー条件の企業もある（要確認）
- 確度と出典：中。公的な定義は未確認

**A12 内々定・内定**
- 定義：内々定＝10月1日より前に口頭・メールで出す合格の意思表示。内定＝10月1日以降の正式な内定で、法的には「始期付解約権留保付労働契約」が成立しているとされる（最高裁 大日本印刷事件 昭和54年7月20日）。取消しは客観的に合理的で社会通念上相当な場合に限られる
- 例：内々定の取消しで契約成立は認めず、信義則違反として損害賠償を認めた裁判例（コーセーアールイー事件 福岡高裁 平成23年3月10日）。26卒の大学生の就職内定率（2月1日）92.0%（文科省・厚労省 就職内定状況調査）
- ESと面接で：「他社の選考状況は」に事実で答える。「第一志望」と言ってよいかは本当にそう思うか（後で撤回が要る発言を避ける）
- 誤解：「内々定も内定も同じ」→ 内々定は契約成立が認められない例がある
- 確度と出典：高。厚労省「確かめよう労働条件」 https://www.check-roudou.mhlw.go.jp/hanrei/saiyo/torikeshi.html ／文科省 https://www.mext.go.jp/b_menu/toukei/chousa01/naitei/kekka/k_detail/1422624_00026.htm

**A13 内定承諾・内定辞退**
- 定義：承諾＝内定を受ける意思を伝え、承諾書・誓約書を出すこと。辞退＝内定を断ること。期間の定めのない労働契約を労働者側から解約する扱いで、民法627条により申入れから2週間で終了すると説明される
- 例：企業側は採用予定数100に対し内定出し184.9、辞退88.5（就職白書2026、充足企業の値、検索要約、中）
- ESと面接で：承諾書に署名する前に条件を確認する。辞退は早めに、丁寧に
- 誤解：「承諾書を出したら辞退できない」→ 法的には辞退の自由がある（違約金請求は違法となりうる、民間解説、中〜低）
- 確度と出典：中〜高。東京都労働相談情報センター https://www.hataraku.metro.tokyo.lg.jp/shiryo/r7_2-4_naiteityunokensyuu.pdf

**A14 オワハラ・オヤカク**
- 定義：オワハラ＝内定・内々定と引き換えに他社の就活をやめるよう迫る、意思に反して就活を終わらせること。オヤカク＝辞退防止のため内定承諾に保護者の同意を強要すること。厚労省の指針（平成27年告示406号）で「行わないこと」とされる
- 例：就活エージェントが内々定後に他社の就活終了を迫る例を、政府が要請文の脚注で挙げている
- ESと面接で：「今ここで承諾を」「他社を断って」と迫られたら、その場で応じず「持ち帰って検討します」。相談先はキャリアセンター、労働局・ハローワーク
- 誤解：「オワハラ自体に罰則がある」→ 直接罰する法律はない（内容次第で強要罪等になりうるという説明は民間解説、仮説）
- 確度と出典：高。政府要請 令和8年3月24日 脚注7〜9（A1）／静岡産業大学 https://ssu.ac.jp/media/shuukatuagent.pdf

**A15 ナビサイト・プレエントリー**
- 定義：ナビサイト＝学生が登録し、企業の募集を見て応募する就職情報サイト（リクナビ・マイナビ・キャリタス就活など）。本エントリーは3月以降、それ以前は「プレエントリー」「インターンシップエントリー」と分けている
- 例：政府はプレエントリーが早期化・二分化の一因になっていると指摘（連絡会議）。27卒の9月時点の平均はエントリー24.3社、応募16.5社（キャリタス、中）
- ESと面接で：ナビ経由のESでも、企業ごとに設問に合わせて書く
- 誤解：「ナビに載っていない企業は受けられない」→ 企業HP・大学・エージェント経由もある
- 確度と出典：高（連絡会議）

**A16 逆求人（スカウト型）**
- 定義：学生がプロフィールを登録し、企業が見て声をかける方式
- 例：企業側の良かった点「他のサービスでは出会えない学生に出会えた」52.8%（リクルート企業調査 23卒、検索要約、中）。学生側の利用割合の最新値は未確認
- ESと面接で：プロフィール欄がESの代わりに読まれる。ESと同じ経験・同じ主張で書く。「なぜ声をかけたか」を聞いておくと志望動機が作りやすい
- 誤解：「スカウト＝内定に近い」→ 一括送信もある。選考免除かは文面で確認
- 確度と出典：中

**A17 就活エージェント**
- 定義：学生に無料で相談・求人紹介をする民間の職業紹介事業者。企業からの紹介料で成り立つ（一般的な説明。職業安定法の許可制度の一次資料は未確認）
- 例：大学が挙げた問題：説明のない登録の促し、希望と違う業種の紹介、内定辞退を認めない説得（静岡産業大学）
- ESと面接で：エージェントの添削は誰が書いても同じ型になりやすい。自分の言葉で話せる範囲に直す。内定の可否・辞退は自分で決める
- 誤解：「学生に有利な会社を選んでくれる」→ 紹介料が企業から出る構造のため、希望と一致しない場合がある
- 確度と出典：高（静岡産業大学・政府要請）

**A18 卒年の呼び方（28卒）**
- 定義：28卒＝2028年3月卒業予定。政府文書では「2027（令和9）年度卒」。文書で呼び方が揺れる
- 例：28卒の4〜9月のキャリア形成活動参加率82.7%（マイナビ）。学生がESを最初に出した時期は卒業前年度の9月以前が約4割（政府連絡会議）
- ESと面接で：28卒は今（2026年秋冬）がちょうど秋冬インターン・早期選考の入口。ここで本選考用のガクチカ・自己PRを一度固める
- 誤解：「2028年度卒＝28卒」→ 政府文書の「2028年度（2029年3月）以降」は29卒以降
- 確度と出典：高（連絡会議）・中（マイナビ）

### B 自己分析と設問の概念

**B1 自己分析**
- 定義：自分が何を選び、なぜそう選んだかを言葉にし、軸・強み・価値観の材料にする作業。手法が違っても共通は「なぜ」を掘ること
- 例：良「なぜ」を3回重ねて価値観を取り出す（富山大の例題）／悪：グラフの山と谷を書いて終わり。谷の時に何を考え、どう動いたかが無い
- ESと面接で：結果をそのまま書くことはない。軸・ガクチカ・自己PRの根拠として使う。手法名はESに不要
- 誤解：「全部やってから就活開始」→ 曽和氏は、今は軸がない状態を受け入れて企業情報に触れ続けてよいと述べる。キャリタスは「7割の完成度で実践に移す」
- 確度と出典：高。富山大学 https://www.u-toyama.ac.jp/wp/wp-content/uploads/7d26c347d559afb507eb5e3a11bd4888.pdf ／リクナビ https://job.rikunabi.com/contents/howto/9956/ ／キャリタス https://job.career-tasu.jp/guide/selfanalysis/138/

**B2 自分史**
- 定義：生まれてから今までの出来事を時系列に書き、その時どう考え、どう動いたかを見る
- 例：良「中学で部活を辞めかけた → 先輩に個別に話を聞いてもらい続けた → 今、後輩の話を聞く側にいる」と、選択の理由がつながる／悪：出来事の年表だけ
- ESと面接で：経験DB（自分史インタビュー）の元。原体験（B8）を探すのに使う
- 誤解：「劇的な出来事が要る」→ 小さな経験でも理由が言えればよい
- 確度と出典：中（複数大学の資料で手法名が一致）

**B3 モチベーショングラフ・ライフラインチャート**
- 定義：横軸に時間、縦軸にやる気・充実度をとった折れ線。上下の「理由」から、熱中できる条件を探す。キャリタスは「ラインチャート」と呼ぶ
- 例：良：山の時に共通する条件（人と一緒に作る時・成果がすぐ見える時）を言葉にする／悪：山と谷の高さだけ
- ESと面接で：設問が「モチベーショングラフ」を求める時は、感情を書いてよい（16の1-1の例外）。それ以外の設問では、取り出した条件を軸の材料にするだけ
- 誤解：「グラフを書けば自己分析が終わる」→ 理由を書くまでが作業
- 確度と出典：中〜高（キャリタス本文確認）。厚労省ジョブ・カード活用ガイドの記入例は本文未確認

**B4 ジョハリの窓・他己分析**
- 定義：ジョハリの窓＝自分が知っている／他人が知っているの2つで自分を4つの窓に分け、自他の認識のズレを見る枠組み。他己分析＝家族・友人・バイト先に自分の強みと性格を聞き、自己評価と比べる
- 例：良：3人以上に「どんな場面でそう思った？」と具体を聞く／悪：褒め言葉を集めて終わり
- ESと面接で：自己PRの強みの名前を、他人の言葉で裏づけられる。「周りからは〇〇と言われる」は面接で使える
- 誤解：「他人の評価が正しい」→ 自己評価とのズレを見る材料
- 確度と出典：中（キャリタス）

**B5 Will-Can-Must**
- 定義：やりたいこと（Will）・できること（Can）・求められること（Must）の重なりを探す枠組み。大学資料では「Want・Can・価値観」と表記されることもある
- 例：良：Will「人の継続を支えたい」、Can「一人ずつ話を聞いて仕組みを変えられる」、Must（会社が若手に求める）「顧客の課題を聞く営業」→ 重なりが志望動機と自己PRの線になる
- ESと面接で：Mustを会社の求める人物像（C24）と若手の仕事（3-2）で埋めると、自己PRの締め（17の2-2）が会社に合う
- 誤解：「Willだけ強ければよい」→ Mustを無視するとキャリアプランが現実と離れる
- 確度と出典：中。発祥と標準的な定義は未確認

**B6 診断ツール（MBTI・強み診断）**
- 定義：質問に答えて性格・強みの傾向を出す診断。キャリタスはMBTI（93問）、自社の適職診断、厚労省「job tag」などを挙げる
- 例：良：診断の言葉を候補にし、当てはまるエピソードを経験DBで探す／悪：「診断で〇〇タイプと出たので」をESの根拠にする
- ESと面接で：診断結果をESに書かない。エピソードの裏づけが要る
- 誤解：「診断の結果が自分」→ 材料の1つ（仮説）。ストレングスファインダーの公式定義は未確認
- 確度と出典：高（キャリタス https://job.career-tasu.jp/guide/selfanalysis/138/ ）

**B7 価値観**
- 定義：何を大切にして選び、行動するかの基準。軸の土台
- 例：良「人が続けられる状態を作りたい」（経験から言え、仕事の特徴に翻訳できる）／悪「誠実でありたい」（誰でも言え、会社選びに使えない）
- ESと面接で：志望動機M4の【原】で1句。全設問で同じ価値観が流れるのが一本の線（2-3）
- 誤解：「立派な価値観ほど良い」→ 経験とつながっているかが大事
- 確度と出典：中（富山大の手法、リクナビ）

**B8 原体験**
- 定義：価値観や軸の元になった、自分の実際の経験
- 例：良：自分の行動が変わった具体的な出来事と、その時の判断があり、そこから今の軸が出る／悪：感動的な出来事を述べるだけで、今の軸や会社とつながらない。盛ったドラマ
- ESと面接で：志望動機の【状】【原】。劇的でなくてよい。面接で「その時何を考えた」と掘られる
- 誤解：「劇的でないと軸が作れない」→ 曽和氏「無理に探さない」
- 確度と出典：中。原体験と志望動機の結びつけ方を人事が直接述べた一次資料は未確認

**B9 就活の軸** → 2章

**B10 ガクチカ（学生時代に力を入れたこと）**
- 定義：ほとんどの会社が聞く設問。何を頑張ったかより、なぜ・どう工夫したかを伝える
- 例：良：原因を聞いて確かめ、打ち手を原因に合わせ、結果を前後で比べる（16の2-1）／悪「ゼミのリーダーとしてチームをまとめた」（役職だけ）、留学そのものを題材にして自分の行動が無い
- ESと面接で：サイバーエージェントの採用人事 田内貴大氏は、見るのはWhatでなくWhy（どんな思いで）とHow（どんな工夫を）、人事が知りたいのは「モチベーションの源泉」と「性格・強み」と述べる。型は16・17
- 誤解：「成果が大きいほど良い」→ 田内氏は客観的にすごい実績である必要はないと述べる。「求める人物像に合わせて盛る」→ 深掘りで崩れる
- 確度と出典：高。サイバーエージェント公式動画 https://www.cyberagent.co.jp/careers/students/biz/video/detail/id=29859 ／リクナビ https://job.rikunabi.com/contents/howto/18900/

**B11 自己PR**
- 定義：入社後に活躍できる根拠を示す設問。強み → 根拠の場面 → 仕事の場面
- 例：良：強みを先に言い、数字つきの場面1つ、締めで会社の仕事に当てる／悪：コツコツ型を求める会社に「好奇心旺盛で行動力がある」だけ（リクナビ）
- ESと面接で：強みは会社・コースの求める人物像から選ぶ（16の2-2）。締めの入社後の姿は、配属が違っても成り立つ形（3-4 型C）
- 誤解：「自己PR＝ガクチカの言い換え」→ ガクチカは何に力を入れたか、自己PRはそこから言える強み（仮説）
- 確度と出典：高（リクナビ https://job.rikunabi.com/contents/entrysheet/11441/ ）。長所・短所の新卒向け公式資料は未確認

**B12 長所・短所**
- 定義：人柄と、自分を客観視できているかを問う設問（転職系メディア中心の整理、中〜低）
- 例：良：短所は長所の行き過ぎ（慎重すぎ・抱え込み）＋今の対策（通過ES 4/4）／悪「特になし」、仕事に致命的な短所（時間を守れない）
- ESと面接で：17の2-6
- 誤解：「短所は隠す」→ 自覚と改善の行動がセットなら評価材料になる（仮説）
- 確度と出典：中〜低

**B13 志望動機**
- 定義：その会社を志望する理由。**軸＋その会社ならではの根拠（事業・制度・人・体験）＋入社後に自分がすること**
- 例：良：経験から来た軸 → 軸を満たす事業・制度の具体 → 入社後（最初は現場で学び、将来こう貢献）／悪「人の役に立ちたい」「業界トップだから」「成長できるから」だけ
- ESと面接で：軸だけだと他社でも言え、会社の根拠だけだと「なぜあなたが」が無い（リクナビ）。型は17のM1〜M4、軸は2章、入社後は3章
- 誤解：「志望動機＝憧れ・好き」→ 感想文にならないよう軸と貢献を入れる
- 確度と出典：高（リクナビ）・中（マイナビ転職 https://tenshoku.mynavi.jp/knowhow/shibodoki/ng/ 、転職向け）

**B14 入社後やりたいこと・キャリアプラン** → 3章
- 定義：入社後に何を身につけ、どんな仕事をし、どんな人になりたいかの道筋（3年・5年・10年）
- 確度と出典：高。厚労省 job-card https://www.job-card.mhlw.go.jp/column/student/job-hunting

**B15 ビジョン**
- 定義：自分が実現したい状態・社会・仕事の姿。キャリアプランより抽象度が高く長期
- 例：良「地域の中小企業が、資金を理由に事業を畳まなくてよい状態」（何がどうなるかが見える）／悪「社会をより良くしたい」
- ESと面接で：会社の理念と大きくずれていないかが見られる（job-card）
- 誤解：「大きいほど良い」→ 会社の事業で近づけるかが大事
- 確度と出典：中

**B16 ポテンシャル採用**
- 定義：今のスキルより、学習意欲・成長可能性・人柄・論理的思考力など将来の伸びしろを見て採ること。新卒採用の性格を指す。専門知識は入社後の研修・OJTで身につける前提
- 例：良「未経験の分野でも、自分から情報を集めて短期間に〇〇できた」（学び方の再現性）／悪「未経験なので何でも頑張ります」（根拠のない意欲）
- ESと面接で：結果より、思考の過程と行動の再現性を書く
- 誤解：「何も見られていない」→ 思考と行動の再現性を見ている
- 確度と出典：中（カオナビ https://www.kaonavi.jp/dictionary/potential_saiyo/ 検索要約）

**B17 再現性**
- 定義：ガクチカで見せた行動の理由・やり方が、入社後の違う場面でも出るか。思いつきでなく狙って行動したと分かれば「思考力の高さや再現性」を示せる（リクナビ）
- 例：良「原因を聞いて確かめてから動く」が2つの場面で同じ形で出ている／悪：運や環境のおかげの成果
- ESと面接で：16の2章(e)・4-2の再現性。締めは「この経験から」で結ぶ
- 誤解：「同じ業界の経験が要る」→ 行動の型が同じなら業界は問わない
- 確度と出典：中

**B18 主体性**
- 定義：誰にも言われずに、自分で課題を見つけて動くこと（一般的な理解。経産省 社会人基礎力の「前に踏み出す力」の一要素だが、公式の定義文は未確認）
- 例：良：誰も問題にしていなかった欠席の多さを自分で数え、原因を聞いて仕組みを変えた／悪「リーダーとして率先して」と書くだけで、何を自分で決めたかが無い
- ESと面接で：経団連の選考重視点で長年2位（2018年度 64.3%、10年連続2位）。2021年調査でも大卒に特に期待する資質の1位（84.0%）。「任された」の後に、自分で決めた行動を続ける（16の1-5）
- 誤解：「リーダー経験＝主体性」→ 役職ではなく、自分で決めた行動の中身
- 確度と出典：高。経団連 2018年度 新卒採用に関するアンケート調査 https://www.keidanren.or.jp/policy/2018/110.pdf ／経団連 採用と大学改革への期待に関するアンケート 2022年1月 https://www.keidanren.or.jp/policy/2022/004_kekka.pdf

**B19 コミュニケーション能力**
- 定義：企業が言う時は定義が曖昧。リクナビは「表現力（意見を言葉にして伝える）」と「感受性（相手の感情を読み取る）」に分け、どちらを重視するかは職種・企業で違うと整理
- 例：良「相手の立場に合わせて説明の順番を変え、理解してもらった」と、どちらの力かを示して場面を添える／悪「誰とでも仲良くなれる」「コミュニケーション能力が高い」と結論だけ
- ESと面接で：経団連の選考重視点1位（2018年度 82.4%、16年連続）。採用担当が最も説得力を感じるのは「わかりやすく伝える力」29.8%（リクナビ調査）。ESで「コミュニケーション能力」の言葉を使わず、場面で見せる
- 誤解：「話し上手・明るさ＝コミュ力」→ 違う価値観の人の意見を聞き、納得するまで話し合う力で、空気に合わせて意見を抑えることとは違う（琉球新報の記事、検索要約、中）
- 確度と出典：高（経団連 2018年度、リクナビ https://job.rikunabi.com/contents/entrysheet/11441/ ）

**B20 一貫性（一本の線）** → 2-3
- 定義：価値観・原体験・ガクチカ・自己PR・軸・志望動機・キャリアプランが同じ「なぜ」でつながっていること。人事が軸・ガクチカ・自己PR・キャリアプランを通して見ているのは、自己理解の深さ・価値観の適合・話の一貫性・入社後も再現できる行動原理（複数源の一致、中）
- 誤解：「全部をきれいにそろえる」→ 矛盾はなくてよいが、深掘りの「なぜ」に答えが出る状態が大事

### C 企業研究・業界・雇用と配属

**C1 業界研究・企業研究**
- 定義：業界研究＝業界の構造・稼ぎ方・競争相手を掴む作業。企業研究＝個社の事業・戦略・人・働き方・配属を掴む作業
- 例：良：志望動機に、その会社の事業の数字・方針を1つ入れる／悪：採用ページの標語を言い換えただけ（他社でも通じる）
- ESと面接で：情報源の性格を分ける。採用ページ＝見せたい姿／有価証券報告書＝法律で義務の事実／決算説明資料・中計・統合報告書＝経営の意図（任意開示）
- 誤解：「説明会の話＝全社の事実」→ 1部署の話を全社の話と取ると外す
- 確度と出典：編集者の整理（各資料はC2〜C8）

**C2 採用ページ・社員紹介**
- 定義：企業が学生向けに出す公式情報（職種紹介・社員紹介・FAQ・募集要項）
- 例：サイバーエージェントのFAQ「配属先は本人希望をヒアリングした後、適性を考慮し、最終的には経営による判断」
- ESと面接で：募集要項の「配属の可能性」「勤務地」「研修」を、志望職種の書き方と食い違わないかの確認に使う（3-3）。**社員紹介は活躍した人の選抜例で、典型とは限らない**（3-6）
- 誤解：「社員紹介の1年目＝自分の1年目」→ 内定者バイトなど前提が違う例もある
- 確度と出典：高。https://www.cyberagent.co.jp/careers/students/biz/2028/faq/

**C3 有価証券報告書（有報）**
- 定義：金融商品取引法に基づき上場企業等が出す法定開示書類。EDINETで誰でも読める
- 例：「事業の状況」「従業員の状況」に、平均年齢・平均年間給与・従業員数・セグメント別売上。2023年3月期から、人的資本を含むサステナビリティの記載欄、女性管理職比率・男性育休取得率・男女間賃金格差の記載
- ESと面接で：会社の数字を事実として引くならここ。連結と単体で意味が違う（単体の従業員数だけで規模を誤らない）
- 誤解：「就活生が読む資料ではない」→ 章立てが決まっていて、必要な所だけ読めば足りる
- 確度と出典：中。金融庁 https://www.fsa.go.jp/policy/kaiji/sustainability01.pdf

**C4 統合報告書**
- 定義：経営戦略・財務・ESG・ガバナンスをまとめた年次の任意開示
- ESと面接で：社長メッセージ・価値創造の図から「会社が自分をどう語るか」を掴み、軸と照らす。数字は有報・決算で裏を取る
- 誤解：「書いてあることは全部実績」→ 任意開示で見栄え重視
- 確度と出典：低〜中（公式の定義は未確認。「任意開示」という性格は複数の解説で一致）

**C5 中期経営計画（中計）**
- 定義：3〜5年程度の目標・重点戦略・財務目標。任意開示
- 例：良「中計で注力とされる〇〇領域に、自分の〇〇を生かしたい」／悪：期間が終わった古い中計を引用する
- ESと面接で：会社の方向を読んだ証拠になる（17のM4【会】）。**計画を実績のように書かない**（16の4-5 #11）
- 確度と出典：低〜中

**C6 決算短信・決算説明資料**
- 定義：決算短信＝取引所ルールに基づく決算の速報。決算説明資料＝図表中心で経営者が業績と見通しを説明する任意資料
- 例：良：直近でどの事業が伸びたかを1文で書く／悪：業績の良し悪しだけで志望動機を作る（数字を追っただけに見える）
- 確度と出典：低〜中（取引所ルール自体は未確認）

**C7 人的資本開示**
- 定義：人材育成方針・社内環境整備方針と、その指標・目標・実績の開示。有報の「サステナビリティに関する考え方及び取組」に置く
- ESと面接で：研修時間・女性管理職比率・離職率など、働き方の質問に事実で答える材料。指標は会社ごとに定義が違い、横並び比較しにくい
- 確度と出典：中。金融庁（C3）、JIL https://www.jil.go.jp/kokunai/blt/backnumber/2022/07/k_01.html

**C8 青少年雇用情報（職場情報）**
- 定義：若者雇用促進法（2016年3月施行）に基づき、新卒者等に提供される職場情報（過去3年の新卒採用者数・離職者数、研修の有無と内容、平均勤続年数など）
- ESと面接で：定着・研修を数字で確かめる。逆質問の材料
- 誤解：「全項目が出ている」→ 何を出すかを企業が選べる部分がある（詳細未確認）
- 確度と出典：中。厚労省 https://www.mhlw.go.jp/content/11801000/000589933.pdf

**C9 業界の分け方**
- 定義：就活の「業界」は学生向けの通称で、公的分類（日本標準産業分類、東証33業種）と一致しない
- 例：良：業界を「作る・運ぶ・売る・お金・情報・人」の機能で説明し、他業界と比べる／悪「広告業界」と一括りにし、代理店・媒体・制作・自社メディアの違いを無視する
- ESと面接で：志望動機の「なぜこの業界か」は、他の手段と比べて書く（16の4-3 業界・仕事の論理）
- 誤解：「東証33業種＝就活の業界」
- 確度と出典：低〜中（JPX公式一覧は未取得）

**C10 BtoB・BtoC**
- 定義：企業向け取引／消費者向け取引
- 例：サイバーエージェントは広告事業＝BtoB、ABEMAの視聴者向けサービス＝BtoCだが、ABEMAの収益には広告枠の販売も含む
- ESと面接で：「知名度より裏方に関心」など軸の説明に使える。同じ会社でも事業ごとに混在する
- 誤解：「BtoC企業の営業は消費者相手」→ 消費財メーカーの営業先は小売店・卸（5章）
- 確度と出典：用語の公式定義は未確認。サイバーの職種記述は高 https://www.cyberagent.co.jp/careers/students/biz/caguide/detail/id=33811

**C11 総合職・一般職・エリア総合職**
- 定義：コース等で区分した雇用管理の代表的な区分。一般的な運用は、総合職＝転勤・配置転換を含む基幹的業務、一般職＝補助的・定型的業務、エリア総合職＝勤務地を限定した総合職。区分の定義は法律になく企業ごと。根拠は厚労省の「コース等で区分した雇用管理」の指針
- 例：東京海上日動は2026年4月からエリア総合職の募集をやめ総合職に一本化し、本拠地の申告と転居転勤の同意を毎年選ぶ制度に（検索要約、中）
- ESと面接で：志望コースの転勤範囲・仕事の範囲を募集要項で確認してから書く。総合職で「勤務地は〇〇がいい」と書かない
- 誤解：「一般職＝女性」→ 指針は男女で運用を分けることを問題としている
- 確度と出典：中。厚労省 https://www.mhlw.go.jp/content/000643881.pdf

**C12 限定正社員（多様な正社員）**
- 定義：勤務地・職務・労働時間のいずれかを限定した正社員（厚労省の用語は「多様な正社員」）
- ESと面接で：勤務地を限定したいなら、制度の有無を募集要項で見る
- 確度と出典：中。https://part-tanjikan.mhlw.go.jp/tayou/pdf/tayou_jirei.pdf

**C13 ジョブ型・メンバーシップ型**
- 定義：ジョブ型＝職務（ポスト）を特定して採る。メンバーシップ型＝職務を特定せず一括で採り、社内で配置・育成する（濱口桂一郎氏の命名）
- 例：日本の新卒はメンバーシップ型が中心。「職種別・コース別」の採用がジョブ型採用の経験の約2割（内閣府 学生調査、中）
- ESと面接で：職種を決めて応募する会社なら職種への適性、入社後に決まる会社なら会社全体への適性と、どの入口でも使える力を書く（3-4）
- 誤解：「ジョブ型と名乗れば配属後の異動はない」→ 実態は職種別採用にとどまり異動がある例も。名称より運用を見る
- 確度と出典：中。JIL https://www.jil.go.jp/institute/zassi/backnumber/2023/06/pdf/034-043.pdf ／内閣府 https://www5.cao.go.jp/keizai1/gakuseichosa/000126089.pdf

**C14 コース別採用・職種別採用**
- 定義：コース別＝入社時に職種のグループ（例：ビジネス・エンジニア・クリエイター）を選ぶ。職種別＝営業・企画など職種を指定
- 例：サイバーエージェントは3コース（ビジネス・エンジニア・クリエイター）、ビジネスコースの募集職種は営業／プロデューサー／本社機能の3種で、全事業部への配属可能性
- ESと面接で：コースは志望動機の主語（何をする人として入るか）を決める。**コースが同じでも、配属先の事業が違えば仕事は全く違う**
- 誤解：「コース＝部署」
- 確度と出典：高。https://www.cyberagent.co.jp/careers/about/

**C15 初期配属**
- 定義：入社後最初の配属先
- 例：採用時に確定する会社（コース別の東京海上日動）と、研修後に発表する会社（三井不動産は5月中旬、信越化学は研修終了後、サイバーエージェントのビジネスコースは研修の日に発表と公式動画の要約にある）がある
- ESと面接で：初期配属を知らずに「〇〇の仕事で成長したい」と書くと、初年度の仕事と合わず「うちを分かっていない」と見られる（3章）
- 確度と出典：高〜中（各社採用ページ。サイバーの研修の流れは動画のAI要約欄で、本編は要確認）

**C16 配属ガチャ**
- 定義：配属先が運で決まるという俗称。公式用語ではない
- 例：「外れたと感じる」11.1%、希望どおりでない配属は約4割（マイナビ 2024年調査）／2024年3月卒業時点で配属先が確定していた学生46.9%（就職みらい研究所）。いずれもメディア経由で母数・方法は未確認（中）
- ESと面接で：ESに「配属ガチャ」は書かない。「配属先を問わず〇〇の力を磨く」（型C）か、希望の理由を書く
- 誤解：「希望はまったく考慮されない」→ 多くの会社が面談・希望調査をする（C18）
- 確度と出典：中。https://www.j-cast.com/2024/08/23491479.html?p=3 ／カオナビ https://www.kaonavi.jp/dictionary/haizokugacha/

**C17 配属確約**
- 定義：内定時に配属先（職種・部署・勤務地）を約束する制度の俗称。法的な定義はない
- ESと面接で：募集要項に確約とあれば、その仕事を前提に書いてよい（3-4 型D）。確約の範囲（職種だけか、勤務地もか）は会社ごと。書面で確かめる
- 確度と出典：低（用語の公式出典なし）

**C18 配属希望（面談・希望調査）**
- 定義：配属前に本人の希望を聴く運用（面談・希望調査票・自己申告）
- 例：三井不動産は研修中に配属希望調査／伊藤忠は配属面談で希望・適性を確認し人事・総務部が決定（検索要約）／リクルートは内定から入社までに希望を聞く面談（検索要約）
- ESと面接で：ESの志望職種欄の内容が希望調査の根拠になりうる。**希望＝約束ではない**。「希望が通らなかったら」の質問に備える（2-8）
- 確度と出典：高（三井不動産FAQ https://recruit.mitsuifudosan.co.jp/shinsotsu/recruit/faq/ ）・中（その他）

**C19 ジョブローテーション**
- 定義：数年ごとに複数の部署・職種を経験させる育成・配置の仕組み。型は2つ：職種そのものが変わる型（大手メーカー・金融の総合職に多い）と、同じ職種の中で担当業界・商材が変わる型（コンサル・総合商社に多い）（OneCareer、検索要約、中）
- 例：三井不動産 総合職は3〜5年程度でローテーション、10年で3部署ほど（高）／損保系ダイレクト企業は異動の平均3〜4年が目安（検索要約、中）
- ESと面接で：「様々な部署を経験して」と書くなら、その会社が実際にローテーションする会社か確かめる。ローテーションがない会社に「幅広い経験を」と書くと矛盾する
- 誤解：「どの会社にもある」→ 会社主導の定期ローテーションの記述が確認できない会社もある（サイバーエージェントは異動公募が中心）
- 確度と出典：用語の公式定義なし（低）。導入率はJILPT調査の紹介（ITmedia、中）https://www.itmedia.co.jp/business/articles/2205/23/news058_2.html

**C20 社内公募・異動公募**
- 定義：本人が手を挙げて異動できる制度。会社ごとに名前がある
- 例：サイバーエージェント「キャリチャレ」（現部署1年以上、応募者の約7割が異動、公式FAQ）／関西みらい銀行「ジョブエントリー制度」（本人の志願で本部へ異動した例）／DeNA「シェイクハンズ制度」（入社1年後以降、検索要約）／イオンも社内公募あり
- ESと面接で：キャリアプランで「〇年目以降、〇〇制度も活用して〇〇に挑みたい」と書ける。**制度名は根拠カードにある時だけ**。条件（1年以上など）を外さない
- 確度と出典：高（サイバーFAQ・関西みらい銀行 https://www.kansaimiraibank.co.jp/saiyo/sinsotsu/careerpath/ ）・中（DeNA）

**C21 OJT・Off-JT・研修**
- 定義：OJT＝仕事をしながらの訓練。Off-JT＝業務を離れた訓練（集合研修・外部研修）
- 例：サイバーのビジネスコースは入社後約1週間の全体研修、その後事業部ごとの研修／信越化学は研修の主体がOJTと明記／JR東日本 総合職は約3週間の集合研修の後、約6か月の職場実習（検索要約）
- ESと面接で：「研修で学びたい」より「研修で得た基礎を、〇〇の現場で生かす」。研修の手厚さを志望理由の中心にすると受け身に見える
- 確度と出典：高（各社公式）・中（厚労省 能力開発基本調査 https://www.mhlw.go.jp/content/11801000/000583354.pdf ）

**C22 キャリアパス**
- 定義：入社後の昇進・異動の道筋
- 例：関西みらい銀行の公式キャリアモデル：1年目は支店の窓口・預金・融資事務、2年目から法人営業、3年目に個人営業、5年目に転居を伴う異動と出向、10年目にジョブエントリーで本部（1社の例。一般化は不可）
- ESと面接で：「5年後」を書く時は、その会社の実在のパスに合わせる。社員紹介は成功例で平均と違う
- 確度と出典：高（1社の事例）

**C23 若手の裁量**
- 定義：公式な定義はなく、意味は会社ごとに違う（予算か・担当領域か・提案の自由度か）
- 例：サイバーエージェントの2022年入社の社員は1年目からX担当、途中でABEMAのX責任者に。ただし内定者バイト（宣伝本部で約10か月）の下積みが先にある
- ESと面接で：「若手から裁量」を志望理由にするなら、何の裁量かに言い換え、それで何をするかを書く。「早く任されたい」だけだと責任への覚悟が見えない
- 誤解：「裁量＝自由・楽」→ 社員の記事では責任とセットで語られることが多い（編集者の読み、低）
- 確度と出典：高（事実）https://www.cyberagent.co.jp/careers/students/people/detail/id=30883

**C24 求める人物像・行動指針・バリュー**
- 定義：採用基準・組織の価値観を言葉にしたもの
- 例：良：自分の行動の事実を1つ示し、結果としてその価値観と合う形にする／悪：バリューの言葉をそのままなぞる（他社でも通る文になる）
- ESと面接で：自己PRの強みと締めは、人物像と同じ向きに（16の2-2）。会社の言葉はそのまま引用しない（es-writerの守ること）
- 確度と出典：公式定義は未確認

**C25 初任給・固定残業代・福利厚生**
- 定義：福利厚生＝法定外の福利（住宅補助・休暇制度など）。固定残業代＝一定時間分の残業代を給与にあらかじめ含める仕組み
- 例：サイバーエージェントの採用概要（取得時点）：初任給 月給42万円（年俸504万円）、固定残業代は時間外80時間／月相当を含む、家賃補助「2駅ルール」月3万円（年度で変わる、最新は要確認）
- ESと面接で：ESにはほぼ書かない。企業比較・逆質問で使う。固定残業代の含む時間を見落とすと給与の比較を誤る
- 確度と出典：高（取得時点）https://www.cyberagent.co.jp/careers/about/

**C26 フレックスタイム制・リモート**
- 定義：フレックス＝始業・終業時刻を働く人が決める制度。就業規則と労使協定が必要。コアタイムは任意設定。清算期間の上限は3か月（2019年改正）。リモート＝会社外で働くこと
- ESと面接で：志望動機にしない。「フレックスあり」でもコアタイムや部署で実態は違う
- 誤解：「フレックス＝労働時間が短い」
- 確度と出典：中（厚労省 https://www.mhlw.go.jp/content/001140964.pdf ）。リモートは公式出典を取得せず未確認

**C27 転勤**
- 定義：勤務地の変更を伴う異動。就業規則に定めがあれば原則として個別の同意なしで命じうるが、権利濫用とされる場合もある（厚労省資料、中）
- 例：サイバーエージェントは原則東京勤務、ただしインターネット広告事業部のみ大阪・福岡・名古屋に支店があり配属の可能性
- ESと面接で：「転勤は問わない」「東京で働きたい」と書く前に、その会社の転勤の有無と例外を確かめる
- 確度と出典：高（サイバーFAQ）・中（厚労省 https://jsite.mhlw.go.jp/hiroshima-roudoukyoku/library/20170510_tenkin_koyoukanri.pdf ）。2025年10月の育児・介護休業法改正が配置に及ぶ範囲は未確認

**C28 企業規模（大手・中堅・ベンチャー・メガベンチャー）**
- 定義：法的に定義があるのは中小企業（中小企業基本法）と中堅企業（2024年の改正産業競争力強化法、従業員2,000人以下で中小企業者を除く会社等）。大企業・ベンチャー・メガベンチャーは通称
- 例：製造業の中小企業は資本金3億円以下または従業員300人以下が目安
- ESと面接で：ESでは通称（大手・メガベンチャー）を使わず、事業の中身と意思決定の距離で書く
- 確度と出典：中（経産省 https://www.chugoku.meti.go.jp/r6fy/topic/chikei/pdf/241017_01.pdf ）。メガベンチャーの定義は未確認

### D 選考手法と評価

**D1 エントリーシート（ES）**
- 定義：企業独自の設問に文章で答える応募書類。自己PR・志望動機・ガクチカが中心。一斉採用で全員を面接できないことへの実務的対応から普及した（鈴木智之 2023）
- 例：ESの自由記述の「達成」「リーダー」「イベント」の3語の頻度だけで、直後の一次面接の合否を約72%当てられた研究がある（鈴木2016。1研究・語の頻度であり「その語を書けば通る」ではない）
- ESと面接で：**多くの企業で、ESは書類だけで判断する物ではなく面接の補助資料**（リクルートMSの人事向け解説、中）。ESが一次面接の質問台本になる。ESの事実が面接で説明できない・数字や役割が食い違うと不利
- 誤解：「ESの面白さで勝負が決まる」→ ESの予測妥当性は学術的にほぼ検証されていない（「理論・実証ともに不足したまま実務だけが先走っている」鈴木2023）。**ESを読む時間・足切りの有無と割合は未確認**
- 確度と出典：高（学術）JIL『日本労働研究雑誌』2023年7月号 https://www.jil.go.jp/institute/zassi/backnumber/2023/07/pdf/020-029.pdf ／中 https://www.spi.recruit.co.jp/spi3news/000407.html

**D2 履歴書**
- 定義：氏名・学歴・資格などの事実を並べる書類。厚労省は履歴書の様式例（2021年4月、性別欄は任意、通勤時間・扶養家族・配偶者の欄を削除）を参考にするよう求める
- ESと面接で：履歴書＝事実確認、ES＝人物・動機・思考の確認。両方の事実（日付・役職）をそろえる
- 確度と出典：中（厚労省系ページの検索要約）。原文 https://www.mhlw.go.jp/content/11600000/04.pdf は要再確認

**D3 公正な採用選考**
- 定義：応募書類・面接で、本人に責任のない事項（本籍・出生地・家族・住宅・生活環境）と本来自由な事項（宗教・支持政党・尊敬する人物・愛読書など）、計14事項を企業が把握しないこと。作文の題材にもしない
- 例：面接で家族構成を聞くのは、雰囲気づくりの目的でも不適切（厚労省）
- ESと面接で：ガクチカ等で家族や生い立ちを書く必要はない。本人が自分の意思で書くことを禁じる趣旨かは未確認。書くなら自分の行動が主役の範囲で
- 確度と出典：高。厚労省 公正な採用選考 https://kouseisaiyou.mhlw.go.jp/consider.html

**D4 適性検査（総論）**
- 定義：能力検査（言語・計数など）と性格検査の2本立てが多い。性格検査は質問紙法が多い（SPIも）。受け方はテストセンター／自宅のWeb／企業のPC（インハウスCBT）／紙
- 例：SHLのGABは活用例に「面接での確認項目の整理」、玉手箱Ⅲは「面接ガイド版の結果帳票（質問例と評価指標つき）」を選べる
- ESと面接で：**性格検査の結果は面接の深掘りの材料にされうる**。ESで語る自己像と大きく食い違わないように（面接官が実際に見て質問するかは企業差で未確認）
- 誤解：「嘘をつけば有利」→ SPIは歪んだ回答を検出する設問を含むと公式が説明。「性格検査に正解がある」→ 基準は企業ごとで非公開（未確認）
- 確度と出典：高。https://www.spi.recruit.co.jp/spi3news/000221.html ／ https://www.shl.co.jp/service/assessment/gab/ ／ https://www.shl.co.jp/service/assessment/tamatebako3/

**D5 SPI3**
- 定義：リクルートマネジメントソリューションズの適性検査。大卒向けはSPI3-U（性格＋基礎能力：言語・非言語）。英語や構造把握力を足した版もある
- 例：PCで性格＋能力が約65分、紙で約110分。テストセンターは能力検査の予約翌日の午前3時までに性格検査をWebで終える必要（FAQの検索要約、中）
- ESと面接で：性格検査の結果は「どんな業務・職場に適応しやすいか」まで数値化される（公式）
- 誤解：「全部同じ形式」→ 方式で時間・内容が違う
- 確度と出典：高 https://www.spi.recruit.co.jp/spi3news/000042.html

**D6 玉手箱**
- 定義：日本SHLの総合適性検査。公式の玉手箱ⅢはWeb、計49分、言語・計数・英語＋性格（OPQ）
- 例：計数は四則逆算、言語は約1,000字の趣旨把握（公式）。「計数が3形式に分かれ1形式ずつまとめて出る」は就活メディア由来で公式未確認
- ESと面接で：面接ガイド版の帳票を企業が選べる（D4）
- 誤解：「玉手箱＝GAB」→ 公式では別商品
- 確度と出典：高 https://www.shl.co.jp/service/assessment/tamatebako3/

**D7 GAB**
- 定義：日本SHLの、論理的思考力に特化した総合適性検査。言語・計数・英語・性格（OPQ）、計80〜90分。AI監視つきのWebGAB Secureもある
- ESと面接で：活用例に初期スクリーニング・面接での確認項目の整理・配属（公式）
- 誤解：「総合職向けだけ」→ 公式に対象を限る記述なし（就活メディアの説明は未確認）
- 確度と出典：高 https://www.shl.co.jp/service/assessment/gab/

**D8 CAB**
- 定義：日本SHLの、IT・デジタル職のポテンシャルを測る検査。知識を前提としない（四則逆算・法則性・命令表・暗号＋性格）、計72〜95分
- 誤解：「IT経験が必須」→ 未経験も受検可（公式）
- 確度と出典：高 https://www.shl.co.jp/service/assessment/cab/

**D9 TG-WEB**
- 定義：ヒューマネージの適性検査。性格（ビッグファイブ）、判断推理力・考察力・基礎能力・英語などのラインナップ。受け方はAI監視型の自宅受検・Web・テストセンター・マークシート
- 誤解：「従来型／新型」という区別は就活メディアの呼び方で、公式の名前との対応は未確認
- 確度と出典：高（受け方）https://tg-web.humanage.co.jp/test_method/ ・中（内容）

**D10 SCOA**
- 定義：能力検査（言語・数理・論理・常識・英語）と性格検査からなる総合適性検査、と就活情報で説明される
- 確度と出典：低／未確認。提供元の公式を取得できず、社名表記も情報源で食い違う。使う時は志望企業の案内で確かめる

**D11 内田クレペリン検査**
- 定義：一桁の足し算を続け、作業量の推移（作業曲線）から性格・行動特性を見る作業検査法。意図的に歪めにくいが専門的な解釈が要る（作業検査法の一般論、RMS）
- 確度と出典：総論は高。前半15分・休憩・後半15分などの仕様、安全重視の職種で使われる等は二次情報で未確認（提供元の公式を取得できず）

**D12 グループディスカッション（GD）**
- 定義：学生を数人に分けてテーマを議論させ、様子を見る選考。協調性・リーダーシップが見やすく、一度に多く会えるが、個人を深く知るには向かない（リクルートMS）
- 例：良：他の人の意見を1つ拾って案に組み込む発言／悪：司会を取ることだけを狙う
- ESと面接で：ESで「チームで成果を出した」と書いた人は、GDの振る舞いと一致するかが暗黙に比べられうる（推論）
- 誤解：「司会をしないと落ちる」→ 役割より発言の中身という採用側の見解（低〜中）。企業公式の評価シートは未確認
- 確度と出典：中〜低 https://www.spi.recruit.co.jp/spi3news/000407.html

**D13 面接（個人・集団・役員）**
- 定義：選抜の中心の手法。目的は見極めだけでなく、企業理解の促進・入社不安の解消・動機づけも含む（リクルートMS）。集団面接は初期に効率よく、個人面接は二次以降で使われることがある
- 例：役員面接は最終段階で入社意思・価値観を確かめる場と言われる（就活メディア、低。公式定義は未確認）
- ESと面接で：ESが質問の出発点。キャリアプランで部署を決め打ちすると、「その部署に行けなかったら」と掘られる
- 誤解：「面接官は皆訓練されたプロ」→ 国内は構造化面接の導入は進んだが、信頼性・妥当性の検証はあまり報告されていない（鈴木2023）
- 確度と出典：中〜高

**D14 構造化面接**
- 定義：事前に質問と評価基準を決め、全員に同じ質問をし、基準で評価する面接。自由質問を足す半構造化面接も多い
- 例：予測の妥当性係数は構造化面接 .51／非構造化 .38（Schmidt & Hunter 1998、鈴木2023の表）
- ESと面接で：全員に同じ観点で深掘りされる前提。ESの事実を、状況→課題→行動→結果で話せるように
- 誤解：「面接官のノリで決まる」→ 構造化されていれば減る
- 確度と出典：高。鈴木2023（D1）／日本の人事部 https://jinjibu.jp/keyword/detl/1668/

**D15 行動面接（STAR）**
- 定義：状況（Situation）・課題（Task）・行動（Action）・結果（Result）の順に、過去の具体的な行動を掘る構造化面接の手法
- 例：Sでは当時のチーム体制・目標、Tでは課題の背景を聞かれる
- ESと面接で：ガクチカはSTARの素材。S・Tを短く、A（自分が何をしたか）を厚く、Rは数字や変化で（推論）
- 誤解：「STARで書けば必ず評価される」→ STARは面接官が掘る枠。準備済みの型どおりの回答は妥当性を損なうと出典側も指摘
- 確度と出典：中 https://directscout.recruit.co.jp/biz/guide/article/2906

**D16 深掘り**
- 定義：回答の背景・思考・行動を段階的に問い返すこと。過去の具体的な行動と、その背景・思考の過程を掘る
- ESと面接で：見られるのは、一貫性・自分の役割の明確さ・事実と解釈の分け方・再現性（推論を含む）。「なぜ」を3回重ねる練習をする（CLAUDE.mdの8）。軸・キャリアプランは「他社では？」「配属が違ったら？」で掘られる（2-8）
- 誤解：「深掘り＝圧迫」→ 全員に同じ観点で掘り、評価のばらつきを抑える目的
- 確度と出典：中

**D17 コンピテンシー**
- 定義：高い業績を挙げる人の行動・思考・判断の特性。「成果につながる行動の特性」。自社の高業績者を分析して評価項目にする
- ESと面接で：企業の「求める人物像」の多くはこの形（推論）。ESで示す行動が、その会社のコンピテンシー（主体性・課題解決など）と対応しているかが観点になる
- 誤解：「コンピテンシー＝性格」→ 行動の形で現れる特性
- 確度と出典：中 https://jinjibu.jp/keyword/detl/14/

**D18 評価シート**
- 定義：面接官が評価項目ごとに採点・コメントする用紙。構造化面接の基準を実装する道具
- ESと面接で：評価項目に沿って、ESの記述が根拠として引かれる運用が想定される（推論）
- 確度と出典：新卒採用の企業公開の評価シート実物は未確認

**D19 ケース面接**
- 定義：架空の企業・業界の課題を出し、その場で構造化して解く面接。コンサルで一般的
- 例：マッキンゼー日本の新卒は経験の面接（Personal Experience Interview）と問題解決の面接（Problem Solving Interview）の組み合わせ。評価軸に Connection・Drive・Leadership・Growth・Problem Solving（公式ページの検索要約）
- ESと面接で：経験の面接ではESやレジュメの経験が素材
- 誤解：「正解を当てる試験」→ 構造化して結論を示せるかのプロセス
- 確度と出典：中 https://www.mckinsey.com/jp/careers/interviewing 。BCG等の公式は未取得

**D20 フェルミ推定**
- 定義：直接のデータがない量を、前提を分解して概算する課題（例：市場規模）
- 確度と出典：公式な定義・評価観点の資料は未確認。ケース面接の一部で使われるとされるが出典なし

**D21 逆質問**
- 定義：面接の最後に応募者から質問する時間
- ESと面接で：3-3の「配属はどう決まるか」「1年目は何をするか」「異動の希望はどう出すか」は、キャリアプランを現実に合わせる材料になる（編集者の提案）
- 確度と出典：評価対象かどうかの公式・学術資料は未確認

**D22 録画面接・AI選考**
- 定義：事前に出された質問に録画で答え、後から人やAIが評価する方式
- 例：JCBは26卒の選考から、人事部以外の社員が行っていた面接をやめ、HireVueの録画面接に切替。AIは発言内容から主体性・状況適応力・学習意欲などを5段階で判定し、外見や個人属性は使わない。AIの総合スコアは参考で、最終合否は採用担当者
- ESと面接で：発言の論理性が見られる。ESの内容と話せる範囲をそろえる（推論）
- 誤解：「AIが顔で判定する」→ この事例では外見は使わないと説明（企業側の説明）。他社の運用は未確認
- 確度と出典：中。経団連掲載の事例 https://www.keidanren.or.jp/policy/2026/016_jirei02.pdf

**D23 内定者面談**
- 定義：内定・内々定の後に、入社意思・不安の確認や懇親で行う面談
- ESと面接で：配属希望を聞く面談を兼ねる会社がある（リクルート、C18）。キャリアプランで書いた希望と同じ話ができるように
- 確度と出典：中。評価に使われる実態の公的データは未確認

**D24 生成AIとES**
- 定義：ESの作成・推敲に生成AIを使うこと
- 例：就活でAIを使った学生66.6%（前年37.2%）、用途はES推敲68.8%・ES作成40.8%（マイナビ 2026年卒総括）。企業は「慎重に検討したうえで活用してほしい」64.1%、対策は「面接での質問内容を工夫する」26.0%、「ESの内容を精査する」10.8%（マイナビ 2026年卒企業新卒採用活動調査）
- ESと面接で：企業はAI利用を禁じるより、面接で本人の中身を確かめる流れ。ESには面接で追加質問されても答えられる具体的な事実（数字・場面・自分の判断）を入れる。会社の事実の誤りはAIの下書きで起きやすいので、根拠カードで必ず裏を取る（16の1-11）
- 誤解：「AIで書けば差がつく」→ 誰でも使うので、差は固有の事実と本人の言葉
- 確度と出典：中〜高。https://career-research.mynavi.jp/reserch/20250723_98417/ ／ https://resemom.jp/release/prtimes/20250926/158019.html

### 6-2 ESへの意味（編集者の整理）
1. **書くべき力は5つに絞れる**：他者とどう関わったか（コミュニケーション）、自分で決めて動いたか（主体性）、挑戦したか、協調したか、誠実か。成果の大きさより、この5つが1つの場面で読み取れるか（16の2章(d)・3章④と同じ向き）
2. **成績・専門性は低い（4.4%・12.0%）が、ゼミ・研究の中身は見られる（46.1%）**。研究の設問は「何を・なぜ・どう工夫したか」で書く
3. **インターンのESは志望度（72.2%）と人柄・価値観（51.2%）**。「なぜこの会社のインターンか」と、価値観が分かる経験を書く。学校名は10.7%
4. **経験の羅列より「今後の可能性」**：締めで入社後に何ができそうかを書く（2012年の古いデータだが、16の再現性と同じ向き）
5. **軸があると決め方の納得が違う（65.8% vs 31.1%）**。軸は本人のためにも作る（2章）
6. **AI前提の時代、差は固有の事実と面接で話せる中身**。企業は面接の質問で確かめる方向（26.0%）
7. **ESは面接の台本**。書いた事実・会社の事実・キャリアプランは、深掘り（「配属が違ったら」）に耐える形で
- 注意：「企業がESのどの設問・どこを見ているか」「ESを読む時間」「足切りの割合」の一次調査は見つからず未確認。審査で「人事は〇秒で読む」などを数字の事実として使わない（reviewer-hrの「1枚90秒」は読み方の前提であって調査値ではない）
